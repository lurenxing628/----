# 第一项迁移验收

## 1. 接口契约

- 新 HTML 入口和只读 API 已接入；非法入口404、资源缺失503、读取失败500、维护窗口503各自明确，不返回假成功。
- QuerySuccess 带真实实例数据和本次请求/快照引用。未知、0、部分异常和未经校验分别表达。
- 前端拒绝外源地址、错误媒体类型、非法JSON、协议不匹配、实际字段缺失；取消与20秒超时分开处理。
- 本阶段的引用只用于只读数据辨认，不宣称写令牌、幂等提交或恢复事务已经实现。

## 2. 行为与决定

- 只读新入口不运行自动维护，旧入口保持既有逻辑；不改 schema，不写正式排产或执行事实。
- 样例草稿不参与真实读取与保存，读取失败不自动切样例。
- 已实际搜索挂载点：`factory.py` 的 Blueprint 导入/注册、新入口免维护名单、模板启动配置、前端合同依赖。
- 拔除沙盘：移除 Blueprint 注册则新URL消失，旧 `/` 仍独立；移除资产清单则宿主503；缺少必需前端合同/组件则启动失败明确显示。对应缺资源、旧首页和依赖检查测试覆盖，不为演练修改用户源文件。
