- 现有identity_triggers增加可选复合备用键，旧调用SQL保持一致。PartOperations的(part_no,seq)唯一冲突和主键冲突同时参与旧引用失效，覆盖recursive_triggers关闭时的REPLACE及双冲突；普通更新保留实例引用，删除重建不复用。
- 新只读列表、详情及路线预检已注册。列表支持搜索、阶段、分页及基础三态排序；详情包含原工序、工时、供应商、外协组策略、批次引用计数和真实问题。存量source或0工时不被推断为人工确认，GET不分配身份、不修补数据。
