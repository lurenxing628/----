# 看清资源派工和日历明细

## 用户故事

- 作为计划员，我希望按人员或设备查看一段时间内每天做什么，而不是在一格里看一坨挤在一起的任务文字。
- 作为调度员，我希望横向看一整个月时还能知道当前行是谁或哪台设备，而不是滚动后忘了自己在看哪一行。
- 作为现场管理人员，我希望超期任务直接写明“超期”，而不是只靠颜色猜。
- 作为需要查问题的人，我希望 Excel 里既能看日历大盘，也能按一条任务一行筛选日期、人员、设备、批次和工序。

## 为什么需要

资源派工不是只给系统算，它还要给人看。人员和设备一天可能有多条任务，如果页面和 Excel 只把文字塞在同一个格子里，计划员很难分清任务边界，也很难在导出后筛选查问题。

## 怎么解决

页面把日历格子里的任务拆成一条条清楚的任务块，时间、批次、工序、设备、人员和图号/物料分开显示。Excel 保留原来的日历矩阵，同时提供日历明细，让用户既能看整体排班，也能逐条任务筛选。

## 边界

- 不负责拖拽改排程，不把资源派工页面变成排程编辑器。
- 不做热力图、复杂折叠或新的大屏分析。
- 不把程序内部编号、快照字段或调试字段放进普通页面和用户导出的 Excel。
- 使用前提是已经有排产结果；没有排产结果时仍按原有空数据和错误提示处理。
