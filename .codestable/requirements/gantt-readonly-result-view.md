# 只读甘特图结果查看能力

## 1. 用户目标

调度员打开甘特图时，要能可信地查看正式排产结果：每道工序排在哪个时间、哪台设备、哪个人员、是否超期、是否属于关键工序，都应该一眼能看懂。

第一版甘特图只负责“看结果”，不负责“改计划”。页面必须明确告诉用户这里是查看模式，任务条不能拖动或拉伸成假修改。

计划员从工作台进入计划中心时，希望直接看到可读的当前正式计划和完整任务行；从已有链接或其他页面回返时，则继续查看原来指定的计划和范围。查看现场实际时，希望初始画面落在有计划或报工的时间段，刷新或调整窗口宽度后能在所选范围内继续查看原时间段。

## 2. 第一版能力范围

- 默认查看模式：拖动和拉伸任务条不会修改计划，页面也不提供保存入口。
- 稳定任务详情区：点击任务后，页面在甘特图旁边或下方持续显示批次、图号或物料、工序、资源、计划时间、现场实际小结、超期提示和下一步入口。
- 时间缩放：支持月、周、日、12小时、6小时、小时、15分钟、5分钟、1分钟。
- URL 复现：`gantt_zoom`、配色、批次筛选、资源筛选、关系线和关键工序开关可以从 URL 恢复。
- 短工序查看：36 分钟、51 分钟、73 分钟和跨天短工序要按真实时长显示，并保留可点击区域。
- 范围保护：分钟级范围过大、列太多或估算节点太多时，不硬渲染，先提示用户缩小范围或切到更粗粒度。
- Win7 离线边界：不引入 CDN，不要求目标机联网，不要求目标机安装 Python。

## 2.1 当前工作台的查看体验

- 未指定计划、没有恢复或筛选定位上下文时，优先打开唯一可读的当前正式计划；没有可自动选择的计划时保留目录。明确指定的计划读取失败时说明原因，不换成另一版计划。
- 选中计划后，目录收成顶部选择器，用户可继续切换计划；在支持的桌面尺寸下，首屏完整显示第一条任务及其条形。计划、甘特和交付风险页签保留当前对象与查看范围。
- 实际甘特初始窗口优先对齐所选计划区间，没有计划端点时使用已有实际报工区间。缩放围绕选中项或数据中心，“适应全部”覆盖计划基线和实际记录；恢复查看位置时按所选范围中的时间段定位，切换范围后重新定位。
- 短工序和零时长点仍可通过鼠标或键盘选择，键盘能继续查看首尾及屏幕外的任务。点击区域易于命中，不代表增加任务持续时间或实际工时。

## 3. 明确不做

- 不做拖动保存。
- 不新增调整草稿接口。
- 不写 `Schedule`。
- 不写 `ScheduleHistory`。
- 不改变正式版本指针。
- 不提供秒级、0.1 秒时间刻度。
- 不因分段显示大量任务而删减完整结果或改变排程事实。
- 不开放“模拟调整正式发布”。
- 不在详情区或弹窗正文里展示 `op_id`、`schedule_id`、`source_table`、`scenario_id`、`op_<数字>` 这类内部定位字段。

## 4. 成功标准

- 用户能看到“当前为查看模式”的页面提示。
- 设备视图和人员视图都不能拖动、拉伸、改进度。
- 点击任务条仍能打开详情弹窗。
- 未选择任务时，详情区提示“点击甘特条查看任务详情”；点击任务后，详情区显示公开字段和下一步入口。
- 没有现场记录时，详情区显示“暂未记录现场实际”，不把计划时间当成实际时间。
- 当前工作台的默认选择不覆盖显式计划与恢复上下文；实际甘特只调整显示视窗，不改变查询范围、计划时间、实际记录或正式版本。
- 9 个时间粒度都能切换。
- 1 分钟视图只允许安全范围，不让页面卡死。
- 说明书、页面帮助和回归测试都和真实页面行为一致。
