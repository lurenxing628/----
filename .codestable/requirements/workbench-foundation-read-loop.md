# 工作台首个真实只读入口

## 已实现

- 从新工作台查看当前实例的数据库可读状态、备份/日志文件信息、操作记录数量、有效和缺省维护配置、最近维护记录。
- 查看、刷新和切页不触发自动备份、清理或缺省配置补写；原正式入口既有行为保持。
- 文件存在不等于可恢复；数据库可读取不等于完整性检查通过；页面依赖检查不冒充本机运行健康。
- 请求失败、非法数据或超时明确报错，并能重试；管理样例不替代真实数据，不写入本机配置。
- 沿用原型的侧栏、主题、分区和控件，整行维护入口可点，文件详情关闭后返回原焦点。
- 静态资源本地预编译交付，目标机不需额外安装 Node/Python，不依赖外链。

## 不属于本阶段

本需求只记录已完成的首项迁移，不宣称完整系统维护、其他业务页、压测、Win7原机或最终发布完成。写入维护动作、候选/正式计划、分次报工及其余业务继续按总体 roadmap 实施。当前是源代码与隔离实例验收通过，未替换生产入口。
