# 工作台视觉与布局统一实施记录

## 1. 结论与边界

用户批准总体方案后，已整理 14 个主页面及独立试调样板，保留现有导航、蓝色主色、深浅主题与桌面操作习惯。主目标 1920×1080，补验 1392×924。原型直接以 `file://` 打开，不需要开发服务器。

本轮只涉及 `前端设计/ui_kits/workbench/` 的原型、对应测试及本记录，不改生产后端、数据、排产算法、打包运行时或依赖。Win7 x64 单机离线前提不变；Mac 上 Chrome 的结果不等于 Win7 实机兼容性证明。

批准方案：`.codestable/brainstorms/2026-09-08-workbench-visual-language/overall-proposal.md`。

## 2. 根因与处理

- 原型存在多套局部字号、控件高度和行距，共享样式与局部覆盖叠加后，同一工具栏和表单错位。现按用途区分 32px 工具栏、36px 连续录入，标签、单位、按钮统一对齐；部分已有日历工具保留更大的点击面积。
- 大量浅底、双边线与外围框重复表达同一层级。现用标题、组距和底色区分大区块，设置行、详情组、表头/数据行、固定动作区仍保留必要细线，不走全部删线或全部加框的极端。
- 报表首屏纵向层级过多，单改输入框无法解决。合并标题/排序/导出，原地收起次要筛选，显示可清除的实际条件值；表格前保留来源、数据截至、警告和短口径，把趋势和长方法移到明细之后。
- 系统配置原有标签/输入距离与信息权重不适合本机维护。现限制表单内容宽度，标签靠近控件；本机维护为主、页面自检为辅，即时偏好与未保存样例草稿分清。
- 语义色必须前景/背景成对使用。修复批次及校准页深色徽标的低对比搭配，重点数字依真实状态着色，不把普通完成率或未知状态包装为健康。
- 原生日期图标原先未跟随深色主题，显示为黑色。复用项目已有 `color-scheme` 方式，仅作用于 `.aps-workbench` 内原生日期/时间输入；新增实际日历图标像素检查，不替换日期组件。
- “兑现、容差、未闭合、账龄”等用户可见文字改为具体中文；10 分钟等说明从现有阈值生成，不改判定。值班台中文来源名称保留原内部来源 ID。校准样例采纳只标记本页，不再声称写入本机定额或已经留痕。

## 3. 页面覆盖

| 页面 | 本轮处理与保留项 |
| --- | --- |
| 基础资料 `process` | 下方工艺/资源/日历维护控件、表单、分区字号和间距；保留原生挂载/会话与用户已批准的产能链主线专用外观例外 |
| 批次管理 `batches` | 列表/详情标题层级，筛选和整表动作对齐，表单/错误态，深浅徽标配对；保留全部事件处理 |
| 主数据总览 `basedata` | 筛选工具栏、主从详情、长名称和状态色；保留来源、实体数量、关联与导出范围 |
| 工时定额校准 `calib` | 去掉大套框，明确校准明细，表格/搜索/按钮对齐；采纳说明与实际样例行为一致 |
| 执行排产 `run` | 规则与检查同排对应，36px 分段/修补按钮，保留组内细线；缺字段继续阻止提交 |
| 选择方案 `analysis` | 重点数值语义色、结论/采用动作分组、比较表字号；保留候选、采用和基线逻辑 |
| 交付风险 `delay` | 交付证据与动作层级、真实延误色；未记录原因继续明确披露 |
| 计划甘特 `gantt` | 工具栏、详情与对话框字号/对齐；时间比例、相邻边界与真实冲突分轨不变 |
| 独立试调样板 | 同步工具栏、标签行盒、详情、表格和弹窗规范；保留准确条长、两行标签、基线与采用 |
| 现场记录 `field` | 录入和记录工作区、按钮/字段对齐、状态文字；报工与导入模型不变 |
| 现场实际甘特 `fieldgantt` | 工具栏分组、选择/详情、字号与条目状态；计划/实际/剩余安排与时间几何不变 |
| 执行复盘 `review` | 列表前置，短口径就近显示，更多条件原地收展，图表后置；往返状态保留 |
| 报表中心 `reports` | 整理首屏而非仅调间距，五专题和全范围导出保留；更多条件收起后仍显示实际值 |
| 值班台 `dashboard` | 待办、详情、处理动作层级和语义色；用户文案自然中文，来源隔离与 120% 工时判定不变 |
| 系统管理 `system` | 本机维护结构，四页签，配置标签与控件靠近，草稿/即时偏好/未知状态分开；保留备份/日志/导出功能 |

基础资料主线的圆角分组例外来源：`.codestable/features/2026-09-07-workbench-radius-system/workbench-radius-system-design.md:17,36`。本轮不把该例外推广到普通列表和内容面。
