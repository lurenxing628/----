## 最新工具栏调整
用户在比较全套页面的操作区习惯后，批准以下布局，替代本记录前一轮的工具栏分组；底部计划截止标记方案不变。

- 主操作行：左侧视图切换、搜索、结果数量；右侧仅延后、导出。图表工具行：左侧三类图例及关键链开关/未接入状态；右侧完整的缩放、刻度、适应全部、定位选中组。图例不再独占第三排。
- `FieldGanttScreen.jsx` 调整 DOM 分组和顺序；`field-gantt.css` 让两行右侧操作区右对齐，缩放/刻度与适应/定位分别作为不可挤压的子组，窄宽度按组排列，不缩小文字。定位未选中时使用现有弱化样式。`index.html` 更新该 JSX 与 CSS 的缓存版本。
- 本次没有修改 `FieldGanttRows.jsx`、截止端帽、数据模型、缩放实现、关键链选择函数或其他页面样式。目录内 `tests/field-gantt-toolbar-deadline.cjs` 和根目录 `tests/workbench-workspace-surfaces.cjs` 更新为新分组合同。
- 本次通过：工具栏/截止点 4940 项、hover/定位 216 项、工作区 257 项、当前报工宿主 502 项、复杂/密集宿主 492 项、浅深色样式 1150 项；1 份 JSX、1 份 CSS 语法及 62 个本地资源检查通过。
- 验证仍为本地 DOM/CSS 和交互合同，不是浏览器截图或布局像素验收。未跑整仓门禁，不提供 clean proof；未提交/暂存，未自动刷新用户页面，保留已有工作区改动及 200 行既有暂存。

## 根因与批准范围
- 用户截图指出工具栏统计悬在中间、操作换到下一行。原 `FieldGanttScreen.jsx` 将视图、缩放、搜索、统计和操作放入同一 flex-wrap 容器，统计同时有 `margin-left:auto`，没有稳定的功能行。
- 原 `field-gantt.css` 的 `.fg-ref` 为实际条中心附近的 52px 长虚线，层级 1，实际条层级 2/hover 4，截止时间落在实际区间时会被遮住；且 `pointer-events:none` 无法查看详情。
- 用户批准固定两行工具栏、独立底部参考带及中性灰截止端帽。只修现场甘特，不改数据、缩放、关键链选择或其他页面。

## 实际修改
- `前端设计/ui_kits/workbench/FieldGanttScreen.jsx:228`：视图控制和数据筛选拆成两个语义组；刻度在第一行右侧，搜索/统计在第二行左侧，筛选/导出在右侧。截止点共用原计划 tooltip 数据，显示包含年份的完整计划完工时间。
- `FieldGanttRows.jsx:85`：计划或实际轨道保留 24px 底部参考带；每个实际资源轨道显示原计划截止点，原计划基线仍只归属原计划资源，不因换人换机复制基线。标记支持鼠标、键盘聚焦、Escape 和已有工序链预览。
- `field-gantt.css:10/114`：固定工具栏分区和 32px 控件外高，继续使用已有圆角/配色 token；窄宽度按组排列。实际条上移腾出参考带，常规最小行高 80px；截止标记为 16px 高的 2px 中性灰竖线及 8px 横臂，位于参考带，不穿过报工文字。竖线中心保持原计划结束时间坐标，不人为横移时间。
- `index.html` 更新上述两个 JSX 和 CSS 的缓存版本。新增目录内 `tests/field-gantt-toolbar-deadline.cjs`；更新原 `field-gantt.integration.cjs` 和根目录 `tests/field-gantt-plan-a.cjs` 的截止点合同。
