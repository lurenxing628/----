# 并行接合进度

## 本批方式

按用户要求分块交回、分块接合，缺陷交给新的独立修改代理；不等全部页面完成或全仓审查结束后才推进下一页。主代理统一路由、入口、构建和真实浏览器联调。未接入模块仍明确不可用，不以样例冒充生产读取。

## 接合约束

- 新增 `pending_live` 只容纳明确列名的未发布脚本，不自动扫描追加。未知、重复、交叉及非法路径仍使构建失败。交回模块才移入显式加载顺序。
- 浏览器入口以 `history.state.workbench` 保留只读导航范围；不将写入 token 放进 URL，不擅自切换为最新计划。
- 导入绑定原始字节、完整事实快照和原预览；确认在同一事务中重新检查。详情导入只允许原零件永久引用。
- 导出区分全部、全部筛选结果和明确选中项；详情读取快照不能冒充列表快照，下载不能换预检格式或范围。
- 现有用户实例与此前冻结测试证据不修改。新集成实例只使用 `migration_pages_live_server.py` 创建的临时库和隔离文件目录。
