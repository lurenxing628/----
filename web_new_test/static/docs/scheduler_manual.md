# 系统使用说明

最后更新：2026年5月

这份说明书是给计划调度员、工艺员和现场管理人员看的。你可以把它当成一套从空库开始建资料、导入表格、补工序、模拟排产、正式排产、看甘特图、导出周计划、查报表和回看历史的操作手册。

这份说明只按现在页面上能看到的入口和现在下载到的 Excel 模板来写。页面上旧入口统一叫 **批量维护**；如果你在老资料里看到“某某 Excel 导入导出”这类叫法，按现在页面上的“批量维护”理解就行。

页面上的 **本页说明** 按钮可以这样理解：

- **什么时候出现**：当前页面已经登记页面级帮助时才会出现；正在看说明书页面本身，或页面还没有登记帮助时，可能不出现。
- **点开后看什么**：只打开当前页面的速览卡片，适合边操作边查重点；这本整本说明书适合从头通读完整流程。
- **绝不会改什么**：本页说明只打开操作说明，不会保存、删除、导入、备份、恢复或修改任何业务数据。

页面右上角有两个全局显示设置：**护眼模式** 用来切换亮色/暗色主题，**表格密度** 用来切换标准、紧凑、宽松三档。它们只影响你当前浏览器里的显示习惯，不改变排产数据。

所有列表页表格的列宽都可以拖拽调整。把鼠标放到表格表头的右边缘，光标变成左右箭头后拖动就能改列宽；双击表头右边缘会自动适应内容宽度。调整后的列宽会记住，下次打开页面还是你调过的宽度；如果想恢复默认列宽，表格右上角有重置按钮。

## 0. 先说清楚：第一次正式排产怎么走

从一个空库做到第一次正式排产，推荐按这个顺序来：

如果这是正式库，不是练习库，先去 **系统管理 → 备份/恢复** 做一次手动备份。后面导入、清空重导和正式排产都会改数据，先备份能让你出错时有路可退。

1. 先进 **工艺管理 → 工种配置**，把会出现在路线文字里的工种建好，比如 `数铣`、`钳`、`数车`、`标印`。
2. 如果有外协工序，进 **工艺管理 → 供应商配置**，给外协工种配启用状态的供应商和默认周期。
3. 进 **工艺管理 → 零件工艺模板**，用路线文字建零件和工序清单。例子：图号 `P1001`，路线文字填 `5数铣10钳20数车35标印`。
4. 给自制工序补工时：可以在零件详情里逐条填，也可以通过零件工序工时模板批量维护。
5. 先进 **人员管理 → 班组管理** 建需要的班组；如果人员和设备暂时都不填班组，可以先跳过。再进 **人员管理 → 人员管理** 建人员，人员状态填 **在岗** 或 **停用**；最后进 **设备管理 → 设备管理** 建设备，设备状态填 **可用**、**维修** 或 **停用**。如果人员或设备要填写班组，必须选择已经存在的班组。
6. 建人员设备关系。例子：工号 `OP001` 能操作设备 `M001`，技能等级填 `熟练`，主操设备填 `是`；同一个人员只能有 1 台主操设备。
7. 进 **工作日历配置**，按需要维护工作日、假期、加班和调休。没有特殊日期时，系统默认周一到周五 8 小时、周六周日不排；法定假期、调休和周末加班要自己在工作日历里维护。
8. 进 **批次管理**，新增或批量维护批次。例子：`B001 / P1001 / 50 / 2026-05-20 / 急件 / 齐套`。
9. 打开批次详情，检查每道自制工序是否已有设备、人员、换型时间、单件工时；外协工序是否已有供应商和周期。
10. 进 **排产调度 → 排产调度**，确认状态筛选是 **待排**，勾选要排的批次，再先做一次 **模拟排产（插单模拟）**。模拟会生成一个可查看版本，但不会把批次状态改成正式已排。
11. 去 **设备甘特图 / 人员甘特图**、**周计划导出**、**资源排班**、**排产优化分析** 看结果是否合理。
12. 确认没问题后，回 **排产调度 → 排产调度**，重新确认状态筛选是 **待排**，重新勾选要正式排产的批次，再点 **执行排产**。模拟排产后网页不会记住上一次表单里的临时勾选，所以正式排产前一定要重新勾选。
13. 正式排完后，去 **报表中心** 看超期、资源负荷、停机影响。正式排产和模拟排产成功后都会自动保存版本。**系统管理 → 排产历史** 只看版本摘要、提醒和结果概况；你可以按版本号筛选，也可以选择查看最近 10 条、50 条这类记录。这里不能导出，也不能把某个版本恢复成当前数据。

### 首页统计卡怎么看

首页上方 4 个数字不是让你在首页直接改数据，而是帮你判断下一步去哪：

- **待排批次**
  - 代表：还没有正式排进计划里的批次数。这个数字多，说明还有批次等着排。
  - 下一步：先去 **批次管理** 检查批次资料，再去 **执行排产** 做模拟排产或正式排产。

- **已排批次**
  - 代表：正式执行排产后，批次状态已经变成已排的批次数。它不等于现场已经生产完成；模拟排产会留下版本记录，但不会把这里的批次状态改成已排。
  - 下一步：去 **甘特图** 看排在哪天、哪台设备；去 **周计划** 导出给现场；去 **资源排班** 看人员和设备任务。

- **超期批次**
  - 代表：最近一次排产结果里，被系统判断会晚于交期的批次数。它主要提醒你最近这版有没有交期风险，不是所有历史版本累计。
  - 下一步：去 **报表中心 → 超期清单** 看具体哪些批次超期，再去 **排产优化分析** 和 **甘特图** 查原因。

- **最近排产版本**
  - 代表：最近一次模拟排产或正式排产保存下来的版本号，比如 `v3`。显示 `--` 表示还没有可看的排产历史。
  - 下一步：有版本时，去甘特图、周计划、资源排班或排产历史按这个版本查看；没有版本时，先去执行排产做一次模拟排产。

首页中间还有 **最近排产** 区域，显示最后一次排产的关键信息：

- **排产时间**：上一次排产是什么时候做的。
- **排产方式**：首页和排产历史会显示 7 种排产方式名称，它们不是同一个下拉框里的选项，而是由多个配置维度组合出来的显示口径：

  | 排产方式 | 什么意思 | 实际来自哪个配置 |
  |---|---|---|
  | 优先级优先 | 先排急件和特急件 | 高级设置 → 排产策略 |
  | 交期优先 | 先排交期最近的 | 高级设置 → 排产策略 |
  | 综合优先级和交期 | 同时考虑优先级和交期 | 高级设置 → 排产策略 |
  | 先进先出 | 按批次创建的先后顺序排 | 高级设置 → 排产策略 |
  | 优化排产 | 系统用精细计算多试几种排法 | 高级设置 → 计算模式选"精细计算" |
  | 快速排产 | 系统用快速计算尽快出结果 | 高级设置 → 计算模式选"快速计算" |
  | 手动排产 | 由人工指定排产参数的组合 | 不对应单一下拉选项，由多个参数组合 |

  也就是说，高级设置页面上你要看两个地方：**排产策略**（4 个选项：优先级优先、交期优先、综合优先级和交期、先进先出）和**计算模式**（2 个选项：快速计算、精细计算）。首页显示的"排产方式"是这两个维度合起来的结果标签，不是让你在一个下拉框里选 7 个。

- **结果状态**：常见的有成功、部分成功、失败、模拟排产。成功表示排产正常完成；部分成功表示有部分工序没排进去，需要检查；失败表示没有生成可用结果；模拟排产表示这版只是试排，没有正式推进批次状态。
- **算法指标**（有记录时才显示）：拖期小时数（越少越好）、总工期小时数（越短表示整体更快）、设备利用率（设备忙碌程度的百分比）。

没有排产记录时，这里会提示"还没有排产记录，排产后这里会显示结果"。

首页下方的 **常用工作区** 是快捷入口，分三组：

| 分组 | 常用入口 | 适合做什么 |
|---|---|---|
| 排产作业 | 执行排产、批次管理、设备甘特图、资源排班 | 日常排产、查看任务安排 |
| 基础资料 | 工艺模板、设备管理、人员管理、工作日历 | 排产前补资料 |
| 分析复盘 | 报表中心、周计划、排产历史 | 排完后查风险、导计划、看历史 |

页面左侧或顶部会有 **全局导航**，常用入口包括首页、排产、工艺、人员、设备、物料、报表、系统。不管你在哪个页面，都可以通过全局导航快速跳到其他模块，不用每次都回首页。

## 1. Excel 批量维护：表格怎么填

系统很多页面都有 **批量维护** 卡片。基本流程都是：

1. 点 **下载模板**。
2. 按模板第一张工作表填写，表头不要改。
3. 选择写入方式。
4. 点 **上传 Excel 并检查**，看每一行是新增、更新、无变化、跳过还是错误。
5. 没有错误行后，点 **确认写入系统**。
6. 写入后可以再点导出，拿导出的表和你原表对一下。

单个上传文件最大 16MB，只读取第一个工作表。固定选项字段请填写中文值，新文件请填中文，比如 `启用`、`停用`、`自制`、`外协`、`普通`、`急件`、`特急`、`齐套`、`未齐套`、`部分齐套`。

几个高风险点要单独记住：

- **确认写入会怎样**：点 **确认写入系统** 后，系统才会真正改数据库。页面会再次按当前系统数据判断一遍，不是把上传预览无条件照抄进去。
- **部分完成怎么办**：有些批量处理会出现“部分完成”。这表示成功的行已经写入，失败的行会单独提示原因。不要重复整表乱导，先按页面提示处理失败行，再下载或导出当前数据核对一次。
- **操作记录怎么看**：批量维护、备份、恢复、排产执行、周计划导出这类正式业务操作通常会写进 **系统管理 → 操作日志**；部分报表导出可能只是直接下载文件，不一定都有操作日志。日志能帮你知道“什么时候做过这类操作”，但不能代替备份；重要数据变更前仍建议先手动备份。
- **确认弹窗先看什么**：恢复备份、删除批次/设备/人员/物料/备份/日志/方案、批量删除、刷新批次工序、模拟排产、保存为方案、删除方案、恢复默认设置这些高风险操作都会弹窗让你二次确认。不是所有保存、上传、查询或导出都会弹窗；看到弹窗时，先看清它说的是要影响哪些数据，再点确认。

### 1.0 Excel 模板总表

第一次准备排产资料时，不要一上来只导批次。批次只是“这次要做什么”，还需要前面的工艺、人员、设备、日历这些资料一起支撑，系统才知道“谁、用哪台设备、在哪天、做多久”。

| 模板 | 主要给谁填 | 解决什么问题 | 建议顺序 | 入口 | 完成标志 |
|---|---|---|---:|---|---|
| 工种配置 | 工艺员 | 先告诉系统有哪些工种，比如数铣、钳、标印 | 1 | 工艺管理 → 工种配置 → 批量维护 | 工种列表里能看到要用的工种，名称和路线文字一致 |
| 供应商配置 | 工艺员或计划员 | 外协工序要交给谁、默认几天回来 | 2 | 工艺管理 → 供应商配置 → 批量维护 | 启用供应商能匹配外协工种，默认周期大于 0 |
| 零件工艺路线 | 工艺员 | 每个图号有哪些工序，路线文字怎么拆 | 3 | 工艺管理 → 零件工艺模板 → 批量维护路线文字 | 零件详情里能看到路线拆出来的工序 |
| 零件工序工时 | 工艺员 | 自制工序换型多久、单件做多久；空工时按 0 小时处理 | 4 | 工艺管理 → 零件工艺模板 → 批量维护工序工时 | 自制工序已有换型时间和单件工时 |
| 人员基本信息 | 计划员或班组长 | 哪些人能参与排产、属于哪个班组 | 5 | 人员管理 → 人员管理 → 批量维护 | 在岗人员列表里能看到要排产的人 |
| 设备信息 | 计划员或设备管理员 | 哪些设备能用、能做什么工种 | 6 | 设备管理 → 设备管理 → 批量维护 | 可用设备列表里能看到要排产的设备和工种 |
| 人员设备关联 | 计划员或班组长 | 某个人能操作哪台设备，谁是主操 | 7 | 人员管理 → 人员详情 → 可操作设备；或设备管理 → 设备详情 → 可操作人员 | 批次详情里的自制工序能选到设备和人员 |
| 工作日历 | 计划员 | 哪些日期能排产，日历类型空着按工作日理解 | 8 | 排产调度 → 工作日历配置 → 批量维护 | 工作日、假期、可用工时和效率能在日历页看到 |
| 个人工作日历 | 计划员或班组长 | 某个人请假、加班、临时只排急件 | 9 | 人员管理 → 人员管理 → 批量维护 → 批量维护个人日历 | 有请假或加班的人能看到自己的单独日历；没有特殊安排可以不填 |
| 批次信息 | 计划员 | 本次要生产哪些批次、数量、交期、齐套状态 | 10 | 排产调度 → 批次管理 → 批量维护 | 批次列表能看到新批次，批次详情里已生成工序 |

填写时有一个总原则：模板里已有的表头不要改，系统靠这些列名认数据；你只改数据行。编号类字段建议先把 Excel 单元格设成文本，避免 `001` 被 Excel 自动变成 `1`。

### 1.1 批量维护写入方式

| 写入方式 | 大白话解释 | 适合什么时候用 |
|---|---|---|
| 更新已有，新增缺少 | 编号已存在就改，编号不存在就新增 | 最常用 |
| 只导入新编号 | 编号已存在的跳过，只补新数据 | 怕误改旧数据 |
| 清空本类数据后重导 | 先删掉这一类旧数据，再按表重建 | 只适合你确认要整批重做时 |
| 更新已有工时 | 只更新已有自制工序的工时 | 零件工序工时专用 |
| 只补空工时 | 已有工时不动，只补空的 | 零件工序工时专用 |

清空重导要非常谨慎。批次被清空时，批次下面的工序和排程记录也会跟着没了；如果不是非常确定，优先用“更新已有，新增缺少”。

上传检查、确认写入、清空重导和失败排查按这个顺序处理：

1. 先点 **上传 Excel 并检查**。这一步只是检查和预览，不等于已经写入系统。
2. 看检查结果。`新增` 表示系统里没有这条；`更新` 表示会改已有数据；`跳过` 表示当前写入方式不处理；`错误` 表示这一行不能写入。
3. 有错误时，不要点确认写入。先按页面提示改 Excel，比如补必填项、改日期、改不存在的图号或工种，再重新上传检查。
4. 没有错误后，再点 **确认写入系统**。只有到这一步，数据才真正进入系统。
5. 如果选择 **清空本类数据后重导**，要先确认你确实要用这份 Excel 重建这一类数据。清空后，旧数据和相关明细可能一起没了，不能把它当成普通更新用。
6. 确认写入后如果发现填错，优先下载当前模板或导出当前数据，改好后再按“更新已有，新增缺少”重新导入；只有整批数据都要推倒重来时，才考虑清空重导。

如果选了 **清空本类数据后重导**，检查预览里的 `无变化` 也不能理解成“确认写入时完全不动旧数据”。这个模式在确认写入时会先清掉这一类旧数据，再按 Excel 文件重建，所以一定要先备份、再确认整张表就是你想保留的最终数据。

#### 1.1.1 “资料不完整就停下”怎么理解

这个开关在不同页面会有不同名字，但意思是同一个：遇到资料不完整或关键参数有问题时，要不要先停下让你补资料。你只要看页面上的文字：通用批量维护常叫 **资料不完整就停下**，路线文字和批次 Excel 常叫 **发现问题就停下**，执行排产面板叫 **发现参数问题就停止排产**。它不是让系统排得更快，也不是自动修数据，而是决定遇到不完整资料或关键参数问题时要不要马上停住。

| 开关状态 | 会发生什么 | 适合什么时候 |
|---|---|---|
| 勾选 | 遇到缺工种、缺供应商或外协周期不正确这类问题，系统会直接停下并告诉你哪里要补。 | 正式导入、正式排产前，希望资料一次补齐 |
| 不勾选 | 系统会尽量处理能确认的数据；能临时用默认值的地方可能先继续，比如外协周期先按 1 天提醒你后续补正。 | 先跑通流程，后续再细调 |

路线文字和批次 Excel 主要检查资料完整性；执行排产页主要检查排产参数和排产输入。批次号、图号、数量、日期这类基础字段有硬错误时，不管开不开这个开关，都要先改对。

### 1.2 日期、时间和数字怎么填

| 内容 | 推荐写法 | 说明 |
|---|---|---|
| 日期 | `2026-05-20` 或 `2026/05/20` | 批次交期、齐套日期、日历日期都按这个写 |
| 时间 | `08:00` 或 `08:00:00` | 班次开始、班次结束用这个写 |
| 小数 | `0.5`、`1.25`、`8` | 工时、效率、周期都可以是小数 |
| 是/否 | `是`、`否` | 不建议填 TRUE/FALSE |
| 编号 | 先把单元格设成文本 | 防止 `001` 被 Excel 变成 `1` |

数值字段最容易因为复制粘贴出错，按下面几条检查更稳：

- 不要填 `TRUE`/`FALSE` 这类是非值。
- 不要填 `NaN`、`Inf`、`Infinity` 这类不是正常数字的内容。
- 工序号不要用科学计数法，比如不要写 `5e0` 或 `1E2`；建议按普通整数写，比如 `5`、`10`。
- 模板表头要按下载文件原样保留，不要改名、删列、合并表头或把有效数据放到第二张工作表。

不要在文本日期里带时间，也不要填 Excel 序列号。公式、合并单元格、空表头都容易导致系统读不到值。

### 1.5 常见检查结果怎么看

| 检查结果 | 意思 | 你要做什么 |
|---|---|---|
| 新增 | 系统里还没有这条编号 | 确认没填错就能写入 |
| 更新 | 系统里已有这条编号 | 确认这次就是要改它 |
| 无变化 | 表里和系统里一样 | 不用处理 |
| 跳过 | 当前写入方式不处理这一行 | 看是否符合你的预期 |
| 错误 | 这一行不能写入 | 改 Excel 后重新上传检查 |

只要还有错误行，就不要硬继续。页面会告诉你哪一列有问题，比如“数量必须大于 0”“图号不存在”“日期格式不正确”。

举几个常见例子：

| 场景 | 检查结果 | 为什么会这样 | 你该怎么处理 |
|---|---|---|---|
| 设备表里填了新设备 `M003` | 新增 | 系统里还没有 `M003` | 确认设备编号、工种、状态正确后确认写入 |
| 人员表里已有 `OP001`，这次改了姓名或班组 | 更新 | 编号相同，内容有变化 | 确认这次确实要改旧资料后确认写入 |
| 批次表里 `B001` 和系统里完全一样 | 无变化 | 数据没有变化 | 不用处理，可以直接忽略 |
| 写入方式选“只导入新编号”，表里又有已存在的 `B001` | 跳过 | 你选的方式就是不改旧编号 | 如果想改 `B001`，把写入方式改成“更新已有，新增缺少”后重新检查 |
| 批次表里图号填 `P999`，但系统没有这个图号 | 错误 | 批次引用了不存在的零件 | 先导入或新建 `P999`，或者把批次图号改成正确值，再重新上传检查 |

确认写入也按检查结果来判断：

提醒：上面这张表是按普通更新理解的。如果你这次选的是 **清空本类数据后重导**，即使检查阶段看到某些行是 `无变化`，确认写入时仍会先清旧数据再重建，不要把它当成“完全不会动旧数据”。

1. 如果检查结果是 `2 条新增、1 条更新、0 条错误`，并且这些新增和更新都是你想要的，就可以点 **确认写入系统**。
2. 如果检查结果里有 `错误`，不要点确认写入。先改 Excel，再重新点 **上传 Excel 并检查**。
3. 如果检查结果里有 `跳过`，先看它是不是你故意选出来的结果。比如“只导入新编号”导致旧编号跳过是正常的；如果你本来想更新旧编号，就要换写入方式。
4. 点 **确认写入系统** 后，才算真的保存。只上传检查、不确认写入，系统数据不会变。

### 1.6 逐模板填写指南

#### 1.6.1 工种配置

**进入方式**：工艺管理 → 工种配置 → 批量维护。

| 列名 | 必填 | 能填什么 | 会报错的情况 |
|---|---|---|---|
| 工种编号 | 是 | 自己定编号，比如 `OT001` | 为空、重复 |
| 工种名称 | 是 | 路线文字里会用到的名字，比如 `数铣`、`钳`、`数车`、`标印` | 为空、重复或不符合页面校验 |
| 归属 | 否 | 推荐填 `自制` 或 `外协`；新文件请只填这两个中文值；不填按自制处理 | 填了系统不认识的词 |

工种名称要和路线文字里的文字一致。你准备写 `5数铣10钳20数车35标印`，就要有 `数铣`、`钳`、`数车`、`标印` 这些工种。

旧模板中已有数据行不会被系统擅自改写；也就是说，如果旧文件里已经有“内部/外部”这类旧写法，系统刷新模板时会优先保住你的原始数据。新填数据请使用 `自制`/`外协`，旧值导入时会尽量兼容识别。

#### 1.6.2 供应商配置

**进入方式**：工艺管理 → 供应商配置 → 批量维护。

| 列名 | 必填 | 能填什么 | 会报错的情况 |
|---|---|---|---|
| 供应商编号 | 是 | 自己定编号，比如 `S001` | 为空、重复 |
| 名称 | 是 | 供应商名称 | 为空 |
| 对应工种 | 否 | 工种编号或工种名称 | 填了不存在的工种 |
| 默认周期 | 是 | `默认周期` 必填，必须是大于 0 的有限数字天数，比如 `3`、`1.5` | 空、0、负数、`TRUE`/`FALSE`、`NaN`、`Inf`、`Infinity`、文字 |
| 状态 | 否 | `启用`/`停用`；旧文件里的 `在用`/`正常`/`禁用` 也能识别；新文件建议填 `启用` 或 `停用` | 填了系统不认识的词 |
| 备注 | 否 | 随便写 | 一般不报错 |

路线文字里遇到外协工种时，系统只会拿启用的供应商来配。没有可用供应商时，勾选“发现问题就停下”会直接报错；不勾选时，系统会先按 1 天提醒你后续补正。

清空重导供应商要特别谨慎。如果供应商已经被零件工序或批次工序引用，系统可能会拒绝清空重导；因为清空供应商会让已经存在的外协工序找不到原来的供应商。

#### 1.6.3 零件工艺路线（重点：工艺路线字符串怎么写）

**进入方式**：工艺管理 → 零件工艺模板 → 批量维护路线文字。

| 列名 | 必填 | 能填什么 | 会报错的情况 |
|---|---|---|---|
| 图号 | 是 | 零件图号，比如 `P1001` | 为空、重复或清空重导时已有批次引用 |
| 名称 | 是 | 零件名称 | 为空 |
| 工艺路线字符串 | 是 | 工序号加工种名连着写 | 空、不是以工序号开头、尾部只有数字 |

路线文字推荐这样写：

```text
5数铣10钳20数车35标印
```

这句话表示：

| 工序号 | 工种 |
|---|---|
| 5 | 数铣 |
| 10 | 钳 |
| 20 | 数车 |
| 35 | 标印 |

写路线文字时注意：

- 必须以数字开头。
- 每个数字后面必须跟工种名。
- 可以不加分隔符，也可以加空格、逗号、顿号、箭头。
- 全角数字会转成半角数字。
- 工种没提前配置时，勾选严格检查会报错；不勾选时，系统会给出提醒并尽量生成可确认的工序。
- 零件工艺路线的清空重导有额外限制：只要系统里已经存在批次，清空重导通常会被拒绝。因为批次会引用零件和工序，清空零件路线会让批次工序断链。

#### 1.6.4 零件工序工时

**进入方式**：工艺管理 → 零件工艺模板 → 批量维护工序工时。

| 列名 | 必填 | 能填什么 | 会报错的情况 |
|---|---|---|---|
| 图号 | 是 | 已存在的图号，比如 `P1001` | 图号不存在 |
| 工序 | 是 | 已存在的正整数工序号，比如 `5` | 工序不存在、0、负数、小数、`TRUE`/`FALSE`、`5e0`/`1E2` 这类科学计数法文本 |
| 换型时间(h) | 否 | 大于等于 0 的有限数字小时数；空着按 `0` 小时 | 负数、`TRUE`/`FALSE`、`NaN`、`Inf`、`Infinity`、文字 |
| 单件工时(h) | 否 | 大于等于 0 的有限数字小时数；空着按 `0` 小时 | 负数、`TRUE`/`FALSE`、`NaN`、`Inf`、`Infinity`、文字 |

换型时间是这道工序开始前准备设备、夹具、刀具的时间。单件工时是做 1 件产品要花的时间。批次数量越大，单件工时占比越大。

更直白地说：工时空着，系统就当它是 `0` 小时。这样做的好处是你可以先把路线搭起来；坏处是正式排产结果会偏短。比如某道工序换型时间填 `0.5` 小时，单件工时填 `0.2` 小时，批次数量是 `50`，这道工序预计用时就是 `0.5 + 0.2 × 50 = 10.5` 小时。如果换型和单件都空着，系统就按 `0 + 0 × 50 = 0` 小时算，现场当然不可能真的不花时间，所以正式排产前要补真实工时。

#### 1.6.5 人员基本信息

**进入方式**：人员管理 → 人员管理 → 批量维护。

| 列名 | 必填 | 能填什么 | 会报错的情况 |
|---|---|---|---|
| 工号 | 是 | 员工编号，比如 `OP001` | 为空、重复 |
| 姓名 | 是 | 员工姓名 | 为空 |
| 状态 | 是 | 新文件建议填 `在岗` 或 `停用`；模板下拉推荐值是 `在岗/停用`；旧文件里的 `启用`、`可用`、`正常`、`休假`、`离岗` 也能兼容读取 | 空、填了系统不认识的词 |
| 班组 | 否 | 班组编号或班组名称 | 填了不存在的班组 |
| 备注 | 否 | 随便写 | 一般不报错 |

如果要在人员 Excel 里填班组，要先到 **人员管理 → 班组管理** 建好班组；否则导入会提示班组不存在。

人员不想参与排产时，Excel 新模板推荐填 `停用`，不要急着删除。页面上的人员状态下拉和列表显示会把不可参与排产的状态显示成 **停用/休假**；这是页面显示口径，不代表 Excel 新模板要写 `停用/休假`。`休假`、`离岗` 这类旧写法只是为了读懂老文件，新文件按模板下拉推荐写 `在岗` 或 `停用`。删除被历史排程引用的人员可能会被拒绝。

#### 1.6.6 设备信息

**进入方式**：设备管理 → 设备管理 → 批量维护。

| 列名 | 必填 | 能填什么 | 会报错的情况 |
|---|---|---|---|
| 设备编号 | 是 | 设备编号，比如 `M001` | 为空、重复 |
| 设备名称 | 是 | 设备名称 | 为空 |
| 工种 | 否 | 设备能干的工种 | 工种不存在时会提示 |
| 班组 | 否 | 班组编号或班组名称 | 填了不存在的班组 |
| 状态 | 是 | 新文件建议填 `可用`、`停用`、`维修`；模板下拉推荐值是 `可用/停用/维修`；旧文件里的 `启用`、`正常`、`禁用`、`不可用`、`维护`、`维护中`、`维修中`、`保养` 也能兼容读取 | 空、填了系统不认识的词 |

设备 Excel 真实模板只有这 5 列：设备编号、设备名称、工种、班组、状态。这个模板里没有“类别”列，也没有“备注”列。设备类别要在设备页面手工新增或打开设备详情维护，不要往设备 Excel 模板里自己加“类别”或“备注”。

如果要在设备 Excel 里填班组，要先到 **人员管理 → 班组管理** 建好班组；否则导入会提示班组不存在。

设备临时不能用时，建议建停机计划或改成维修；长期不用再停用。旧状态写法只是为了读懂老文件，新文件按模板下拉推荐写 `可用`、`停用` 或 `维修`。

#### 1.6.7 人员设备关联

**进入方式**：人员管理 → 人员详情 → 可操作设备，或设备管理 → 设备详情 → 可操作人员；批量时在对应页面的批量维护里处理。

人员设备关联和设备人员关联维护的是同一类关系，但下载模板的列顺序不同：

| 入口 | 模板列顺序 | 怎么理解 |
|---|---|---|
| 人员管理侧 | 工号、设备编号、技能等级、主操设备 | 从“这个人能操作哪些设备”出发 |
| 设备管理侧 | 设备编号、工号、技能等级、主操设备 | 从“这台设备有哪些人能操作”出发 |

填数据时按你下载到的模板表头来填，不要把两张表的前两列顺序混用。

| 列名 | 必填 | 能填什么 | 会报错的情况 |
|---|---|---|---|
| 工号 | 是 | 已存在的人员工号，比如 `OP001` | 人员不存在 |
| 设备编号 | 是 | 已存在的设备编号，比如 `M001` | 设备不存在 |
| 技能等级 | 否 | 新文件建议填 `初级`、`普通`、`熟练`；旧文件里的 `新手`、`一般`、`中级`、`高级`、`专家` 也能兼容读取 | 填了系统不认识的词 |
| 主操设备 | 否 | 新文件建议填 `是` 或 `否`；旧文件里的 `主操`、`非主操`、`主`、`非主`、`1`、`0` 也能兼容读取 | 同一人员设多台主操时会被校验 |

> **技能等级说明**：新文件建议直接填中文：初级、普通、熟练。旧文件里如果写过旧叫法，系统会尽量换成现在的中文值。你日常只管看中文，不需要记系统内部怎么存。

真实例子：

| 工号 | 设备编号 | 技能等级 | 主操设备 |
|---|---|---|---|
| OP001 | M001 | 熟练 | 是 |
| OP001 | M002 | 普通 | 否 |
| OP002 | M001 | 初级 | 否 |

排产时，自制工序的设备和人员下拉框会受这个关系限制。某道工序下拉没有人或没有设备时，先回这里补关系。

#### 1.6.8 工作日历

**进入方式**：排产调度 → 工作日历配置 → 批量维护。

| 列名 | 必填 | 能填什么 | 会报错的情况 |
|---|---|---|---|
| 日期 | 是 | `2026-05-20` | 空、格式不对 |
| 类型 | 否 | 新文件建议填 `工作日` 或 `假期`；模板下拉推荐值是 `工作日/假期`；空着按 `工作日`；旧文件里的 `周末`、`节假日` 也会按假期处理 | 填了系统不认识的词 |
| 可用工时 | 否 | 大于等于 0 的有限数字小时数 | 负数、`TRUE`/`FALSE`、`NaN`、`Inf`、`Infinity`、文字 |
| 效率 | 否 | 大于 0 的有限数字 | 0、负数、`TRUE`/`FALSE`、`NaN`、`Inf`、`Infinity`、文字 |
| 允许普通件 | 否 | 新文件建议填 `是` 或 `否`；模板下拉推荐值是 `是/否`；旧文件里的 `1/0` 也能兼容读取；不填默认是 | 填了系统不认识的词 |
| 允许急件 | 否 | 新文件建议填 `是` 或 `否`；模板下拉推荐值是 `是/否`；旧文件里的 `1/0` 也能兼容读取；不填默认是 | 填了系统不认识的词 |
| 说明 | 否 | 备注说明 | 一般不报错 |

默认口径：

- 工作日不填可用工时，按 8 小时。
- 假期不填可用工时，按 0 小时。
- 工作日不填效率，按 1.0。
- 假期不填默认高级设置中的“假期工作效率”，也就是假期没单独填效率时用的默认值。
- 类型空着时按 `工作日` 算。
- 常用选项是 `工作日`、`假期`；如果旧文件里手填 `周末` 或 `节假日`，系统也按假期算。新文件按模板下拉推荐写，不要再故意写旧叫法。

#### 1.6.9 个人工作日历

**进入方式**：人员管理 → 人员详情 → 个人工作日历，也可从批量维护进入。

个人工作日历比全局工作日历更细，适合请假、个人加班、临时借调。

| 列名 | 必填 | 能填什么 | 会报错的情况 |
|---|---|---|---|
| 工号 | 是 | 已存在的人员 | 空、人员不存在 |
| 日期 | 是 | `2026-05-20` | 空、格式不对 |
| 类型 | 否 | 新文件建议填 `工作日` 或 `假期`；模板下拉推荐值是 `工作日/假期`；空着按 `工作日`；旧文件里的 `周末`、`节假日` 也按假期 | 填了系统不认识的词 |
| 班次开始 | 否 | `08:00` | 时间格式不对 |
| 班次结束 | 否 | `17:00` | 时间格式不对 |
| 可用工时 | 否 | 大于等于 0 的有限数字小时数 | 负数、`TRUE`/`FALSE`、`NaN`、`Inf`、`Infinity`、文字 |
| 效率 | 否 | 大于 0 的有限数字 | 0、负数、`TRUE`/`FALSE`、`NaN`、`Inf`、`Infinity`、文字 |
| 允许普通件 | 否 | 新文件建议填 `是` 或 `否`；模板下拉推荐值是 `是/否`；旧文件里的 `1/0` 也能兼容读取；不填默认是 | 填了系统不认识的词 |
| 允许急件 | 否 | 新文件建议填 `是` 或 `否`；模板下拉推荐值是 `是/否`；旧文件里的 `1/0` 也能兼容读取；不填默认是 | 填了系统不认识的词 |
| 说明 | 否 | 备注 | 一般不报错 |

如果某个人同一天有个人日历，排产会优先按个人日历理解这一天。

#### 1.6.10 批次信息（排产核心）

**进入方式**：排产调度 → 批次管理 → 批量维护，也可以在批次管理页面手工新增。

| 列名 | 必填 | 能填什么 | 会报错的情况 |
|---|---|---|---|
| 批次号 | 是 | `B001` | 空、重复 |
| 图号 | 是 | 已存在的图号，比如 `P1001` | 图号不存在 |
| 数量 | 是 | 正整数，比如 `50` | 空、0、负数、小数、文字 |
| 交期 | 否 | `2026-05-20`；强烈建议填写。留空可以导入，但会排到后面，也不会进入超期报表 | 日期格式不对 |
| 优先级 | 否 | 新文件建议填 `普通`、`急件`、`特急`；模板下拉推荐值是 `普通/急件/特急`；旧文件里的 `急` 也能兼容读取；不填默认普通 | 填了系统不认识的词 |
| 齐套 | 否 | 新文件建议填 `齐套`、`未齐套`、`部分齐套`；模板下拉推荐值是 `齐套/未齐套/部分齐套`；旧文件里的 `是`、`否` 也能兼容读取；不填默认齐套 | 填了系统不认识的词 |
| 齐套日期 | 否 | `2026-05-18` | 日期格式不对 |
| 备注 | 否 | 随便写 | 一般不报错 |

真实例子：

| 批次号 | 图号 | 数量 | 交期 | 优先级 | 齐套 | 齐套日期 | 备注 |
|---|---|---:|---|---|---|---|---|
| B001 | P1001 | 50 | 2026-05-20 | 急件 | 齐套 |  | 第一次正式排产示例 |

这句话 `B001 / P1001 / 50 / 2026-05-20 / 急件 / 齐套` 的意思是：批次 `B001`，图号 `P1001`，数量 `50`，交期 `2026-05-20`，优先排急件，目前判断为齐套。

> **重点纠偏**：齐套日期只有在启用齐套检查时才影响排产。没启用齐套检查时，齐套状态和齐套日期主要是页面显示信息；启用后，只要所选批次里有未齐套或部分齐套，本次排产会报错并停止。系统不会自动跳过这些批次继续排其它批次；齐套日期只对齐套批次作为最早开工日。`急`、`是`、`否` 是为了兼容老文件，新批次表按模板下拉推荐写。

更新已有批次时，`齐套日期` 留空会写成空值，也就是清掉原来的齐套日期。如果想保留旧日期，不要用空白单元格覆盖这一列。

批次导入页还有两个重要开关：

- **导入后自动生成批次工序（推荐）**：确认写入时，系统会按零件工艺模板给批次生成工序。空库第一次导入批次时建议开启，这样导完批次就有批次工序，后面可以直接进批次详情补设备、人员和工时。
- **发现问题就停下（严格模式）**：开启后，按路线生成工序时，如果缺工种、缺供应商或外协周期不正确，会停止导入并告诉你哪一行、哪一项要补。不勾选时，能确认的数据会继续处理，缺少外协周期这类可补内容会先按 1 天记录并提醒你后续补正；但批次号、图号、数量这类必填项有问题仍然会报错。

导入后自动生成批次工序只处理本次真正新增或更新成功的批次；无变化、跳过、出错的行不会顺手刷新工序。

更新已有批次时，要特别小心“导入后自动生成批次工序”。只要开启它，已有批次会按当前零件模板刷新批次工序，之前在批次详情里手工补过的设备、人员、换型时间、单件工时、供应商和外协周期，都可能被新模板重新写入或清空。已经手工细调过的批次，导入前先确认这些内容可以重新补。

如果自动生成批次工序时产生提醒，当前页面确认写入后只会展示去重后的前 3 条提醒；如果还有更多提醒，页面会显示“另有 X 条提醒未在当前页显示，请处理已展示提醒后重新检查”。所以提醒很多时，先处理当前页已经展示的提醒，再重新上传检查或重新确认。

提醒去向要分清：批次自动生成工序时的模板提醒，是当前页局部提醒，不承诺一定能在排产历史里查到；正式排产或模拟排产成功后的排产结果提醒，属于某个历史版本的结果，可以到排产历史查看这次排产的详细提醒。

### 1.7 导出功能一览

常用导出有这些：

| 页面 | 导出内容 | 用途 |
|---|---|---|
| 工艺管理 → 零件工艺模板 | 路线文字、当前路线、工序清单 | 工艺员核对工艺资料 |
| 人员管理 | 人员、人员设备关系、个人日历 | 人员资料维护 |
| 设备管理 | 设备、设备人员关系 | 设备资料维护 |
| 排产调度 → 批次管理 | 批次表 | 计划员批量下发和复核 |
| 排产调度 → 周计划导出 | 当前周计划表 | 给车间看每天任务 |
| 排产调度 → 资源排班 | 当前查询的资源排班 | 查某人、某设备、某班组任务 |
| 报表中心 | 超期清单、资源负荷、停机影响 | 管理复盘 |

导出的文件名由系统自动生成，不需要你自己手动起名。排产结果类导出通常会带版本或日期，比如周计划可能是 `周计划表_v3_2026-05-04至2026-05-10.xlsx`；资源排班会按当前查询对象、日期范围和版本拼文件名；基础资料模板或当前数据导出很多是固定业务文件名。不要反过来用“文件名有没有时间/版本”判断它是不是有效数据，真正口径以页面标题、筛选条件和导出内容为准。

## 2. 从空库到第一次正式排产

### 2.1 准备一个最小可排示例

下面这个示例适合你第一次跟着做：

| 内容 | 示例 |
|---|---|
| 图号 | `P1001` |
| 路线文字 | `5数铣10钳20数车35标印` |
| 批次 | `B001` |
| 数量 | `50` |
| 交期 | `2026-05-20` |
| 优先级 | `急件` |
| 齐套 | `齐套` |

你至少要准备：

- 工种：`数铣`、`钳`、`数车`、`标印`。
- 自制设备：能做 `数铣`、`钳`、`数车` 的设备。
- 人员：能操作这些设备的人。
- 人员设备关系：比如 `OP001 / M001 / 熟练 / 是`。
- 自制工序工时：每道自制工序的换型时间和单件工时。
- 如果 `标印` 是外协：要有对应外协供应商和默认周期。

### 2.2 第一次不要先正式排

先做模拟排产。模拟排产能让你看到结果，但不污染正式批次状态。你能用它检查：

- 有没有工序没设备。
- 有没有工序没人。
- 有没有工时仍然是 0，需要工艺员补成真实工时。
- 有没有外协供应商或周期缺失。
- 交期是否明显会超。
- 甘特图上有没有排到不该排的假期。

确认后再正式排产。

## 3. 基本概念：用白话理解

| 名词 | 大白话 |
|---|---|
| 工种 | 这道活是什么类型，比如数铣、钳、标印 |
| 归属 | 自制就是厂内做，外协就是交给供应商做 |
| 零件工艺模板 | 图号和工序清单，后面建批次会照它生成工序 |
| 工序 | 一件产品生产路线上拆出来的一步活，比如先数铣、再钳、再数车 |
| 批次 | 这次要生产的一批东西 |
| 批次工序 | 这个批次真实要排的每一道工序 |
| 换型时间 | 开始做之前的准备时间 |
| 单件工时 | 做 1 件花多久 |
| 齐套 | 物料够不够开工的显示状态 |
| 外协 | 这道工序不在厂内做，交给供应商做，需要供应商和外协周期 |
| 关键工序关系 | 影响整批任务完工时间的关键任务串；其中某个任务晚了，整个批次通常也会跟着晚 |
| 齐套检查 | 一个排产开关；打开后只要所选批次里有未齐套或部分齐套，本次排产就会报错并停止；系统不会自动跳过这些批次继续排其它批次，齐套日期只对齐套批次作为最早开工日 |
| 排产版本 | 每次排产留下的结果编号，比如 v1、v2 |
| 模拟排产 | 只看结果，不改正式批次状态 |
| 正式排产 | 生成正式排程并更新批次状态 |
| 资料不完整时的提醒 | 系统遇到配置异常或数据不完整时，会先按能确认的内容继续运行，同时提醒你哪里需要补 |
| 主操 | 某个人最擅长操作的那一台设备；同一个人只能有 1 台主操设备 |
| 技能等级 | 人员对设备的熟练程度，分为初级、普通、熟练三档 |
| 停机计划 | 预先安排某台设备某段时间不可用，排产时会自动避开 |
| 冻结窗口 | 保护近期已排好的任务，重新排产时不乱动近几天的计划 |

**编号创建后通常不能直接修改**：图号、工种编号、供应商编号、设备编号、工号、班组编号、物料编号这类编号，是系统用来认数据的“身份证”。页面上一般会禁用编号输入，或者只展示不让改。如果编号确实填错，通常要删除后重新创建；已经被批次、工序、人员设备关系、物料需求或排产历史引用的编号，删除可能会失败。

**搜索和筛选要分清**：很多列表页有两类控件。一类是页面上的查询/筛选，比如状态、班组、齐套显示、日期范围，它会重新向系统查询数据；另一类是表格里的搜索框，多数只是搜索当前页已经显示出来的行，比如“输入批次号、图号”“输入工号、姓名”。如果分页很多，不要以为当前页搜索没找到就代表全库没有，先用上方筛选或翻页再确认。

**版本下拉也要按页面理解**：甘特图、周计划、资源排班、排产分析、报表和排产历史都会用到排产版本。多数下拉会显示版本号和结果状态，比如 `v3 · 成功`、`v7 · 部分成功`，但每个页面能列出的版本数量、空历史时的展示方式不完全一样。不要把某一个页面的下拉数量当成全系统固定规则；需要找更早版本时，优先去 **系统管理 → 排产历史** 查。

## 5. 数据准备：排产前必须做的事

### 5.1 工艺管理

#### 零件列表

入口：**工艺管理 → 零件工艺模板**。

这个页面用来维护图号、名称、路线文字和工序清单。按钮含义：

| 按钮 | 作用 |
|---|---|
| 添加零件 | 新增一个图号 |
| 批量维护 | 用 Excel 整批维护路线文字或工时 |
| 查看/编辑 | 打开零件详情，补工时和外协周期 |
| 删除 | 删除未被批次引用的零件 |
| 批量删除 | 删除勾选的零件；被批次引用会失败 |

批量删除前先确认筛选条件、已选条数和本次删除范围。

零件列表上方有 **搜索框**，输入图号或名称可以快速过滤当前页显示的零件。列表默认每页 100 条，数据多时用页面底部的 **上一页/下一页** 翻页。

| 操作 | 查看/编辑、删除 |

#### 零件详情（工序清单）

入口：零件列表里点 **查看/编辑**。

这个页面做三件事：

1. 改零件名称、路线文字和备注。
2. 点 **按路线重新生成工序清单**，按当前路线文字重新生成模板工序。
3. 给自制工序填换型时间、单件工时；给连续外协工序设置周期。

注意：重新生成工序清单会按路线文字重做模板。生成失败时，原工序清单不会被改动。

**页面上的两个独立表单**：零件详情页有两个独立保存的区域——上面是"基本信息"（改名称、路线文字、备注后点 **保存**），下面是"重新生成工序清单"（点 **按路线重新生成工序清单**）。两个操作互不影响：你改了路线文字后点保存，只是保存文字本身，不会自动重新生成工序；要生成工序，必须单独点生成按钮。

**工序清单的颜色标记**：蓝色底色的行是自制工序，橙色底色的行是外协工序，方便一眼区分。工序清单上方有统计：共 X 道工序（自制 X，外协 X）。

**自制工序的工时编辑**：每道自制工序右边有换型时间和单件工时的输入框，改完后要点这一行的 **保存** 按钮。不点保存，修改不会生效。

**外协工序组的删除**：如果有多道连续外协工序，系统会把它们归为一组。每组右上角有 **删除此组** 按钮，但只有排在最前面或最后面的外协组才允许删除。中间的外协组不能直接删。

工序清单里通常会把自制和外协区分显示，方便你知道哪些工序要填设备、人员和工时，哪些工序要看供应商和外协周期。多道连续外协工序可以按单道周期分别设置，也可以按整组周期统一管理；如果选了整组周期，后续批次详情里单道外协周期就不能随便单独改，要回零件详情调整这组外协周期。

入口：**人员管理 → 班组管理**。

班组可以同时挂人员和设备。资源排班支持按班组查看任务，也能看班组里是按人员轴还是设备轴展开。班组不是必须项，但现场按班组管理时建议维护。

> **照着做**：

1. 打开 **人员管理 → 班组管理**。
2. 在“新增班组”里填 **班组编号**，比如 `TEAM-01`。
3. 填 **班组名称**，比如 `车工一组`。

（班组列表的名称、状态和备注都可以直接在表格里修改，不需要进单独的详情页。）
8. 如果要删除班组，点这一行右侧 **删除**。已经被人员或设备引用的班组会删除失败，需要先把人员或设备上的班组改掉。

人员 Excel 和设备 Excel 里的“班组”列不会自动新建班组。要在 Excel 里填班组，必须先在这里建好；Excel 里可以填班组编号，也可以填班组名称。

1. **编辑基本信息**：可以改设备名称、工种、类别、班组、状态和备注；设备编号不作为普通字段修改。
   设备编号在详情页上是灰色不可编辑的。
2. **维护可操作人员**：每行能改技能等级和主操标记，点保存才会写入；点解除关联只解除关系，不删除设备或人员。
3. **管理停机计划**：新增停机要填开始、结束、停机原因和备注；已有停机只取消，不直接改时间。

   停机原因是下拉选择，固定 5 个选项：

   | 选项 | 什么时候用 |
   |---|---|
   | **计划维护** | 定期保养、预防性维护（这也是默认值） |
   | **故障停机** | 设备出了故障需要维修 |
   | **停电/能耗** | 外部原因：停电、能源供应中断 |

   | **其他** | 以上都不是时选这个，具体原因写在备注里 |

#### 批量停机计划

入口：**设备管理 → 批量停机计划**。

这个页面可以按单台设备、按设备类别、或全部设备批量建停机。你要填开始时间、结束时间、停机原因和备注。开始和结束建议写成 `2026-05-20 08:00` 这样的格式，结束时间必须晚于开始时间。

> **重点纠偏**：按类别或全部批量停机时，默认只作用于状态为 **可用** 的设备。已经停用或维修的设备，不会被默认批量建进去。

批量创建时，系统会逐台检查。已经有重叠停机记录的设备会被跳过，其它不冲突的设备会照常创建；页面里的“影响设备 x 台”只代表本次真正创建成功的数量。看到跳过清单时，不要当成整批失败，要按设备逐台复核。

### 5.4 物料管理

入口：**物料管理**。物料管理主要做两件事：维护物料主数据（编号、名称、库存等），以及按批次管理物料需求和齐套状态。

#### 物料主数据

入口：**物料管理 → 物料主数据**。

物料主数据维护物料编号、名称、规格、单位、库存数量、状态和备注。库存数量可以为 0，但不能为负数。这里的库存只是物料资料的一部分，不会自动拆成每个批次的到料数量；某个批次到底缺不缺料，要去批次物料需求里看需求数量和到料数量。

#### 批次物料需求（齐套判定）

入口：**物料管理 → 批次物料需求（齐套判定）**。

这个页面按批次维护物料需求。选择批次后，可以新增物料、需求数量、到料数量。

如果你不启用齐套检查，物料管理不是排产必填资料；它主要用于让页面显示缺料情况，方便计划员提前看风险。只有这次排产勾选 **本次启用齐套检查**，或高级设置默认启用了齐套检查时，未齐套和部分齐套才会挡住排产。

实际操作按这个顺序做：

1. 先到 **物料管理 → 物料主数据** 建好物料，并确认物料状态是可用。
2. 再到 **物料管理 → 批次物料需求（齐套判定）**。
3. 先选批次，再点 **查看**，页面会显示这个批次当前的物料需求。
4. 在 **新增物料需求** 区域选择物料，填写需求数量和到料数量，再点新增。
5. 新增后在列表里复核齐套状态；需要改数量时，在这一行改完后点保存；填错物料时删除这一行后重新新增。

- "需求数量"必须大于 0。
- 新增物料需求时，到料数量不填，系统按“到料数量等于需求数量”处理，也就是默认到齐。
- 更新已有物料需求时，到料数量不填或清空，系统会保留原来的到料数量，不会把它改成 0；如果你确实要改成 0，必须明确填 `0`。
- 到料数量填不足时，该物料行显示未齐套。
- 一个批次没有任何物料需求行时，默认按齐套显示。大白话说，就是系统没有看到缺料明细，所以先按齐套看；如果现场确实要管物料，就要把需求行补上。
- 有需求行时，系统会按到料情况自动更新齐套、部分齐套或未齐套。
- 同一批次里，同一个物料只能新增一次。如果你尝试给同一批次再次添加已有的物料编号，系统会提示“该批次已存在该物料需求，无需重复添加”。
- 新增物料需求时，物料下拉框只显示状态为“可用”的物料。如果某个物料在下拉框里找不到，先去 **物料管理 → 物料主数据** 确认它是不是“停用”状态。
- 批次齐套日期会自动清空：当批次物料需求中出现缺料，也就是部分齐套或未齐套时，系统会自动把这个批次的齐套日期清空。只有所有物料需求行都到齐，并且这个批次原来人工填过齐套日期时，这个日期才会保留。也就是说，一旦有物料缺料，批次齐套日期就没了，重新齐套后需要再填一次。

再次强调：齐套状态只有在启用齐套检查时才会真正影响本次排产；只要所选批次里有未齐套或部分齐套，本次排产会报错并停止。系统不会自动跳过这些批次继续排其它批次；齐套日期只对齐套批次作为最早开工日。

### 5.5 工作日历配置

入口：**排产调度 → 工作日历配置**。

这个页面维护某一天是不是工作日、能干几小时、效率是多少、能不能排普通件或急件。

| 页面字段 | 怎么填 |
|---|---|
| 日期 | `2026-05-20` |
| 类型 | 工作日或假期 |
| 班次开始 | 默认 08:00 |
| 班次结束 | 可选；填了以后，系统会用“班次结束 - 班次开始”反算可用工时 |
| 可用工时 | 工作日不填默认 8，假期不填默认 0；填写时必须是大于等于 0 的有限数字 |
| 效率 | 工作日不填默认 1.0，假期不填默认高级设置中的“假期工作效率”；填写时必须是大于 0 的有限数字 |
| 允许普通件 | 是或否 |
| 允许急件/特急 | 是或否 |
| 说明 | 备注文字，可填可不填 |

常用类型是 `工作日` 和 `假期`。类型空着时按工作日处理。旧 Excel 里如果已经手填 `周末` 或 `节假日`，系统也会按假期处理；新模板不要故意写旧叫法。

班次结束和可用工时同时填写时，以班次开始/结束反算出来的工时为准。比如填 `08:00` 到 `17:00`，即使可用工时写了 `4`，系统也会按 9 小时理解；如果结束时间早于或等于开始时间，系统会按跨午夜班次理解。

页面操作按这个顺序：

1. 点 **选择** 可以打开日期面板，已配置日期会高亮，周末也会单独标识。
2. 填日期、类型、班次开始、班次结束、可用工时、效率、是否允许普通件、是否允许急件/特急和说明。
3. 点 **保存** 后，这一天的配置会出现在下方 **已配置日历** 表格里。
4. 点 **批量维护工作日历** 可以进入 Excel 批量维护页；点 **去执行排产** 会回到排产调度页。

下方 **已配置日历** 表格展示当前已维护的所有日历记录：

| 列 | 说明 |
|---|---|
| 日期 | 配置的日期 |
| 类型 | 工作日或假期 |
| 班次开始 | 上班开始时间 |
| 班次结束 | 下班结束时间 |
| 可用工时 | 这一天能排产多少小时 |
| 效率 | 工作效率系数 |
| 允许普通件 | 是否允许排普通优先级的批次 |
| 允许急件 | 是否允许排急件和特急件 |
| 说明 | 备注文字 |


工作日历主页面没有“删除单条日历记录”的按钮。同一天重新保存会覆盖这一天的配置。如果要真正清掉一批特殊日期，让它们回到默认规则，走 **工作日历配置 → 批量维护工作日历**，下载当前模板，整理好要保留的日期，再谨慎选择 **清空本类数据后重导**。这个模式会重建整类工作日历，做之前先手动备份；没有把握时先找维护人员。

注意：工作日历批量模板没有 `班次开始`、`班次结束` 两列。如果你曾在手工工作日历页给某天填过班次时间，清空重导前要先确认这些班次时间是否还需要保留。

### 5.6 个人工作日历

入口：**人员管理 → 人员详情 → 个人工作日历**。

个人工作日历适合记录请假、个人加班、临时只排急件。它比全局工作日历更细。同一天既有全局日历又有个人日历时，排这个人会优先看个人日历。

个人工作日历里的可用工时必须是大于等于 0 的有限数字；效率必须是大于 0 的有限数字。`TRUE`/`FALSE`、`NaN`、`Inf`、`Infinity` 和文字都不能当作数字用。

班次时间按实际班次理解：`08:00` 到 `16:00` 是 8 小时白班；`22:00` 到 `06:00` 会按跨到第二天的夜班理解。班次结束和可用工时同时填写时，也以班次开始/结束反算出来的工时为准。

页面操作按这个顺序：

1. 从人员详情点 **个人工作日历** 进入单个人的日历；如果要一次维护很多人，走人员管理页的 **批量维护** 入口。
2. 上方日期面板会高亮已配置日期，方便看这个人哪些天已经单独设过。
3. 填日期、类型、班次开始、班次结束、可用工时、效率、是否允许普通件、是否允许急件/特急和说明。
4. 点 **保存** 后，下方 **已配置个人日历** 会显示这条记录。
5. 如果高级设置里的假期工作效率配置异常，页面会显示黄色提示；先去高级设置修好，再继续维护假期加班这类安排。

下方 **已配置个人日历** 表格展示这个人已维护的所有个人日历记录：

| 列 | 说明 |
|---|---|
| 日期 | 配置的日期 |
| 类型 | 工作日或假期 |
| 班次开始 | 上班开始时间 |
| 班次结束 | 下班结束时间 |
| 可用工时 | 这一天能排产多少小时 |
| 效率 | 工作效率系数 |
| 允许普通件 | 是否允许排普通优先级的批次 |
| 允许急件 | 是否允许排急件和特急件 |
| 说明 | 备注文字 |


个人工作日历页面没有“删除单条记录”的按钮。同一个人同一天只能有一条个人日历，重复保存会覆盖原来的配置。单人页面只能维护当前这个人的某一天；如果要一次维护很多人的个人日历，走 **人员管理 → 人员管理 → 批量维护 → 批量维护个人日历**，下载模板，整理好要保留的人员日期，再谨慎选择 **清空本类数据后重导**。这个模式会影响整类个人日历数据，做之前先手动备份；没有把握时先找维护人员。

## 6. 排产操作：完整指南

完整排产路线可以按这 6 段记：

| 段 | 入口 | 要做什么 | 完成标志 |
|---:|---|---|---|
| 1. 先建基础资料 | 工艺管理、人员管理、设备管理、排产调度 → 工作日历配置 | 工种、供应商、零件路线、工序工时、人员、设备、人员设备关系、日历都准备好 | 后面建批次时不会再提示缺工种、缺人员、缺设备或缺日历 |
| 2. 再建批次 | 排产调度 → 批次管理 | 新增或导入批次，确认图号、数量、交期、优先级、齐套状态没有填错 | 批次列表能看到要排的批次，状态通常是待排 |
| 3. 生成并补齐批次工序 | 排产调度 → 批次管理 → 点批次号或查看/编辑 | 让系统按零件工艺模板生成工序，再补设备、人员、工时、供应商和外协周期 | 批次详情里每道自制工序都有设备、人员、换型和单件工时；外协工序有供应商和周期 |
| 4. 先模拟排产 | 排产调度 → 排产调度 → 模拟排产（插单模拟） | 先试算一版，不推进正式批次状态 | 模拟成功后通常跳到甘特图，能看到刚生成的版本 |
| 5. 再正式排产 | 排产调度 → 排产调度 → 执行排产 | 确认模拟结果可用后生成正式排程 | 正式成功或部分完成后跳到甘特图，直接看到新版本实际排产区间 |
| 6. 最后复盘和下发 | 甘特图、周计划导出、资源排班、报表中心、系统管理 → 排产历史 | 看任务排布、导出现场周计划、查资源负荷和超期，必要时回看版本摘要 | 现场拿到周计划，计划员知道是否超期、哪里资源紧张、历史版本在哪里查 |

### 6.1 排产调度

入口：**排产调度 → 排产调度**。

这里列出待排、已排、加工中、已完成、已取消等批次。你可以按状态和齐套显示筛选。要排哪些批次，就勾选哪些批次。

页面最上方有 **常用方案** 区域。下拉框选中方案后会应用到当前排产参数，不需要再点一个“确认方案”按钮。没有勾选批次时，切换方案会直接刷新参数；如果下方已经勾了批次，系统会先提醒“切换方案会清空当前已选批次”，你确认后才会切换，取消就会回到原来的方案。

常用方案下方有 **当前配置状态** 卡片，展示当前生效的排产策略和参数摘要。如果系统临时用了默认值、读到了旧格式资料，或发现某些设置需要你复核，这里会显示黄色提示。

排产操作面板只在状态筛选为 **待排** 时显示。首次进入 **排产调度 → 排产调度** 时，系统默认按待排批次查看；如果你后来主动切到已排、加工中、已完成或全部，页面主要用于查看批次，不会展示执行排产和模拟排产按钮。找不到按钮时，先确认状态筛选是 **待排**。


排产调度页的批次表格列：

| 列 | 说明 |
|---|---|
| 勾选框 | 勾选要排产的批次 |
| 批次号 | 点击进入批次详情 |
| 图号 | 产品图号 |
| 数量 | 批次数量 |
| 交期 | 应该完成的日期 |
| 优先级 | 普通、急件或特急 |
| 齐套显示 | 齐套、部分齐套或未齐套 |
| 状态 | 待排、已排、加工中、已完成、已取消 |
| 操作 | 查看/编辑、删除 |

列表有搜索框（按批次号、图号过滤当前页）和分页翻页。

排产调度页面下方还有一个 **最近一次排产快照** 卡片，会显示上一次排产的方案、版本、时间、结果状态、批次和工序数等摘要信息。如果系统启用了"保存补齐资源"，这里也会说明是否已启用；如果排产有错误摘要，也会在这里展开。没有排过产时，这里提示"还没有排过产，排产后这里会显示最近一次排产结果"。

排产调度页面方案区域还有一个 **管理方案/高级设置** 链接按钮，点击可以直接跳转到高级设置页面，不用从全局导航绕路。


执行前先看三件事：

1. 批次图号是否正确。
2. 批次数量和交期是否正确。
3. 批次详情里的自制工序是否补了设备、人员、换型时间、单件工时。

### 6.2 补充工序信息

入口：**排产调度 → 批次管理 → 点批次号或查看/编辑**。

页面右上角有 **返回批次管理** 按钮，可以直接回到批次管理列表。还有 **删除批次** 按钮（红色），点击会弹窗确认后连同工序和排程一起删除。

手工补工序按这个顺序做：

1. 进入 **排产调度 → 批次管理**。
2. 找到要排的批次，点批次号，或点这一行的 **查看/编辑**，进入批次详情。
3. 在“批次工序（可编辑补充）”表里逐行检查。
4. 自制行要补 **设备**、**人员**、**换型（小时）**、**单件（小时）**。
5. 外协行要补 **供应商** 和 **外协周期（天）**。
6. 每一行填完，都要点这一行最右侧的 **保存**。只填表格不点这一行的保存，系统不会把这一行写进去。

设备和人员下拉受人员设备关联限制。如果某道自制工序没有可选设备或人员，先去人员管理或设备管理补“可操作关系”。如果你点 **按最新工艺模板刷新本批次工序**，本批次已补的设备、人员、工时、供应商和外协周期会被清空，需要重新检查。

批次详情的工序表按这些列展示：

| 列 | 说明 |
|---|---|
| 工序编码 | 系统生成的唯一编码 |
| 工序 | 路线文字里的工序号，比如 5、10、20 |
| 工种 | 这道工序的工种 |
| 归属 | 自制或外协 |
| 设备 | 自制工序选择设备 |
| 人员 | 自制工序选择人员 |
| 换型（小时） | 自制工序的准备时间 |
| 单件（小时） | 自制工序每件耗时 |
| 供应商 | 外协工序选择供应商 |
| 外协周期（天） | 外协工序周期 |
| 操作 | 每行保存 |

设备和人员是双向联动的：先选设备，人员下拉会缩小到能操作这台设备的人；先选人员，设备下拉也会缩小到这个人能操作的设备。如果打开“优先推荐主操/高技能人员”，主操和熟练人员会更靠前。

外协工序如果属于零件工艺模板里的“整组周期”外协组，批次详情里的单道外协周期会被禁用，并提示这道工序由整组周期统一控制。要改这类周期，回 **工艺管理 → 零件详情** 改外协工序组。

如果历史工序里引用的设备、人员或供应商后来被删除或停用，下拉框可能显示“已删除”或“不可用”这类灰色项。它是在提醒你这版数据引用了旧资源，不表示可以继续选来做新排产。

> **下拉框加载提示**：当系统里的设备或人员数量比较多（超过 80 个），或者自制工序超过 30 道时，批次详情页的设备和人员下拉框会变成"点击后再加载"模式——打开页面时下拉框只显示当前已选中的那一项，第一次点开时才会加载全部选项。这是为了避免页面变卡，不是系统出了问题。如果你觉得某个下拉框选项不全，先点一下再看。



### 6.3 执行排产与模拟排产

入口：**排产调度 → 排产调度**。

操作步骤：

1. 筛选出待排批次。
2. 勾选要排的批次。
3. 填排产开始时间；不填时，默认明天 08:00。
4. 如有需要，填排产截止日期。注意：这是严格限制，不是普通备注。填了以后，如果系统判断部分工序无法在截止日期内完成，这些工序不会保存成可用排程；结果可能失败，也可能是部分完成。不确定时先不填，先模拟看结果。
   排产面板底部有一段风险提示：未勾选 **发现参数问题就停止排产** 时，换型时间或单件工时空着、填负数、填文字或表格异常值（如 NaN、Inf），系统会按 0 小时继续排，并在结果提醒里提示你补正；勾选后，这些工时问题会直接报错停下。正式排产前建议先去批次详情把工时补成真实值。

5. 按本次要求勾选或取消 **本次启用齐套检查**。日常不想让齐套挡住排产时可以不勾；这次必须确认物料齐套才能开工时再勾。
6. 勾选或取消 **发现参数问题就停止排产**。勾上以后，系统会先检查排产设置和工时：下拉选项必须是页面能选到的值，数字不能空着、为负数或填文字；发现问题就停下让你改。不勾时，系统会先按默认值继续排，例如空工时按 0 小时、外协周期缺失按 1 天，并在结果提醒里告诉你要补哪项。
7. 先点 **模拟排产（插单模拟）**。
8. 模拟成功后，系统会 **自动跳转到甘特图页面**，先核对版本号，再看任务有没有排到不该排的日期、设备或人员。如果没自动跳，手动进甘特图选最新版本查看。
9. 没问题后，回 **排产调度 → 排产调度**，再点 **执行排产**。
10. 正式成功或部分完成后，系统会 **自动跳转到甘特图页面**，并带上这次新版本的实际开始日期和结束日期。也就是说，跳过去以后应该直接看到这版排出来的条形，不需要再猜它排在哪一周。正式失败或系统校验报错时，页面会留在排产调度页，并显示错误提示。

模拟排产和正式排产都会生成排产版本。区别是：模拟排产不影响批次正式状态；正式排产会把结果作为正式排程使用。

排产成功后，如果系统生成提醒，页面只展示前 5 条。提醒很多时，不代表后面的提醒不存在；先处理页面已经展示的提醒，再回到排产调度重新模拟或重新执行。

排产跑完后，先按页面提示判断是哪种结果。版本下拉、版本摘要和排产历史里的状态标签通常写 **部分成功**；刚执行完排产后的黄色提示可以写 **排产部分完成**，这是在说这次动作处理完了但需要复核。

| 结果 | 页面上通常怎么看 | 代表什么 | 下一步 |
|---|---|---|---|
| 成功 | 绿色成功提示，生成新版本，批次数和工序数有数值 | 系统保存了可查看的排产结果 | 看甘特图、周计划、资源排班和报表 |
| 部分成功 / 排产部分完成 | 黄色提醒或“排产部分完成”，有版本，但同时有提醒或部分数据需要复核 | 系统保存了能确认的结果，但有些工序、资源、提醒需要人工看 | 先看页面展示的提醒，再去排产历史看完整摘要；必要时补资料后重新模拟 |
| 失败 | 红色错误提示，没有可用新版本，或提示缺少必要数据 | 这次没有形成可正常使用的结果 | 按错误提示补批次、工序、设备、人员、工时、日期或齐套状态后重试 |

**无可保存结果** 不是一种结果状态，而是失败原因。看到“本次排产没有生成可保存结果”时，按失败处理：回批次详情逐行补齐设备、人员、换型时间、单件工时，确认每行点了保存后再排。

> **常见报错**：

| 报错 | 大白话解释 | 怎么处理 |
|---|---|---|
| 请至少选择 1 个批次执行排产 | 没勾批次 | 勾选批次 |
| 以下批次未齐套，禁止排产 | 启用了齐套检查，批次不是齐套 | 补物料或关闭齐套检查 |
| 所选批次没有可重排工序 | 批次没有能排的工序 | 回批次详情生成或检查工序 |
| 本次排产没有生成可保存结果，存在自制工序缺设备/人员 | 有自制工序没补设备或人员，且本次没有成功自动分配；如果工时是负数、不是数字、不是有限数字，也会导致排不出可保存结果。工时空着会按 0 处理，但正式排产前仍建议补成真实工时 | 回 **批次管理 → 批次详情**，把自制行的设备、人员、换型时间、单件工时补齐，或到高级设置开启自动分配；每一行点右侧 **保存** 后再排 |
| 开始时间写法不对 | 时间写法不对 | 写 `2026-05-20 08:00` |
| 结束日期不能早于开始时间所在日期 | 排产截止比开始还早 | 调整日期 |

### 6.4 甘特图

入口：**排产调度 → 甘特图**。

甘特图用条形图看排程。可以切换设备视图和人员视图，也可以按起止日期范围、周切换按钮、指定版本查看。没有手动选范围时，页面会按所选版本里真实任务的最早开始日期到最晚结束日期来显示；如果你已经手动填了起止日期，或点了上周/本周/下周，系统会尊重你选的范围。

甘特图当前是 **查看模式**。这里显示已经生成的排产结果，可以点击任务条看详情、筛选、换配色、切换时间粒度；拖动或拉伸任务条不会修改计划。后续如果开放调整，会通过单独的“模拟调整”功能处理，不会在查看页里悄悄改正式排产。

页面上会看到 **模拟调整（后续开放）** 的灰色入口。它只是提前告诉你后续功能会放在这里：当前不能点击，也不会产生草稿、模拟方案或正式新版本。

排产区间按本地自然日理解：开始日从当天 `00:00:00` 开始，结束日整天都算在内。系统内部查数据时可能用“结束日后一天 00:00:00 之前”这种写法，但页面和提示都按“结束日到 `23:59:59` 都包含”来理解。

页面上常用控件：

| 控件 | 作用 |
|---|---|
| 设备视图/人员视图 | 按设备或人员分行看任务 |
| 上周/本周/下周 | 快速换周 |
| 排产区间起止 | 看自定义日期范围 |
| 版本 | 看某一次排产版本 |
| 时间粒度 | 月、周、日、12小时、6小时、小时、15分钟、5分钟、1分钟 |
| 配色 | 按批次、优先级、归属、工序状态配色 |
| 批次筛选/资源筛选 | 只看某批次或某设备、某人员 |
| 仅超期 | 只显示超期任务 |
| 仅外协 | 只显示外协任务 |
| 高亮关键工序 | 标出影响总工期的关键任务 |
| 工序关系线 | 可看只显示关键工序关系线、显示全部工艺关系线或不显示关系线 |
| 重置 | 把筛选和配色恢复到默认 |
| 模拟调整（后续开放） | 当前是灰色占位入口，不能点击；后续页面入口接好并放行后再开放 |

筛选和配色默认收在 **筛选与配色** 折叠面板里，先展开才能改。这个面板里的图例区会显示当前配色、任务数、关键工序统计、假期/停工背景说明等信息。

时间粒度按这个理解：

- **月 / 周 / 日**：适合看整体排产范围。
- **12小时 / 6小时**：适合看班次附近的安排。
- **小时 / 15分钟 / 5分钟 / 1分钟**：适合查看短工序的具体开始和结束时间。
- 时间粒度只改变“看图的疏密”，不会重新排产，也不会保存任何调整。
- 粒度越细，能看的日期范围越短；如果范围太大，页面会提示先缩短日期范围，或者切回更粗的时间粒度，避免浏览器卡顿。

甘特图交互按这个理解：

| 操作 | 效果 |
|---|---|
| 点击任务条 | 弹出任务详情，包含开始/结束时间、批次、图号、工序、设备、人员、来源、优先级、交期和关键工序状态等 |
| 再次点击同一批次任务 | 聚焦或取消聚焦同批次任务；聚焦时其他任务会变淡 |
| 切换配色或筛选 | 页面只改变当前视图，不会改排产数据 |

很短的工序会按真实时长显示，所以条形可能很窄。页面会给它保留方便点击的区域，点任务条附近也能打开详情；这个点击区域只是方便操作，不代表工序时长被放大。

甘特图不支持拖拽任务条来改计划。要调整计划，回基础资料、批次详情或高级设置修改后重新模拟或执行排产。

红色边框表示该批次在该版本里被判定为超期；蓝色外框表示关键工序，这些工序会直接影响当前版本的最晚完工时间；虚线边框表示外协任务；淡红色背景竖条表示假期或非工作日。工作日历加载失败时，页面会提示暂时不显示假期或停工背景。

**版本不存在** 要和 **甘特图空白** 分开看。

版本留空或版本为空字符串，都表示看最新排产历史。你手工填了不存在的版本号、`0`、负数或乱填文字时，页面会提示类似“版本号不对”“排产版本不存在”或“无对应排产历史”，不会偷偷改看最新版本。这时不要按“甘特图空白”处理，先换成下拉框里的已有版本，或把版本留空。

如果已经选到一个存在的版本，但图上还是空白，再按这几件事排查：

1. **日期范围没覆盖任务**：任务排在别的周或别的日期区间，当前范围内就会空白。页面如果提示“当前范围无任务，请切换到 xxx ～ xxx”，就说明这版实际任务在提示的那段日期里。
2. **筛选条件太窄**：只看某个批次、设备、人员、仅超期或仅外协时，可能把任务过滤没了。
3. **时间粒度太细、范围太大**：比如 1 分钟视图一次看好几天，页面会主动提示缩短日期范围，不会硬撑着渲染到卡死。
4. **本次排产没有保存出可用结果**：比如自制工序缺设备、缺人员，或正式排产没有成功保存。
5. **选择了另一种视图**：设备视图看设备，人员视图看人员；如果某类资源没有任务，对应视图里也会少。
6. **系统还没有任何排产历史**：页面会提示先去执行排产。先模拟或正式排一版，再回来看甘特图。

### 6.5 周计划导出

入口：**排产调度 → 周计划导出**。

周计划用于把一周内任务给现场复核。页面字段包括日期、批次号、图号、工序、设备、人员、时段。跨天工序会按天拆成多行。周计划现在只按 **指定周** 查询；指定周里填这一周任意一天，系统都会自动归到这周的周一到周日。旧链接里如果还带着旧版起止日期，周计划页也不会再拿它们当查询范围。

如果你是从模拟方案预览跳到周计划，页面会显示“当前正在预览模拟方案，正式计划还没有改变”。这时周计划和导出的 Excel 都按这份模拟方案看，但它还不是正式计划；要给现场正式下发，先确认是否已经正式采用生成了新版本。

页面上常用按钮和筛选：

| 控件 | 怎么用 |
|---|---|
| 去执行排产 | 回到排产调度页，重新模拟或正式排产 |
| 指定周 | 填任意一天，系统会按这一周查看 |
| 版本 | 选择要导出的排产版本，避免把模拟版和正式版拿错 |
| 查询 | 改完指定周或版本后点它，页面预览会刷新 |
| 导出周计划表.xlsx | 把当前版本、当前指定周内的完整周计划导出成 Excel |

> **重点纠偏**：页面只预览前 50 行，并显示总行数。完整周计划以点击 **导出周计划表.xlsx** 按钮后下载的 Excel 为准。

页面预览表格的列：

| 列 | 说明 |
|---|---|
| 日期 | 任务对应的日期 |
| 批次号 | 对应的批次 |
| 图号 | 产品图号 |
| 工序 | 工序号 |
| 设备 | 分配的设备 |
| 人员 | 分配的人员 |
| 时段 | 这一天内的具体时间段 |


也就是说，页面预览是给你快速扫一眼用的：看列对不对、日期对不对、有没有明显漏任务。真正要发给现场或留档时，要点导出，导出的 Excel 才包含完整周计划。

空白和异常提示要分开看：

- **暂无排产历史**：系统里还没有任何模拟或正式排产版本，先去执行排产页生成一版。
- **版本不存在**：你指定的版本号没有对应历史，系统不会偷偷切到最新版本；从下拉框选已有版本，或把版本留空看最新版本。
- 版本留空表示看最新版本。
- **当前指定周没有任务**：这个版本存在，但这一周里没有任务；改指定周，或去甘特图确认任务实际排在哪几天。
- **时间数据被过滤**：页面提示过滤了开始或结束时间写法不对的排程记录时，先回甘特图、批次详情或排产历史核对这版数据源。

选中有效版本后，页面会显示 **所选版本摘要**，包括版本、时间、排产方式和结果。如果这版有临时处理提示、排产提醒或错误摘要，摘要区会用黄色提示或可展开明细告诉你。

**导出周计划表.xlsx** 按钮按当前版本和当前指定周导出，导出操作会记录到操作日志。没有排产历史、版本不存在或系统没有识别到有效版本时，导出按钮可能不会出现。导出文件名通常会带版本和周计划日期范围，但最终仍以页面当前筛选条件和导出的 Excel 内容为准。

### 6.6 资源排班

入口：**排产调度 → 资源排班**。

资源排班可以按三种视角看：

| 视角 | 适合看什么 |
|---|---|
| 人员 | 某个人这段时间排了什么活 |
| 设备 | 某台设备这段时间排了什么活 |
| 班组 | 某个班组的人或设备排了什么活 |

区间类型有按周、按月、自定义。

> **重点纠偏**：自定义日期范围最多 62 天；查更长时间要分段查。

页面上常用按钮和筛选：

| 控件 | 怎么用 |
|---|---|
| 去执行排产 | 回到排产调度页，重新生成版本 |
| 视角 | 选人员、设备或班组 |
| 人员/设备/班组 | 按你选的视角继续选具体对象 |
| 班组轴 | 选班组时再决定按人员轴还是设备轴展开 |
| 区间类型 | 选按周、按月或自定义 |
| 查询日期/开始日期/结束日期 | 决定要看哪段时间 |
| 版本 | 选择要查看的排产版本 |
| 查询 | 按当前条件刷新结果 |
| 重置 | 清空筛选，回到默认查询 |
| 任务明细/日历矩阵/甘特图 | 在三种看法之间切换 |
| 甘特粒度 | 在资源排班页内按日、周、月看甘特图 |
| 导出资源排班.xlsx | 导出当前查询条件下的资源排班；没有历史、没有选到具体对象，或当前结果为空时，按钮可能不可用，文件也可能没有明细任务；文件名会清理不能放进下载文件名的符号 |

页面里有任务明细、日历矩阵、甘特图三个视图。导出前一定先确认版本、视角、资源和日期范围；导出的不是全部历史，而是当前查询结果。

如果页面提示正在预览模拟方案，说明这里展示的是“如果采用这份调整，会怎么排”的效果，不代表正式计划已经变了。资源排班的页面、数据加载和导出会继续保留这次模拟预览，避免你一筛选就掉回正式计划。

查询有结果时，页面上方会显示 6 个汇总数字：

| 统计项 | 含义 |
|---|---|
| 任务数 | 当前查询条件下的任务总数 |
| 总工时（小时） | 当前任务合计工时 |
| 超期任务 | 当前结果里标成超期的任务数 |
| 跨班组 | 涉及其它班组的任务数 |
| 外协未分配 | 外协但没有分到具体内部资源的任务数 |
| 跨天任务 | 跨自然日的任务数 |

任务明细表有 11 列：

| 列 | 说明 |
|---|---|
| 开始 | 任务开始时间 |
| 结束 | 任务结束时间 |
| 批次号 | 对应的批次 |
| 图号 | 产品图号 |
| 工序编码 | 系统生成的唯一编码 |
| 工序 | 工序号 |
| 查询对象 | 当前视角正在看的人员、设备或班组 |
| 对应资源 | 与查询对象配合的设备或人员 |
| 班组关系 | 是否属于当前查询的班组 |
| 来源 | 显示自制、外协等公开中文标签；无法识别时会明确标成来源未识别 |
| 状态 | 可能组合显示已锁定、超期、跨天等标签；锁定状态无法识别时会明确标成锁定状态未识别 |

导出的 Excel 明细也使用同一套公开中文标签。来源会显示自制、外协或来源未识别；锁定状态会显示已锁定、未锁定或锁定状态未识别。导出表会多给查询对象、对应资源、班组关系、是否跨天、是否超期等核对字段，方便按人、设备和批次逐条对照。

选择班组视角时，页面会按班组人员任务、班组设备任务、跨班组三块看；跨班组只有有数据时才显示。日历矩阵按日期列展示每天任务，跨天任务会按自然日拆开看。

当前查询没有数据时，导出按钮可能不可用，也可能导出一份没有明细任务的空结果。先改版本、资源或日期范围并点查询，再判断是不是确实没有任务。

### 6.7 排产优化分析

入口：**排产调度 → 排产优化分析**。

这个页面主要看当前排产结果的汇总指标，比如总工期、超期批次数、拖期小时、设备平均利用率、人员平均利用率。它适合用来比较不同方案或不同版本哪个更好。

版本口径和其他排产结果页面一致：不填版本或版本为空，都会查看最新的历史排产版本。输入不存在的数字版本时，页面会保留这个版本号并提示没有找到，不会自动改看最新；输入 `abc` 这类不是数字的版本号会报“版本号不对”。

页面上几个字段可以这样理解：

- **系统先比较哪些结果**：表示系统比较方案时先看哪些结果，比如先看超期、再看拖期或换型。它只是解释本次结果，不是让现场人员按这个顺序手工改计划。
- **冻结窗口**：可以理解成“近期已经安排好的任务尽量别乱动”。页面显示已启用、锁定天数、实际生效和冻结工序数，是帮你判断本版有没有保护近期计划。
- **趋势图**：至少两个有指标的版本才适合对比趋势；只有一个版本、快速模式没有曲线、或历史摘要不完整时，不要把空图当成系统坏了。趋势图只使用有排产指标的版本；早期版本或旧格式版本如果没有记录这些指标，可能不会出现在趋势里。只有历史摘要读取失败时，页面才会提示读取失败的版本数量。
- **未排批次数 / 数据异常批次数**：不为 0 时，先回批次、工序、设备人员关系、日历和外协周期查资料，不要一上来只调高级设置。

指标卡片常见 8 个，每个卡片的含义：

| 指标 | 看什么 |
|---|---|
| 超期批次数 | 超过交期的批次有几个，越少越好 |
| 总拖期（小时） | 所有超期批次加起来晚了多少小时 |
| 加权拖期（小时） | 按优先级加权后的拖期，急件权重更大，这个数字更能反映“重要的单子晚了多少” |
| 总工期（小时） | 从排产开始到最后一道工序结束的总时长 |
| 内制工期（小时） | 只算自制工序的工期，不含外协等待时间 |
| 换型次数 | 设备切换不同工种或不同批次的次数，次数少说明排得更连贯 |
| 设备平均利用率 | 设备总负荷占总可用工时的比例，还会显示用了几台设备 |
| 人员平均利用率 | 人员总负荷占总可用工时的比例，还会显示用了几个人 |

有上一版可比时，每个卡片右下角会显示 **对比上一版：+X / -X**，方便你一眼看出调整后是变好还是变差。利用率卡片还会显示 **任务分配均匀程度**；数值越小，说明设备或人员之间的任务分布越均匀，没有某台设备或某个人被挤爆。

精细计算记录完整时，页面还会显示 **计算过程曲线** 和 **方案尝试表**。曲线横轴是用时，纵轴是整体表现，越低越好。方案尝试表的列如下：

| 列 | 看什么 |
|---|---|
| 排序 | 系统第几次尝试 |
| 方案来源 | 这次尝试用的是什么组合 |
| 排序策略 | 先排急件还是先排交期近的 |
| 派工 | 按批次顺序还是智能派工，以及具体派工规则 |
| 失败工序数 | 这次尝试中没排进去的工序数，0 最好 |
| 目标值 | 当前优化目标的数值（比如超期批次数） |
| 条形 | 整体表现的直观进度条，越低越好。系统会先避免明显拖期更多的方案，再结合整体表现选择正式采用方案 |

快速模式或旧版本可能没有这些记录。

如果发现超期很多，先回看：

- 甘特图红框是不是集中在某个设备或人员。
- 资源负荷里是否某些资源利用率特别高。
- 工作日历是否漏了加班或误设假期。
- 批次优先级和交期是否填错。

### 6.8 批次管理

入口：**排产调度 → 批次管理**。

批次管理可以手工新增、批量维护、复制、删除和批量修改批次。

手工新增时按这个例子填：

| 字段 | 示例 |
|---|---|
| 批次号 | `B001` |
| 图号 | `P1001` |
| 数量 | `50` |
| 交期 | `2026-05-20` |
| 优先级 | `急件` |
| 齐套显示 | `齐套` |
| 齐套日期 | 留空或填预计齐套日 |

批量修改只会改你填写的字段。复制所选会把所选批次逐个复制一份，批次号末尾数字自动加 1 并保持位数不变；比如 `B001` 复制成 `B002`，`B009` 复制成 `B010`。如果新号已经存在，系统会自动继续往后加，直到找到一个不重复的号。批次号末尾没有数字时，系统不知道怎么续号，会提示失败。删除所选会同时删除这些批次下面的工序和排程记录。

批次列表可以按状态、齐套显示筛选，也可以用表格搜索框按当前页的批次号、图号快速找。分页很多时，先用状态和齐套筛选缩小范围，再翻页或搜索当前页。

批次管理的表格列：

| 列 | 说明 |
|---|---|
| 勾选框 | 勾选后可以复制、删除或批量修改 |
| 批次号 | 点击进入批次详情 |
| 图号 | 产品图号 |
| 数量 | 批次数量 |
| 交期 | 应该完成的日期 |
| 优先级 | 普通、急件或特急 |
| 齐套显示 | 齐套、部分齐套或未齐套 |
| 状态 | 待排、已排、加工中等 |
| 操作 | 查看/编辑、删除 |

列表默认每页 100 条，有分页翻页。

批量修改支持 3 个字段：**优先级**、**交期**、**备注**。只填你要改的字段，没填的字段不会覆盖原数据；三个字段都不填时会提示没有可修改内容。复制所选、删除所选、修改所选只作用于已经勾选的批次。

## 7. 高级设置：每个开关的作用

入口：**排产调度 → 高级设置**。

日常建议先用常用方案。确实要调时，先按下面三类判断，不要一上来把所有开关都改一遍。

### 7.1 日常最常看的设置

- **排产策略**：决定先照顾急件、交期，还是按先进先出排。
- **计算模式**：快速计算更快，精细计算会多试方案，通常更慢。
- **默认启用齐套检查**：系统默认关闭。关闭时齐套只显示；打开后，只要所选批次里有未齐套或部分齐套，本次排产就会报错并停止。
- **未指定设备或人员时，系统自动分配**：自制工序缺设备或人员时，允许系统帮你补，但前提是设备、人员、技能和关系资料够用。

### 7.2 有明确目的时再改

- **优化目标**：用于精细计算，比如最少超期、最少拖期小时、最少加权拖期小时、最少换型次数。
- **优先级权重 / 交期权重**：只在“综合优先级和交期”这类策略下更有意义，用来决定更偏急件还是更偏交期。
- **派工方式 / 智能派工策略**：用于决定系统按批次顺序排，还是自动挑更合适的任务。
- **锁定近期排程 + 锁定天数**：用于保护近期已安排好的任务，减少现场波动。

### 7.3 不懂先别乱改

- **找更好排法先试多久** 和 **深度优化尝试时间** 都是控制系统尝试多久的，不是越大越好。
- **假期工作效率** 会影响假期被安排生产时的效率，填错会影响日历计算。
- **深度优化** 只在精细计算时额外尝试更好的排法，日常不确定时先不要打开。

下面这张表把所有字段再汇总一遍，方便你对照页面：

| 设置 | 大白话解释 |
|---|---|
| 排产策略 | 有 4 个选项：**优先级优先**（先排急件和特急件）、**交期优先**（先排交期近的）、**综合优先级和交期**（同时考虑两者）、**先进先出**（按批次先后顺序排） |
| 计算模式 | 快速计算或精细计算；精细计算会多试方案，通常更慢 |
| 优化目标 | 有 4 个选项：**最少超期**（尽量减少超期批次数）、**最少拖期小时**（压缩超期时间）、**最少加权拖期小时**（按优先级加权后压缩超期，急件权重更大）、**最少换型次数**（减少设备切换不同工种的次数） |
| 优先级权重 | 数值越大，越照顾急件和特急件 |
| 交期权重 | 数值越大，越照顾交期近的批次 |
| 派工方式 | 按批次顺序排，或由系统自动挑更合适的任务 |
| 智能派工策略 | 只在派工方式选"智能派工"时生效，有 3 个选项：**时间余量少的先做**（剩余时间和交期差距小的优先）、**交期更紧的先做**（综合看交期和剩余加工时间）、**综合判断更紧急的先做**（系统综合多种因素判断紧急程度） |
| 找更好排法先试多久 | 精细计算会在这段时间里多试排法，单位是秒 |
| 假期工作效率 | 假期安排生产但没单独填效率时用它 |
| 锁定近期排程 + 锁定天数 | 复用上一版本近期排程，减少现场波动；锁定天数要填 0 或正整数 |
| 优先推荐主操/高技能人员 | 补工序时更偏向主操和熟练人员 |
| 默认启用齐套检查 | 关闭时齐套只显示；打开后只要所选批次里有未齐套或部分齐套，本次排产就会报错并停止；系统不会自动跳过这些批次继续排其它批次，齐套日期只对齐套批次作为最早开工日 |
| 未指定设备或人员时，系统自动分配 | 自制工序缺设备或人员时，允许系统帮你补 |
| 深度优化 + 深度优化尝试时间 | 精细计算时额外多花几秒试着找更好的排法；不保证每次一定更好，也不影响正常排产。这个时间只管深度优化组件，不等于“找更好排法先试多久” |

常用字段的默认值（点"恢复默认"会恢复到这些值）：优先级权重 0.4、交期权重 0.5、找更好排法先试多久 20 秒、假期工作效率 0.8、锁定天数 0、深度优化尝试时间 5 秒。其他下拉和开关的默认值以"默认-稳定"方案为准。

页面顶部的“当前配置状态”里可能会看到“保存补齐资源”。这不是你手动填写的高级设置，而是系统说明“自动分配补上的设备和人员，要不要保存回工序”。你只需要看它是“已启用”“已关闭”还是“旧历史未记录”；如果页面提示需要检查，按页面提示保存或重新应用方案即可，不需要去找页面上没有展示的英文内部字段名。

页面上有两个和时间有关的输入，不要混：

| 输入框 | 管什么 |
|---|---|
| 找更好排法先试多久 | 精细计算会在这段时间里多试排法；时间到了以后，不再开始新的排法，已经开始算的会算完 |
| 深度优化尝试时间 | 只在深度优化开启时，控制深度优化额外最多尝试几秒 |

常用动作：

- **切换方案**：换成系统已有或你保存过的方案；下拉选中后立即生效。
- **保存为方案**：把当前设置保存成一个名字，方便以后复用。方案名称不要超过 50 个字。
- **删除方案**：只删保存的方案，不删批次、工艺、设备、人员和历史排程。
- **保存当前设置**：保存页面上的参数。
- **恢复默认**：把页面参数恢复成系统初始设置。

系统内置了 4 个常用方案：**默认-稳定**、**交期优先**、**换型最少**、**改进-更优(慢)**。内置方案用于快速切换，不作为普通自定义方案删除；你自己保存的方案可以在高级设置里删除。

高级设置页面会在浏览器端暂存编辑草稿。意外关闭页面后，下次打开如果检测到上次有未保存的修改，页面顶部会弹出提示条，你可以选择 **恢复草稿**（把上次改的值填回去）、**清除**（丢弃草稿用系统当前值）或 **关闭**（暂时不处理）。草稿保存在你当前浏览器的本地存储里，换电脑或清浏览器缓存后草稿会丢失。真正点 **保存当前设置** 成功后，草稿会自动清掉。

## 8. 算法选择：怎么判断结果好不好

不用先懂算法。第一次用时建议：

1. 批次少、只想快速看结果：用快速计算。
2. 批次多、想多试几种排法：用精细计算。
3. 交期很重要：策略选交期优先，或提高交期权重。
4. 急件很重要：策略选优先级优先，或提高优先级权重。
5. 现场排程不想天天大变：打开锁定近期排程。

判断结果好不好，先看三件事：

- 超期批次数有没有降。
- 总拖期小时有没有降。
- 甘特图上关键设备和关键人员是否被挤爆。

## 9. 报表中心

入口：**报表中心**。

报表中心有三张常用表：超期清单、资源负荷与利用率、停机影响统计。

报表中心先记住一个总规则：改完筛选条件后要点 **查询**，有数据时再点 **导出 Excel**。导出的都是当前报表、当前版本、当前日期范围下的结果，不是完整数据库，也不能拿来恢复排产版本。

如果报表页面提示正在预览模拟方案，说明这张表是在帮你看“这份模拟调整会带来什么结果”。第一版只支持在页面上看模拟方案报表，不支持直接导出模拟方案报表；想导出给别人流转，请先正式采用生成新版本，再按新版本导出。

报表首页的两个数字只做快速速览：**最新排产版本** 是最近一个排产历史版本，正式排产和模拟排产都算；**超期批次数** 按这个最新版本的超期清单口径重新计算，不是所有历史版本累计，也不是全库不分版本实时计算。真正对账时，要进入具体报表确认版本、日期范围和导出按钮是否可用。

报表子页面的版本下拉通常会显示版本号和结果状态，方便你先判断要看成功版、部分成功版还是模拟版。不同报表页、结果页和历史页能列出的版本数量不一定完全一样；需要追更早版本时，去 **系统管理 → 排产历史** 先查清版本号。

### 9.1 超期清单

入口：**报表中心 → 超期清单**。

超期清单按排产版本查看。已排程超期是完工时间晚于交期；未排程超期是到当前截至时间还没完工，并且已经过了交期。每条超期批次都可以点开 **查看为什么晚了**，看晚了多久、建议先复核哪里、证据等级、还缺哪些数据和下一步建议。

页面操作：

| 控件 | 怎么用 |
|---|---|
| 排产版本 | 选择要查看的版本；别人给你版本号时，先确认下拉框里确实有这一版 |
| 查询 | 按当前版本刷新超期结果 |
| 导出 Excel | 有超期数据时可用，导出当前版本的超期清单，同时带“诊断依据”工作表 |

表格上方有结果摘要，包含总数、已排程、未排程和截至时间。表格里的批次号是可点击链接，点进去可以直接看这个批次的工序详情。

“查看为什么晚了”给的是保守解释，不是系统已经确认唯一原因。没有现场执行反馈时，系统不会判断“现场做慢了”；没有批次物料明细或齐套状态时，系统只会提示物料数据不足，不会直接说“一定是物料造成延期”。

表格列：

| 列 | 意思 |
|---|---|
| 类别 | 已排程逾期或未排程逾期 |
| 批次号 | 哪个批次 |
| 图号 | 哪个产品 |
| 名称 | 零件名称 |
| 数量 | 批次数量 |
| 交期 | 应该完成的日期 |
| 完工/截至时间 | 已排程看完工时间，未排程看截至时间 |
| 超期(天) | 超了多少天，可以是小数天 |
| 超期(小时) | 超了多少小时 |
| 延期解释 | 点开后看晚了多久、建议先复核哪里、证据等级、可能线索、证据缺口和下一步建议 |

> **重点纠偏**：报表里的超期天数是小数天，不是只取整天。比如超 12 小时，会显示约 0.5 天。

筛选和导出边界：页面筛选按你当前选择的版本来算；导出时导出的也是当前筛选结果，不是自动导出系统里所有历史超期记录。要导另一个版本，先改版本并点查询，再导出。导出文件里“超期清单”工作表是明细，“诊断依据”工作表会写本次诊断编号、依据摘要、核对信息、证据来源、证据缺口、生成时间和筛选条件。

### 9.2 资源负荷与利用率

入口：**报表中心 → 资源负荷与利用率**。

这个页面按排产版本和日期范围看设备、人员的负荷。没手动填日期时，页面会优先用这个版本里任务的最早开始日期到最晚结束日期；如果这个版本没有排程任务，才临时显示最近 7 天。

页面操作：

| 控件 | 怎么用 |
|---|---|
| 排产版本 | 选择要统计的版本 |
| 开始日期/结束日期 | 选择要统计的日期范围；页面有时会按所选版本自动带出排程范围 |
| 查询 | 按当前版本和日期范围刷新设备、人员负荷 |
| 导出 Excel | 有设备或人员负荷数据时可用，通常会带出设备和人员两个工作表，工作表名称是“设备负荷”和“人员负荷” |

设备负荷表：

| 列 | 意思 |
|---|---|
| 设备编号 | 哪台设备 |
| 设备名称 | 设备名称 |
| 负荷(小时) | 这段时间排给这台设备的任务小时数 |
| 任务数 | 这段时间这台设备有几条任务 |
| 可用工时(小时) | 这段日期里单台设备的可用工时口径 |
| 利用率(%) | 负荷小时除以可用工时后转成百分比 |

人员负荷表：

| 列 | 意思 |
|---|---|
| 工号 | 哪个人 |
| 姓名 | 人员姓名 |
| 负荷(小时) | 这段时间排给这个人的任务小时数 |
| 任务数 | 这段时间这个人有几条任务 |
| 可用工时(小时) | 这段日期里单个人的可用工时口径 |
| 利用率(%) | 负荷小时除以可用工时后转成百分比 |

> **重点纠偏**：资源负荷与利用率不展示完全没任务的资源。某台设备或某个人这段时间一条任务都没有，就不会出现在设备负荷或人员负荷表里。

筛选和导出边界：这个报表只统计当前版本、当前日期范围内有任务的资源。导出表不会补上完全没任务的设备或人员；如果你要查另一个版本或日期范围，先在页面上改筛选并点查询，再导出。

### 9.3 停机影响统计

入口：**报表中心 → 停机影响统计**。

这个页面按版本和日期范围统计设备停机，以及停机是否和已排任务重叠。日期范围先决定查哪些停机记录；排产版本决定拿哪一版任务来和这些停机记录对比。也就是说，停机事实按日期查，任务重叠按版本比。

页面操作：

| 控件 | 怎么用 |
|---|---|
| 排产版本 | 选择要对比的排产版本 |
| 开始日期/结束日期 | 选择要统计的停机日期范围 |
| 查询 | 按当前版本和日期范围刷新停机影响 |
| 导出 Excel | 当前范围有停机影响结果时可用，导出当前查询结果 |

筛选区下方有汇总摘要，显示涉及设备台数、停机总时长和与排程重叠总时长。没手动填日期时，页面会先按所选版本的排程范围自动带入开始和结束日期；如果该版本没有排程任务，才临时显示最近 7 天。

| 列 | 意思 |
|---|---|
| 设备编号/设备名称 | 哪台设备 |
| 停机时长(小时) | 停机总小时数 |
| 停机次数 | 有几段停机 |
| 与排程重叠(小时) | 停机和排产任务撞上的小时数 |
| 重叠次数 | 撞上的次数 |

如果这里重叠很多，回设备详情或批量停机计划检查停机时间，再重新排产或调整任务。

筛选和导出边界：停机影响按当前版本和日期范围统计。导出的是当前查询结果，不会把未筛进来的日期、设备或其它版本一起带出去。它也不是停机台账备份，不能用来恢复停机计划。

## 10. 系统维护

### 10.1 备份/恢复

入口：**系统管理 → 备份/恢复**。

这个页面可以手动备份、恢复数据、清理过期备份，也能切换现代/经典界面。

按钮含义：

| 按钮 | 作用 |
|---|---|
| 手动备份 | 立即保存一份当前数据库 |
| 清理过期备份 | 按保留天数清理旧备份 |
| 批量删除选中 | 删除勾选的备份，删除后不能恢复 |
| 恢复 | 用某个备份覆盖当前系统数据 |
| 删除 | 删除单个备份 |

恢复会覆盖当前数据。恢复前系统会先尝试生成一份“恢复前自动备份”。如果恢复过程失败，系统会尽最大努力恢复到这份备份。自动回滚是最后保护，不替代你手动确认过的备份。

备份文件名由系统自动按时间和用途生成，不需要你自己起名。文件名一般会带上时间和用途，常见用途包括手动备份、自动备份、程序正常退出时留下的备份、恢复前系统自动留下的保护备份。恢复前不要只看名字，要一起看创建时间、文件大小和当时为什么做这份备份。

> **重点纠偏**：恢复成功的完整口径是 **已从备份恢复并完成结构校验**。只看到"文件已复制"还不算完整成功；恢复后结构校验失败时，不要继续当作恢复成功使用。


备份页还有 **自动备份与自动清理** 设置区：

| 设置 | 怎么理解 |
|---|---|
| 自动备份开关 | 开启后，系统会在有人访问或操作时检查是否到间隔；同一个开关也控制程序正常退出时的退出备份 |
| 间隔（分钟） | 自动备份检查间隔，页面允许 1 到 1440 分钟 |
| 自动清理开关 | 开启后，系统会按保留天数清理过期备份 |
| 保留天数 | 清理时保留多少天内的备份，页面允许 1 到 365 天 |
| 保存设置 | 保存这些自动备份和清理设置 |

这里不是后台一直倒计时运行，而是有人打开或操作系统时顺手检查有没有到时间。单次自动清理也有数量限制，避免一次删太多。

备份页底部还有 **扩展功能状态**。它展示随系统交付的扩展功能、版本、开关、是否加载和问题说明。普通排产人员一般不用操作；如果维护人员让你切换扩展功能，保存后通常要重启软件才真正生效。

### 10.2 操作日志

入口：**系统管理 → 操作日志**。

操作日志用来查什么时候、哪个模块做了什么动作，以及操作目标或结果说明。可以按开始时间、结束时间、模块、动作、日志级别、查看条数筛选。

查看条数默认是最近 50 条，可填 1 到 500。批量删除前先确认筛选条件、已选条数和本次删除范围。

日志级别筛选有 **全部**、**信息**、**警告**、**错误**。如果只是查最近操作，通常只填查看条数；如果要追某次问题，再加开始时间、结束时间、模块和动作。

页面上方还有 **日志自动清理设置**：启用开关、保留天数、间隔分钟和保存设置。页面会提示最少保留多少条、单次最多删多少条，避免自动清理把最近排查线索一次删光。

查询结果表包含 10 列：

| 列 | 说明 |
|---|---|
| 勾选 | 批量选择用 |
| 日志序号 | 当前查询结果里的顺序，不是固定不变的数据库编号 |
| 时间 | 操作发生的时间 |
| 级别 | 信息、警告或错误 |
| 模块 | 哪个功能模块的操作，比如“排产”“设备”“人员” |
| 动作 | 做了什么，比如“导入”“导出”“删除”“排产执行” |
| 目标 | 操作对象，比如某个批次号、设备编号；页面可能只提示目标信息已记录 |
| 错误 | 如果操作有错误，点击可展开查看错误详情 |
| 详情 | 操作的补充说明；页面通常只提示详细内容已记录，维护人员可以进一步查看 |
| 操作 | 删除这条日志记录 |

错误和详情有时是可展开内容；普通用户看不懂时，把时间、模块、动作和错误提示发给维护人员即可。

### 10.3 排产历史

入口：**系统管理 → 排产历史**。

每次执行排产或模拟排产都会生成一个版本。历史页可以按版本或最近记录条数查询，能看到版本、时间、排产方式、结果、批次数、工序数、摘要和提醒。

历史页主要用于追溯和复盘。这里能做的事是：查看版本摘要、按版本筛选、选择查看最近 10 条、50 条这类记录、看结果概况和提醒。这里不能导出版本，也不能恢复某个排产版本；排产历史不是备份/恢复功能。想看具体每道工序排在哪天、哪台设备、哪个人员，请去甘特图、周计划或资源排班。

选择某个版本后，版本详情会显示版本、时间、排产方式、结果、批次数、工序数和创建人。若这版有告警、排产提醒或错误摘要，页面会用可展开明细展示；如果提醒或错误很多，当前页可能只展开前几条，并显示另有多少条未展开。

最近排产记录表会显示编号、时间、版本、方式、批次/工序、结果、摘要与提示。最近记录条数用于控制先查多少条历史，分页只在这个查询结果里翻页；它不是关键词全文搜索。

## 12. 出错后的恢复路线图

这一章专门回答“已经做错了，怎么退回”。先记住一个原则：能用普通页面改回来的，不要急着恢复数据库；只有整批数据错了、误删了很多、或者恢复到某个时间点才是目标时，才去 **系统管理 → 备份/恢复**。

| 出错场景 | 先做什么 | 怎么退回 |
|---|---|---|
| Excel 导入错了少量行 | 不要马上清空重导，先看页面提示哪些行成功、哪些行失败 | 下载当前数据或模板，把错行改对后用 **更新已有，新增缺少** 再导入 |
| Excel 用了清空重导，发现整类数据不对 | 先停下，不要继续排产或继续导更多表 | 如果能用正确 Excel 重建，就重新清空重导；如果已经影响很多关联数据，去 **备份/恢复** 找导入前备份 |
| 工作日历或个人日历填错 | 找到具体日期重新保存 | 单条没有删除按钮时，同一天重新保存会覆盖；如果要批量清掉特殊日期，先备份，再谨慎用清空重导 |
| 停机计划时间填错 | 不要直接找编辑按钮 | 当前做法是先取消错误停机，再按正确时间重新新增 |
| 模拟排产结果不满意 | 不要把模拟结果发给现场执行 | 回基础资料、批次详情或高级设置改资料，再重新模拟；模拟不会把批次改成已排 |
| 正式排产结果不满意 | 先确认是数据问题、参数问题还是交期本身太紧 | 修正资料后重新正式排产会生成新版本；排产历史能看旧版本摘要，但不能把旧版本恢复成当前数据库 |
| 恢复备份后发现不对 | 先看页面是否提示“已从备份恢复并完成结构校验” | 恢复前系统会尝试留下恢复前自动备份；确认要回去时，再从这份恢复前备份恢复 |
| 恢复过程中失败 | 不要继续大批量操作 | 看页面提示，系统会尽量回滚；仍不确定时让维护人员看应用运行日志和备份文件 |
| 浏览器关闭或服务中断 | 先重新打开页面，不要重复点高风险按钮 | 已经确认写入的导入、备份、恢复、排产通常以页面提示和操作日志为准；不确定时先查操作日志和当前数据，再决定是否重做 |

恢复数据库属于高风险操作。恢复前先确认备份文件、创建时间和用途；恢复后刷新页面，抽查批次、物料、排产历史、甘特图和报表。报表导出的 Excel 不是数据库备份，不能拿来恢复系统。

## 13. 常见问题

### 齐套日期为什么没影响排产？

先看高级设置里是否启用了“默认启用齐套检查”，或本次排产页面是否勾选启用齐套检查。没启用时，齐套日期只做显示；启用后，齐套日期只对齐套批次作为最早开工日。如果同一次选择的批次里有未齐套或部分齐套，系统会先报错并停止本次排产，不会自动跳过这些批次继续排其它批次。

### 工作日历填了周末为什么变成假期？

这是当前规则。新模板常用项是工作日和假期；旧文件里手填过周末、节假日的，系统也按假期处理。新文件不要故意写旧叫法。

### 为什么资源负荷表里找不到某台设备？

资源负荷与利用率只汇总有任务的资源。完全没任务的设备或人员不会显示。

### 周计划页面怎么只有 50 行？

页面只是预览前 50 行，完整内容要点导出周计划表。

### 批量停机为什么没给停用设备建停机？

按类别或全部批量停机时，默认只作用于可用设备。停用、维修设备默认不在批量范围里。

### 利用率超过 100% 一定错吗？

不一定，但要检查。它表示排程负荷超过可用工时，可能是日历没配好，也可能是任务确实太挤。

### 导入批次时“自动生成工序”覆盖了手工补的数据怎么办？

批次 Excel 导入页面的“导入后自动生成批次工序”开关，会在确认写入时按零件工艺模板重新生成批次工序。已有批次工序可能会被刷新，之前在批次详情里手工补过的设备、人员、换型时间、单件工时、供应商或外协周期，也可能会被新模板覆盖。补救方法是：先导出或记录当前批次数据备用，再回批次详情逐行重新补。下次更新已有批次时，如果只是改交期、优先级或备注，一般不需要勾选自动生成工序。

### 版本下拉为空或提示“暂无排产历史”怎么办？

这通常说明系统里还没有任何模拟排产或正式排产记录。先去 **排产调度 → 排产调度** 做一次模拟排产，成功后甘特图、周计划、资源排班、分析和报表页面才有版本可选。不同页面表现不完全一样：有的页面会提示暂无历史，有的页面会把版本选择退成输入框，有的页面会显示空下拉和提示；都先按“还没有可看的排产版本”理解。

### 恢复备份后数据和之前不一样？

恢复成功并完成结构校验后，系统会用备份文件覆盖当前整个数据库。恢复后看到的数据就是备份时的状态，恢复之后新增或修改的数据可能不在这份备份里。恢复前系统会自动创建一份“恢复前自动备份”；如果恢复后发现不对，可以在确认清楚后用这份自动备份再恢复回去。

### 排产成功但甘特图上看不到任务？

先检查 5 件事：一是你有没有手动选了一个不包含任务的日期范围；没有手动选范围时，甘特图会自动用这个版本真实任务的最早开始日期到最晚结束日期。二是筛选条件是不是太窄，比如只看了某个批次或某台设备，可以点“重置”。三是视图模式对不对，设备视图看设备，人员视图看人员。四是版本号是不是对应那次排产，版本下拉里要选对版本。五是页面有没有提示时间数据写法不对被过滤，如果有，就回批次、工序或排产历史核对这版数据。


### 同一个人能不能操作多台设备？

可以。一个人可以关联多台设备，但同一个人只能有 1 台 **主操设备**。如果你在 Excel 里给同一个人设了多台主操，导入检查会标记所有多余的主操行为错误。

### 设备编号/工号/图号填错了怎么改？

编号一旦创建就不能直接修改。如果填错了，需要先删除错误的记录再重新创建。不过，已经被批次工序、排程结果、人员设备关联或物料需求引用的编号，删除会被拒绝——系统会提示"已被引用，不能删除"。这时要先把引用关系解除（比如改掉批次工序里选的设备、解除人员设备关联），再删除错误记录。

### 停机计划的时间填错了怎么办？

停机记录只能新增或取消，不能直接编辑时间。如果开始时间或结束时间填错了，先点 **取消** 把错误的停机记录撤掉，再按正确时间重新新建一条。原因或备注填错时也是同样的处理方式。

### 批次详情里设备/人员下拉框是空的？

说明这道自制工序涉及的设备和人员之间没有建"可操作关系"。先去 **人员管理 → 人员详情** 或 **设备管理 → 设备详情** 添加关联；比如让 OP001 能操作 M001，设好技能等级后，回批次详情刷新页面，下拉框里就能选到了。

### 外协工序的周期被禁用了，改不了？

这说明这道外协工序属于零件工艺模板里的"整组周期"外协组。整组周期由工艺模板统一控制，批次详情里不允许逐道单独改。要改这个周期，回 **工艺管理 → 零件详情**，找到对应的外协工序组，改整组的周期或者把模式从"合并设置"切成"分别设置"。

### 排产时提示"人员未被配置为可操作该设备"？

这说明你在批次详情里选的人员和设备之间没有关联。比如选了设备 M001 和人员 OP002，但 OP002 没有被配置为可操作 M001。解决办法：去 **人员管理 → 人员详情 → 可操作设备** 给 OP002 添加 M001 的关联，或者换一个已经关联了 M001 的人员。
