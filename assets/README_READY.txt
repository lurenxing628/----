APS 排产系统使用说明

一、解压和启动

1. 下载全部编号 ZIP，把每个 ZIP 都解压到同一个本机文件夹，合并形成一个 APS 文件夹。
2. 打开 APS 文件夹，双击 Start.cmd。
3. 程序会打开自带的浏览器。数据库和全部业务资料已经放好，无需安装 Python、Office 或导入数据。

各个 ZIP 是同一套程序的不同文件部分，必须全部解压。解压目录可以包含中文和空格；请选择当前账户可以读写的本机目录。

二、排产

点击侧栏“执行排产”，系统会读取已保存的批次、日期和规则，并自动核对。
核对本次范围后，点击“确认开始排产”。计算结束后查看候选方案，比较交期、资源安排和负荷。
选中合适方案，点击“采用方案”，填写经办人和采用原因，确认正式采用。
随后可以查看正式计划、甘特图和负荷，也可以进行试调、导出和报工。

随包资料使用正常业务入口。设备、人员、工艺、批次、物料、外协和日历都可以照日常方式修改。
修改批次范围、日期或规则后，按页面正常操作重新核对；系统会记住新的排产选择。

三、随包资料

资料包含 HSS2、HZK1、SZM1、SZS2A、BSSY5G、SSJ10、XFT1A、YB9 八个型号族，31 个图号、93 个批次、858 道工序；每图号三批，批量分别为 2、4、6 件。
工艺路线、单件工时、准备定额和设备身份来自五分厂原始资料。准备定额按每批每道计一次，单件工时按数量计算。
资源包含29台机台及15个钳工、装配、检验等工位，共44个资源、28个人员岗位；技能、日历、物料和外协信息已经准备完成。
交期、班次、人员岗位、停机、到料日以及缺失工时和外协周期为本资料集的安排值。外协沿用系统现行规则，采用1—3个自然日周期。
部分物料分次到货，排产会按已核对的数量和日期等待释放。不同型号共用设备、人员和工序能力，形成交织安排。
本系统按批次内部工艺顺序排产；未加入排产的其他装配配套件按已备齐设置。

四、重复使用与备份

首次计算前，可以在“系统管理”的“备份恢复”页签备份初始数据库。需要重新从待排状态开始时，通过同一页面恢复这份备份。
也可以将全部原始 ZIP 重新解压到一个新的空文件夹，得到相同的初始资料。已经操作过的目录保留原来的排产和报工记录。
部分开工或报工后，若没有完整的剩余安排，系统会阻止再次排产。可以先完成相应业务记录，或恢复初始备份重新演示。

业务数据库位于 APS\user-data\db\aps.db。正常使用时不要在运行中手工替换数据库。
仅关闭浏览器窗口不会停止后台服务；再次双击 Start.cmd 会复用健康的现有实例。
需要复制、迁移整个程序目录时，先正常停止服务。在 APS 文件夹按住 Shift 并单击鼠标右键，选择“在此处打开命令窗口”，执行：
  start /wait "" ".\APS.exe" --runtime-stop . --stop-aps-chrome
  echo %ERRORLEVEL%
显示 0 后可以复制整个 APS 文件夹。

五、启动问题

保留 APS\user-data\logs\launcher.log 和同目录的 aps_launch_error.txt，供核对启动阶段和实际错误。
随包程序适用于 Windows 7 SP1 x64，资源和浏览器均在本地，正常排产无需联网。
