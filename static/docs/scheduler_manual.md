# 系统使用说明

最后更新：2026年9月

## 新工作台常用操作

工作台左侧按“值班台、数据准备、排产、现场、统计分析、系统”分组，一共 15 个页面：值班台；基础资料、资料总览、批次管理；执行排产、选择排产方案、试调排产方案；现场记录、现场实际甘特；报表中心、工时定额校准；系统管理。**选择排产方案**里有“选择排产方案、计划甘特、交付风险”三个页签；**报表中心**里可以切到“执行复盘”页签。原来收藏的计划甘特、交付风险和执行复盘地址仍然能用，并保留原链接指定的计划和筛选范围。

- **显示设置与帮助**：顶栏“切换深色 / 切换浅色”切换主题；“紧凑表格”只缩小行距，不缩小字体、不改变数据。顶栏同时显示本机名称，点“帮助”打开当前页面的 **本页说明**。
- **看计划**：没有指定计划时，选择排产方案会选中唯一可读取的当前正式计划；从历史、候选或带范围的链接进入时，保留链接指定的那份计划。没有可读取正式计划时显示计划列表。选中计划后列表可收起，甘特与筛选工具留在主要区域。
- **操作长表格**：数据在表格内部滚动，表头、关键标识和操作列保持可见。每页条数以当前页面提供的选项为准；部分计划列表按上一段、下一段读取，不显示没有核对过的总页数。
- **详情与编号**：点详情后焦点移到详情标题，关闭或按 Esc 返回触发位置。维护用的编号和诊断编号收在“编号”里，需要查证时再展开。按钮不可用时会显示原因。
- **保护未保存内容**：编辑后切换工作区、前进后退或关闭编辑器，会先确认是否放弃未保存内容。选择留下时保留原页面和输入。还在提交、或者结果还没查到的操作，不能靠放弃草稿当成取消，也不要重复提交。
- **现场报工**：新增记录时会预填可清除的时间；请按实际情况核对预填时间，不知道的时间可以清除。补齐、更正和已经保留的草稿不会被预填覆盖。“复制上一条”只取同任务同工序的有效记录值。“保存并继续”必须先确认保存成功并刷新到最新结果，才会打开下一份草稿。
- **现场实际甘特**：默认显示范围靠近实际数据；缩放跟随所选工序或数据中心，“适应全部”可查看完整范围。没有结束时间的记录按点表示。
- **系统管理**：页面环境自检只表示当前页面环境。无法读取维护状态时会明确提示并保留写入保护，不能把读取失败当成已确认暂停或已恢复。诊断文件可导出，恢复入口保留确认与等待规则。

支持列宽调整的表格会在表头右边缘显示拖动位置。出现左右箭头时可以拖动，具体重置或自动适应操作以该表提供的按钮为准。

## 阅读指引：不同人先看哪里

第一次看这本说明书时，不建议从第 1 章的列名表一路硬读到底。先按自己的角色找到主流程，再回头查细节，会更省力。

| 什么角色 | 建议先看 | 主要目的 |
|---|---|---|
| 第一次接触系统的计划员 | 第 0 章、第 2 章、第 6 章 | 先知道从空库到第一次正式排产怎么走 |
| 工艺员 | 第 3 章、第 5.2 到 5.3 节、第 1.6.1 到 1.6.4 节 | 先把工种、供应商、路线文字和工时准备对 |
| 人员或设备维护员 | 第 5.4 到 5.7 节、第 1.6.5 到 1.6.10 节 | 先把人员、设备、可操作设备、物料和日历维护对 |
| 只负责看结果的人 | 第 6.3 到 6.5 节、第 10 章 | 看选择排产方案、计划甘特、交付风险、报表和执行复盘 |
| 现场班组长 | 第 9 章、第 1.6.12 节 | 登记报工、看现场实际甘特、用报工文件整批导入 |
| 要做恢复或排错的人 | 第 11 章、第 13 章 | 先知道怎么备份、怎么恢复、出错后怎么退回 |

先记住这条主流程：**基础资料准备好 -> 建批次 -> 补批次工序 -> 执行排产生成候选方案 -> 采用为正式计划 -> 需要微调时试调 -> 看结果和报表 -> 必要时从备份恢复找回整库数据**。后面每个章节都是围着这条线展开的。

## 0. 先说清楚：第一次正式排产怎么走

从一个空库做到第一次正式排产，推荐按这个顺序来：

如果这是正式库，不是练习库，先去 **系统管理 → 备份恢复** 点 **新增备份** 做一次手动备份。后面导入、清除重导和正式排产都会改数据，先备份，出错时才有路可退。

1. 先进 **基础资料**，在上方产能链选 **自制工种**，把会出现在路线文字里的工种建好，比如 `数铣`、`钳`、`数车`；有外协工序再切到 **外协工种** 建 `标印` 这类外协工种。
2. 如果有外协工序，产能链选 **供应商**，给外协工种配一个启用状态的供应商，填默认周期（天）和它可做的外协工种。
3. 产能链选 **工艺**，点 **新增零件**，用 **录入路线** 把路线文字建成工序清单。例子：图号 `P1001`，路线文字填 `5数铣10钳20数车35标印`。然后按 **确认路线 → 确认归属 → 填写工时** 三步把这个零件做到 **已就绪**。
4. 给自制工序补工时：可以在零件工艺详情的“工时定额”一步里逐条填，也可以用 **导入工时定额** 批量导入。
5. 产能链选 **人员** 建人员，选 **设备** 建设备并绑定自制工种。设备状态有可用、停机、停用；人员状态有在岗、请假、停用。
6. 建人员设备关系：在人员详情里点 **编辑可操作设备**，选设备、填技能等级（初级 / 普通 / 熟练）和是否主操设备，**预览变更** 后 **确认保存设备关联**。同一个人只能有 1 台主操设备。
7. 产能链选 **工作日历**。没有单独设置的日期按页面右侧“默认规则”里显示的标准工时 / 日和假期录入默认效率排产；法定假期、调休和周末加班要用 **维护此日** 或 **批量维护** 自己设。
8. 进 **批次管理**，点 **新增批次** 或用 **批量导入** 导入批次。例子：`B001 / P1001 / 50 / 2026-05-20 / 急件 / 齐套`。
9. 打开批次详情，点 **维护物料需求**，选择物料、填写需求量和已有到料量（未到料填 0）；可选择使用工序，并逐次填写到料日期和数量，已有量与逐次记录不要重复计算。保存后按当前日期的到料计算齐套；移除需求须明确点击移除。复制批次会保留需求、将到料量清零并重置齐套日期；修改批次数量后须在这里重新核对。再逐道点 **补充资料**，检查每道自制工序是否已有设备、人员、换型工时、单件工时；外协工序是否已有供应商和外协周期。
10. 进 **执行排产**，按“选批次和日期 → 检查 → 计算”三步走：选好批次和排产日期范围，点 **开始排产检查**，检查通过后 **核对并开始排产**，等 **候选排产** 算完。
11. 在候选方案页核对候选甘特和候选交付风险，没问题就点 **采用方案**，填采用原因、经办人后 **确认正式采用**。采用后它就是当前正式计划。
12. 去 **选择排产方案** 和它的 **计划甘特**、**交付风险** 页签看结果是否合理；需要微调个别工序时，用 **试调排产方案** 在正式计划或候选方案的基础上单独改，改好再采用。
13. 现场开始干活后，在 **现场记录** 登记报工；到 **报表中心** 看工序完成情况、设备人员工时和执行复盘。**执行排产 → 排产记录** 只看历次排产的范围、时间、候选数和安排数，可以按排产状态和提交日期筛选；这里不能导出，也不能把某次排产恢复成当前数据。

### 值班台怎么看

入口：左侧 **值班台**。页头写着 **计划员值班台**，右上角有 **刷新值班台**；“数据截至”后面是这一页数据的读取时间。值班台是只读的判断面板，不在这里改资料，只帮你判断下一步去哪个页面；页脚写着数字的来源：正式计划 / 报工记录 / 资源班表 / 齐套记录 / 外协登记。

**第一段·7 张卡**：交期风险、资源压力（≥90% · 同范围日峰值）、执行偏差、外协回厂、停机影响、齐套缺口、待排批次（本机全部待排批次）。数字按当前正式计划和现场记录算，不是历史累计。点一张卡，右侧“需要关注”清单就只看这一类条目。

**第二段·需要关注清单**：左侧按类别切换——全部风险、交期风险、执行偏差、外协回厂、停机影响、齐套缺口、候选方案待确认。清单上方可以按 **条目搜索**、**处置状态**（全部状态 / 未关闭 / 待分析 / 跟进中 / 待验证 / 已关闭）和 **排序**（涉及记录 / 风险类别 / 处置状态 / 责任期限，可改为降序或升序）过滤。表格列是：涉及记录 / 类别、风险说明、处置状态、责任人 / 期限、操作。每条前面的标记表示“风险仍在”“当前无风险”或“风险未知”。没有条目时显示“当前筛选没有条目”。

**第三段·风险条目详情**：点某条的 **详情**，打开“风险条目详情”，里面有四个页签：

- **处置清单**：这条风险涉及的记录。下面的跳转按钮按类别不同，会直接跳到计划甘特、现场实际甘特、批次管理、选择排产方案、现场记录、执行排产或外协物流登记。
- **影响分析**：按类别显示“影响批次交付”“直接重叠工序 / 停机登记依据”“待排批次与齐套日期 / 本次排产约束”“工序执行偏差（工序报工与定额对照）”这些面板。资源压力类会给出“正式计划资源压力”表：资源、班表内占用（小时）、可用、整窗占用率、重叠时段、班表外占用、容量缺口。
- **方案对比**：对“候选方案待确认”这类条目有用。先在“候选方案列表”里看排产提交时间、计算状态、候选数量、范围，点 **查看候选** 进候选方案页；或者在“方案对比”里选排产记录和候选方案，看“整体收益与代价”和“逐批交期变化”，勾选“仅比较原问题批次”只看这条风险涉及的批次，点 **查看方案摘要** 看这份候选的换设备工序。
- **处置历史**：这条风险以前登记过的处置；外协回厂类叫“登记与更正历史”。

**登记处置**：详情里点 **登记处置**（已关闭的条目改为 **独立重开**），填处置状态、责任人、责任期限、处置行动、原因说明；要关闭时再填完成时间、具体完成结果、凭据说明和已核验附件编号，最后 **提交处置**。提交后结果没回来时，点 **查询上次处置结果**；已经确认的结果用 **查看已确认的结果** 再看一遍。

**外协回厂**：这一类的详情多一个 **外协物流登记** 入口，进去是“外协发出与回厂登记”：可以按全部登记 / 待回厂 / 超期未回 / 已回厂筛选；点 **新增外协登记** 选择要登记的外协工序和发出方式（合并发出 / 单工序），填经办人后 **预检核对**，再 **确认保存外协登记**；已有登记可以用它的更正登记按钮改，要填本次更正原因。登记完点 **返回值班台条目** 回到风险详情。

候选工序可以按批次号、图号、工序、分件和供应商搜索。一次合并发出只能选择同一批次、供应商及分件的连续外协工序；中间要回厂加工的两次外协分别登记。已有登记的批次不能删除、替换工序或换供应商，以便原登记能继续办理回厂；备注等普通信息仍可维护。历史登记保持原样，不会自动改写成员。

工作台左侧是 **导航栏**，按值班台、数据准备、排产、现场、统计分析、系统分组。不管在哪个页面，都可以用左侧导航直接进其他工作区，不用先回值班台。

### 分阶段用料、分批开工与默认工作时间

- **执行排产 → 本次排产规则 → 物料放行方式**：默认“整批齐套”；“按工序齐套”允许前序先做，缺料工序及后序暂不排，已登记后续到料时等待相应日期。选择“预检分批开工”，一次选一个尚未排产和开工的批次，按排产开始日期计算可做数量。
- 按工序齐套时，已具备条件的前序安排可以正式采用，也可以先试调再采用；共同工序与分件工序仍须满足前后关系。未安排的缺料工序保留待排，不算整批完成，也不据此前序结束时间承诺整批交付。漏排可开工工序、缺少设备人员或遗漏已有正式安排，仍不能采用。
- 例如原批100件、料够40件，预检会列出子批40件、原批剩60件和用料分配。取消不保存；确认后原批与子批的需求、已有到料和逐次到料总量不变，页面选中子批，仍需重新检查并开始计算。需求按件数同比分配；整批固定耗用须先人工核对，不能直接套用同比拆分。拆分后的换型工时和外协周期按各子批分别计算。
- 拆分后原批和子批都要保留，用于核对拆分数量，不能直接删除；批次页面会说明原因。拆分前填过的齐套日期继续生效。
- **基础资料 → 工作日历 → 修改默认工作时间**：初始为08:30–11:50、13:30–17:30，共7小时20分钟。保存默认配置影响没有单独设置的日期；已保存的日期、个人设置和旧计划保留原记录。日历和班次均可填写多个工作时段，午休不计入工时。
- 编辑班次时，临时切成休息再切回工作，会恢复原工作时段；工作日至少需要一个时段。只修改旧个人日历的备注或其他非时间资料，不会改变原工时。
- **设备 → 编辑 → 可做工种**支持多选。人员还必须具有该工种技能和对应设备操作授权；同一台设备的多个工种共用设备时间，不会重复算成多台设备。


## 1. 用文件批量维护：12 张表怎么填

工作台里凡是能用文件批量维护的地方，流程都一样：

1. 点这张表的导入入口（每页叫法不同，见 1.0 的「从哪里进」一列），在弹出的对话框里点 **下载模板**；想在现有数据上改，就先点导出拿当前数据。
2. 按第一张工作表填写，表头不要改；不确定某一列填什么，翻到第二张 **填写说明** 表。
3. 点 **选择文件** 选好填完的表。
4. 点 **开始预检**，看每一行的结果。想重来就再点一次 **重新预检**。
5. 没有被拒绝的行之后，点 **确认导入**。
6. 导入后可以再点导出，拿导出的表和原表对一下。

第 3 到第 5 步的按钮名 12 张表完全一样。

**预检结果怎么读**：多数表用 **新增 / 更新 / 不变 / 拒绝** 四种。另外三处有自己的说法：批次多一种 **跳过**（写入方式选了「只新增」时，已有的批次就跳过）；工时多一种 **单件工时已锁定 · 本行跳过**；报工把"和现有记录一样"叫 **重复**，整行没填叫 **空白**，另有 **补齐**（只补空项、不动已填的值）。只要有一行被拒绝，整批都不写入。

**单个上传文件的大小上限按表不同**，具体数值见 1.0 的规格速查表（那张表由系统按当前代码生成）。所有表都只读第一张工作表。

固定选项直接使用模板中的中文，例如“自制”“外协”“可用”“停用”“急件”“齐套”。模板提供下拉选项，各列的可选范围以第二张 **填写说明** 为准。以前导出的英文代号仍然兼容，不需要为了重新导入逐格改写。

几个高风险点要单独记住：

- **确认导入会怎样**：点 **确认导入** 后，系统才会真正改数据库。页面会再次按当前系统数据判断一遍，不是把预检时的结果无条件照抄进去。
- **不会出现“写进去一半”**：12 张表都是整批提交。只要预检里有一行被拒绝，确认按钮就点不下去；确认之后要么整批写入，要么整批不写。所以不用担心"成功几行、失败几行"，也不需要挑出失败行单独补导。
- **操作记录怎么看**：批量维护、备份、恢复、排产、采用这类正式业务操作通常会写进 **系统管理 → 运行日志** 的操作记录；部分报表导出可能只是直接下载文件，不一定都有操作记录。日志能查到“什么时候做过这类操作”，但不能代替备份；重要数据变更前仍建议先手动备份。
- **确认弹窗先看什么**：恢复备份、删除批次 / 设备 / 人员 / 物料 / 备份、批量删除、更新批次工序、采用方案、撤销报工这些高风险操作都会弹窗要求二次确认（清单见 15.2）。不是所有保存、上传、查询或导出都会弹窗；看到弹窗时，先看清它说的是要影响哪些数据，再点确认。

填写时有一个总原则：下载到的文件里表头不要改，系统靠这些列名认数据；只改数据行。编号类的列建议先把 Excel 单元格设成文本，避免 `001` 被 Excel 自动变成 `1`。

每份下载到的文件都有两张工作表：第一张是数据表，第二张固定叫 **填写说明**，写的就是这一张表每一列能填什么、会在什么情况下报错。导入时系统只读第一张表，第二张不用删；文件里还有别的工作表时，系统也只读第一张，其余忽略——除了报工记录，其余 11 张表还会在检查结果里提醒你有几张表没读。

### 1.1 写入方式：只有批次能选

12 张表里只有 **批次信息** 能选写入方式，其余 11 张一律是“按编号增量更新”，没有选项：

| 表 | 写入方式 | 大白话解释 | 适合什么时候用 |
|---|---|---|---|
| 批次信息 | 已有批次就更新，没有的就新增 | 批次号已存在就改，不存在就新增 | 最常用 |
| 批次信息 | 只新增没有的批次（已有的跳过） | 批次号已存在的跳过，只补新批次 | 怕误改旧批次 |
| 批次信息 | 先清除全部批次，再按表格重导 | 先删掉全部旧批次，再按表重建 | 只适合确认要整批重做时 |
| 其余 11 张 | 已有的就更新，没有的就新增 | 编号已有的改，没有的新增 | 没有别的选项 |

“按编号增量更新”有三件事要特别记住：

- **文件里没写的记录不会被删除。** 想删掉一个人、一台设备、一条关系，要到对应的详情页里删，不能靠“从文件里去掉这一行”来实现。
- **空格子表示这一项保持原样，不是清除。** 要真正清除某一项，按这张表的说明填 `\N`（大写）；多工种列表填“清除”。
- **日历和关系类的表不会取消已有安排。** 想取消一段请假或解除一条人机关系，要到人员详情里按日期范围清除或手工解除。

清除重导只有批次能选，而且要非常谨慎：批次被清除时，批次下面的工序和排程记录也会跟着没了。这个模式在确认导入时会先清掉全部旧批次再按文件重建，所以预检里看到的 `不变` 不能理解成“确认时完全不动旧数据”。没有十足把握时，优先用“已有批次就更新，没有的就新增”。

预检、确认导入和失败排查按这个顺序处理：

1. 先点 **开始预检**，核对预检结果。
2. 看检查结果。`新增` 表示系统里没有这条；`更新` 表示会改已有数据；`不变` 表示和系统里一样；`跳过` 表示当前写入方式不处理；`拒绝` 表示这一行不能写入。各表还有几个自己的说法，见 1.5。
3. 有被拒绝的行时，不要点确认导入。先按页面提示改文件，比如补必填项、改日期、改不存在的图号或工种，再点 **重新预检**。
4. 没有被拒绝的行之后，再点 **确认导入**。只有到这一步，数据才真正进入系统。
5. 确认导入后如果发现填错，优先导出当前数据，改好后再导一次；除批次外，重导一次就能把值改回来。

### 1.2 日期、时间和数字怎么填

| 内容 | 推荐写法 | 说明 |
|---|---|---|
| 日期 | `2026-05-20` 或 `2026/05/20` | 批次交期、齐套日期、日历日期都按这个写；Excel 的日期格子也认 |
| 时刻 | `08:00` | 班次开始、班次结束用这个写；Excel 的时间格子也认，但只到分钟，带秒会报错 |
| 日期加时刻 | `2026-09-13 08:30` | 报工实际开完工、设备停机计划的起止用这个写 |
| 小数 | `0.5`、`1.25`、`8` | 工时、周期都可以是小数 |
| 百分比 | `100`、`80` | 日历的效率按百分比填数字；格子设成百分比格式、显示成 `100%` 也认（按你看到的数读）。不要写 `1.0` 当成 100% |
| 是/否 | `是`、`否` | 日历和可操作设备用中文；不要填 TRUE/FALSE |
| 编号 | 先把单元格设成文本 | 防止 `001` 被 Excel 变成 `1` |

数值列最容易因为复制粘贴出错，按下面几条检查更稳：

- 不要填 `TRUE`/`FALSE` 这类是非值。
- 不要填 `NaN`、`Inf`、`Infinity` 这类不是正常数字的内容。
- 工序号不要用科学计数法，比如不要写 `5e0` 或 `1E2`；建议按普通整数写，比如 `5`、`10`。
- 数字不要带单位和千分位逗号，比如填 `12.375`，不要填 `12,375 kg`。
- 表头要按下载到的文件原样保留，不要改名、删列、合并表头。
- **不要用空格当"清除"**。空格子的意思是"这一项保持原样"；只打了几个空格的格子会被当成填错直接拒绝。真要清掉某一项，按各表填写说明操作：允许清除的普通项填 `\N`，多工种列表填“清除”。

日期列不要带时刻，也不要填 Excel 的日期序列号。公式、合并单元格、空表头都容易导致系统读不到值。

数据只能放在第一张工作表里：第二张是系统生成的 **填写说明**，放在那里的数据不会被导入。

### 1.3 推荐导入顺序

第一次建库时按这个顺序最稳：

1. 工种
2. 供应商
3. 零件工艺路线
4. 零件工序工时
5. 人员
6. 设备
7. 可操作设备
8. 物料
9. 工作日历
10. 个人日历
11. 批次信息

报工记录不在建库顺序里：它要等排产排出计划、现场开始干活以后才有内容可填。

**第 3 步和第 4 步之间、第 4 步之后各有一次确认，不能跳过。** 零件的工艺资料要在零件工艺详情里按
**路线 → 归属 → 工时** 逐级确认完，这个零件才能用来生成批次工序；三个阶段是有先后的，上一阶段
没确认，下一阶段点不了。完整顺序是：

```
导入工艺路线 → 到零件工艺详情确认「路线」→ 确认「归属」→ 导入工时定额 → 到零件工艺详情确认「工时」
```

只导文件不做确认，批次那一步会提示“该零件工艺尚未完成路线、归属和工时确认，不能用于生成批次工序”。

### 1.5 常见检查结果怎么看

页面上按表显示的就是下面这些词，照着对就行：

| 检查结果 | 哪些表会出现 | 意思 | 要做什么 |
|---|---|---|---|
| 新增 | 全部 | 系统里还没有这一条 | 确认没填错就能写入 |
| 更新 | 全部 | 系统里已有这一条，内容有变化 | 确认这次就是要改它 |
| 不变 | 多数表 | 表里和系统里一样 | 不用处理 |
| 重复 | 报工 | 和现有记录一样 | 不用处理，同「不变」 |
| 原值相同 · 无需导入 | 零件工序工时 | 表里和系统里一样 | 不用处理，同「不变」 |
| 补齐 | 报工 | 只补上原来空着的项，不动已填的值 | 确认这就是想要的 |
| 空白 | 报工 | 整行没填内容 | 不用处理；想录入就把这一行填完 |
| 跳过 | 批次 | 写入方式选了「只新增没有的批次」，这一行是已有批次 | 看是否符合预期 |
| 单件工时已锁定 · 本行跳过 | 零件工序工时 | 这道工序的单件工时已在工时定额校准里采用并锁定 | 锁定后不能撤销，普通保存、导入和再次校准采用都改不了它；新定额只用于以后新增的工序，见第 10.4 节 |
| 拒绝 | 全部 | 这一行不能写入 | 改好文件后重新预检 |

只要还有被拒绝的行，就不要硬继续。整批是一起写的：有一行被拒绝，整批都不会写入，不会出现“对的写进去了、错的没写”。页面会指出哪一列有问题，比如“数量必须大于 0”“图号不存在”“日期格式不正确”。

举几个常见例子：

| 情况 | 检查结果 | 为什么会这样 | 怎么处理 |
|---|---|---|---|
| 设备表里填了新设备 `M003` | 新增 | 系统里还没有 `M003` | 确认编号、状态、自制工种编号正确后确认导入 |
| 人员表里已有 `OP001`，这次改了名称或技能 | 更新 | 编号相同，内容有变化 | 确认这次确实要改旧资料后确认导入 |
| 批次表里 `B001` 和系统里完全一样 | 不变 | 数据没有变化 | 不用处理，可以直接忽略 |
| 批次写入方式选“只新增没有的批次”，表里又有已存在的 `B001` | 跳过 | 选的方式本来就不改旧批次 | 想改 `B001` 就把写入方式换成“已有批次就更新，没有的就新增”，再预检一次 |
| 批次表里图号填 `P999`，但系统没有这个图号 | 拒绝 | 批次用到了系统里没有的零件 | 先用路线表导入 `P999`，或者把批次图号改成正确值，再重新预检 |
| 工时表里图号填 `P999`，但系统没有这个图号 | 拒绝 | 工时表不新增零件 | 先用路线表把 `P999` 和它的工序建出来，再导工时 |

确认导入也按检查结果来判断：

1. 如果检查结果是 `2 条新增、1 条更新、0 条拒绝`，并且这些新增和更新都是想要的，就可以点 **确认导入**。
2. 如果检查结果里有 `拒绝`，不要点确认导入。先改好文件，再点 **重新预检**。
3. 如果检查结果里有 `跳过`，先看它是不是自己选出来的结果。批次选“只新增没有的批次”导致旧批次跳过是正常的；本来想更新旧批次，就要换写入方式。
4. 核对完成后，点 **确认导入** 保存。

预检结果只在一段时间内有效，中途别停太久。过期后重新点 **开始预检** 就行，数据没有被改过。

写路线文字时注意：

- 每道工序写“工序号: 工种”，工序之间用分号分开，例如 `10: 3D打印；20: 热处理`。
- 原来的紧凑写法 `5数铣10钳20数车35标印` 仍可导入；名称含数字时使用带冒号的写法，避免把名称里的数字读成工序号。

- 全角数字会转成半角数字。
- 工种没提前配置时，预检会指出是哪一道工序对不上，先把工种补齐再导。
- 改动路线会影响已有工序和外协组。预检会列出受影响的外协组，要逐个确认才能保存。

**导完还要去零件工艺详情确认。** 路线导入只是把工序拆出来，零件工艺详情里的 **路线** 和 **归属** 两个阶段
都确认过，才能接着导工时；三个阶段合起来确认完，这个零件才能用来生成批次工序。

### 1.7 导出功能一览

上面 12 张表每一张都能导出。导出的文件和导入模板是同一副列，也带同一张 **填写说明** 表，所以“导出 → 改 → 导回”是最稳的改法：不用担心表头对不上，也不会漏列。

**部分表**的导出比模板多一样东西：**只读参考列**。它们把系统里的现状带出来给你核对，比如人员的原技能明细、设备的原设备授权。这些列导回去时不看，改了也没用。

有只读参考列的是：人员（9 列）、设备（7 列）、供应商（6 列）、工种（2 列）、可操作设备（2 列）、个人日历（2 列）、物料（1 列）。批次导出会多一列只读的 **状态**（模板里没有，导回去也不看）。零件工艺路线、零件工序工时、工作日历、报工记录这四张表的导出和模板是同一副列，没有额外的只读列。

| 基础资料 → 人员 | 人员、可操作设备、个人日历 | 人员资料维护 |
| 基础资料 → 设备 | 设备 | 设备资料维护 |

### 2.1 准备一个最小可排示例

| 内容 | 示例 |
|---|---|
| 图号 | `P1001` |
| 路线文字 | `5数铣10钳20数车35标印` |
| 批次 | `B001` |
| 数量 | `50` |
| 交期 | `2026-05-20` |
| 优先级 | `急件` |
| 齐套 | `齐套` |

至少要准备：

- 工种：`数铣`、`钳`、`数车`、`标印`。
- 自制设备：能做 `数铣`、`钳`、`数车` 的设备。
- 人员：能操作这些设备的人。
- 人员设备关系：比如 `OP001 / M001 / 熟练 / 是`。
- 自制工序工时：每道自制工序的换型工时和单件工时。
- 如果 `标印` 是外协：要有对应外协供应商和默认周期。

### 2.2 第一次不要先正式排

先生成候选方案，核对排产结果。可以用它检查：

- 有没有工序没设备。
- 有没有工序没人。
- 有没有工时仍然是 0，需要工艺员补成真实工时。
- 有没有外协供应商或周期缺失。
- 交期是否明显会超。
- 计划甘特上有没有排到不该排的假期。

确认后再正式排产。

## 3. 基本概念：用白话理解

| 名词 | 大白话 |
|---|---|
| 工种 | 这道活是什么类型，比如数铣、钳、标印 |
| 归属 | 自制就是厂内做，外协就是交给供应商做 |
| 零件工艺模板 | 图号和工序清单，后面建批次会照它生成工序 |
| 工序 | 一件产品生产路线上拆出来的一步活，比如先数铣、再钳、再数车 |
| 批次 | 这次要生产的一批东西 |
| 批次工序 | 这个批次真实要排的每一道工序 |
| 换型工时 | 开始做之前的准备时间，按小时填 |
| 单件工时 | 做 1 件花多久，按小时填 |
| 齐套 | 物料够不够开工的显示状态 |
| 外协 | 这道工序不在厂内做，交给供应商做，需要供应商和外协周期 |
| 关键链 | 影响整批任务完工时间的关键任务串；其中某个任务晚了，整个批次通常也会跟着晚 |
| 齐套检查 | 本次排产规则之一；开启后，没确认齐套、物料没到齐的批次在排产检查里标成“本次跳过”，其它批次照常排，但这次排出的结果只能查看、不能采用；要采用，先取消勾选这些批次再重新排产 |
| 排产记录 | 每次执行排产留下的记录，里面有这次算出来的候选方案 |
| 候选方案 | 执行排产算出来的方案；采用之前只是候选，不影响现场 |
| 正式计划 | 现场照着干的那份计划；采用候选方案或试调方案时生成新一版，旧版保留为历史正式 |
| 试调 | 在正式计划或候选方案基础上单独改几道工序的草稿，正式计划保持不变；保存成试调方案后可以采用 |
| 资料不完整时的提醒 | 系统遇到资料不完整时，会先按能确认的内容继续运行，同时提醒哪里需要补 |
| 主操 | 某个人最擅长操作的那一台设备；同一个人只能有 1 台主操设备 |
| 技能等级 | 人员对设备的熟练程度，分为初级、普通、熟练三档 |

**编号新增之后不能直接修改**：图号、工种编号、供应商编号、设备编号、工号、物料编号、批次号这类编号，是系统用来认数据的“身份证”。页面上会禁用编号输入，或者只展示不让改。如果编号确实填错，要删掉再重新录一条；已经被批次、工序、可操作设备关系、计划或报工记录用到的编号，删除会被拒绝，页面会说明原因。

**搜索和筛选**：列表页的搜索框要点 **搜索** 才会重新查询，查的是当前筛选下的全部数据，不只是当前页；状态、齐套显示、日期范围这类筛选也一样。分页很多时，先用筛选或搜索把范围缩小，再翻页确认。

**计划要按页面理解**：选择排产方案、计划甘特、交付风险、试调、现场实际甘特都要先选一份计划（当前正式 / 历史正式 / 候选方案 / 试调方案）；现场记录、报表中心、值班台固定看当前正式计划。要找某次排产的候选，去 **执行排产 → 排产记录**。

## 5. 数据准备：排产前必须做的事

### 5.1 基础资料：页面结构和通用操作

入口：**数据准备 → 基础资料**。页面顶部是 **产能链**，按资料在排产里的位置分四段：

| 产能链 | 资料类别 | 管什么 |
|---|---|---|
| 输入 | 工艺、物料 | 零件的工序怎么走、料够不够 |
| 自制链 | 自制工种、设备、人员 | 厂内工序由哪种工种、哪台设备、哪个人做 |
| 外协链 | 外协工种、供应商 | 外协工序交给谁、默认几天回来 |
| 全局 | 工作日历 | 全厂哪天上班、每天几小时 |

点产能链上的类别切换资料，产能链本身可以 **展开 / 收起**。工艺和工作日历有自己的页面布局（见 5.2 和 5.7），其余六类是同一套列表页：

**列表页顶部工具**

- **搜索**：按编号或名称搜；**状态筛选** 默认“全部状态”；**刷新列表** 重新读一遍；**清除选择** 清掉勾选。
- **导入 / 导出**：打开这一类资料的文件弹窗，规则见第 1 章。人员页另有 **导入可操作设备 / 导出可操作设备** 和 **导入个人日历 / 导出个人日历**。
- **新增**：打开新增表单。
- **批量删除**：勾选后先预检，再勾“已核对完整删除范围及明细”确认；整批一起判断，任意一行不通过就全部不删。

**列表列**

每类都有编号、名称、状态、备注和操作列，另外：

| 类别 | 特有列 |
|---|---|
| 自制工种 / 外协工种 | 归属（自制 / 外协 / 待归类）、默认周期规则、可用设备和可用人员（自制工种）或匹配供应商（外协工种）、产能备注 |
| 设备 | 绑定工种、设备组 |
| 人员 | 技能工种、班次 |
| 供应商 | 可做外协工种、默认周期（天） |
| 物料 | 规格、库存 |

“可用设备”是已启用且关联此工种的设备数；“可用人员”是具备对应技能和设备授权的在岗人数（同一人只计一次）。

**操作列**

- **查看/编辑**：打开这条资料的详情。
- **删除**：弹出确认，要勾选“我已核对要删除的资料及其关联关系”才能删；被批次工序、计划或报工用到的资料删不掉，页面会说明原因。
- 工种行还有 **查看绑定**（自制工种看绑定的设备和有对应技能的人员）或 **查看供应商**（外协工种看可做它的供应商）。

**详情弹窗**

标题是“某某详情”，里面有 **编辑**、**删除**、**关闭**，从别的详情跳过来时还有 **返回上一条详情**。详情下方按类别列出关联设备、关联人员或关联供应商，可以搜索、查询、刷新，人员和设备之间会标“匹配设备授权”和“工种资格匹配 / 不匹配”。人员详情多一个 **编辑可操作设备** 和个人日历入口（见 5.4）；物料详情多一个 **调整库存**（见 5.6）。

**新增 / 编辑表单**

所有类别都填编号、名称、状态；编号新增后不能改。状态下拉里的“旧状态 / 原因未知（保持原值）”是旧数据带过来的，新资料不要选它。各类特有的项见下面各节。表单里有没保存的内容时，切页面会先问是否放弃。提交后页面显示“上次操作结果”，结果还没确认时不能关闭，按提示刷新或查询结果，不要重复提交。

### 5.2 零件工艺

入口：**基础资料 → 产能链选「工艺」**。

页面上方四个数字：零件总数、待定归属、待填工时、已就绪。下面的 **工艺三阶段** 页签（路线 / 归属 / 工时）按阶段筛选零件；搜索框可以搜图号、名称、路线；右侧有 **刷新工艺列表**、**新增零件**、**导入 / 导出**（分工艺路线、工时定额两种文件，见 1.6.3 和 1.6.4）和 **批量删除**。

零件列表的“下一步 / 操作”列直接写着这个零件下一步该做什么：**确认路线**、**确认归属**、**填写工时** 或 **已就绪 · 汇总**，后面是 **删除**。

点零件打开 **零件工艺详情**。详情按 **工艺路线 → 归属 → 工时定额** 三步走，上一步没确认，下一步只能看不能改：

1. **工艺路线**：点 **录入路线**，弹出“录入工艺路线”。路线录入模式有 **整条录入**（例如 `5: 数铣；10: 钳；20: 数车；35: 标印`）和 **逐行表格**（填工序号和工种，可 **新增工序**）。两种模式使用同一份草稿，可以互相切换；文字无法识别时保留原输入并提示问题。点 **预检路线**，下面会列出每道工序的识别、增删改、归属、供应商和周期。同一工序号改成另一个已登记工种时，会按预检更换绑定并清除不适用的旧工时，需要重新确认。未识别工种可以先存，到归属一步再补。预检没有错误后点 **确认保存路线**。改路线影响已有外协段时，要明确确认解除；已有定额锁定仍受保护。采用最新资料会合并你没有改过的内容，双方同时修改的工序需要核对冲突。
2. **归属**：在“归属明细”里给每道工序选自制或外协，外协工序还要选供应商；工种还没建的可以点 **新增工种** 当场建。点 **保存归属并继续**。
3. **工时定额**：“自制工时明细”里填换型工时（小时）和单件工时（小时）；“外协周期明细”里填周期（天），连续外协工序可以合成一个外协组填总周期。点 **保存工时**。单件工时填 0 时会再问一次 **按零单件工时保存**，因为排产只计算换型工时，数量增加不会增加加工时长。加工时长 = 换型工时 + 单件工时 × 批次数量。
4. 三步都确认后零件变成 **已就绪**，点 **查看汇总** 看“已就绪工序汇总”：工序、工种、现有归属、供应商 / 外协组、换型工时（小时）、单件工时（小时）、外协周期（天）、确认记录 / 问题。

详情顶部写着“此工艺已用于 N 个批次。修改后，已有批次工序不会自动更新”时，改完要回批次详情用 **预检工序更新** 把新工序刷过去（见 6.1）。

**外协段**：在工时定额一步点 **管理外协段**，选择同一供应商承接的连续外协工序，可以新增、调整范围、拆成多段或解除，先预览变更再保存。中间隔着自制工序的两次外协各自成段。合并段只填一次统一周期，成员原来的单道周期不再作为当前生效值。归属中为整段换供应商会保留段范围与周期，候选供应商必须能承接整段的所有工种。

**已有批次**：保存工艺只影响模板；批次保留生成工序或明确更新工序时的外协段范围和周期。需要更新已有批次时回批次详情用 **预检工序更新**。升级前没有保存原始外协规则的批次，按升级时有效资料保留，并在详情明确提示来源；不会把升级时资料说成原始历史。

**已锁定的单件工时**：在工时定额校准里采用过的模板工序，单件工时已锁定，这里保存和文件导入都会跳过它，见第 10.4 节。

### 5.3 工种和供应商

**自制工种 / 外协工种**：产能链上是两个入口，各自只显示自己那一类。新增时填编号、名称、状态、归属（自制 / 外协）、默认周期规则（分别设置 / 合并设置，只对外协工种有意义）和产能备注。路线文字里写的工种名要能在这里找到，预检路线时才会标“已识别”。

**供应商**：新增时填编号、名称、状态、默认周期（天）和可做外协工种。默认周期填大于 0 的数字。停用的供应商不要再给新工序选。

### 5.4 人员、可操作设备和个人日历

入口：**基础资料 → 产能链选「人员」**。列表列有编号、名称、状态、技能工种、班次、备注。人员状态有在岗、请假、停用；“待复核”是供应商状态，不是人员状态。短期请假、个人加班优先用个人日历，不要为了几天变化反复改人员状态。“班次”来自班次档：在人员表单的班次旁点加号可以直接维护班次档（编号、名称、状态、周期起始日期、轮换天数，**生成逐日规则** 后逐天填工作 / 休息和班次起止）。

**可操作设备**：打开人员详情点 **编辑可操作设备**，弹出“可操作设备 · 工号 · 姓名”。在“搜索可关联设备”里找到设备后 **新增关联**，给每条关联选技能等级（初级 / 普通 / 熟练）和是否 **主操设备**；不要的关联点 **解除关联**。改完先 **预览变更**，再 **确认保存设备关联**。同一个人只能有 1 台主操设备，设了新的，原来那台会自动变成非主操。人员的技能工种只说明这个人会什么工种，不等于设备授权；批次详情里选人员时看的是这里的设备关联。一次维护很多人时用列表页的 **导入可操作设备**（见 1.6.7）。

**个人日历**：从人员详情进入“工号 · 个人日历”。它只管这一个人：某一天设了单独设置，这一天就整天按这里的安排排产，不再套用他的班次轮换，也不看全局工作日历；没有单独设置的日期显示“按班次”。

1. 用 **上一月 / 下一月 / 刷新本月** 找到月份，点一天开始维护。
2. “这一天”选 **上班** 或 **休息**。上班要填班次开始、班次结束（工时由班次起止算出来，不用单独填；结束时刻早于开始时刻表示跨零点的夜班；留空结束时刻时，由系统按默认班次时长推算）、效率（%）、允许普通件、允许急件和备注。休息日不排产，工时按 0 计。
3. 点 **保存这一天**。要取消这一天的单独设置，点 **清除单独设置**，再 **确认清除，恢复默认**。
4. 要一次清掉一段日期，用下方的 **按日期范围清除**：填开始日期、结束日期，先 **预检要清除的日期**，看清有几天后再 **确认清除**。文件导入不会删除任何日期，导错了就从这里批量清掉。

一次维护很多人时用列表页的 **导入个人日历**（见 1.6.10）；**导出个人日历** 要先选日期范围和人员范围（全部人员 / 已选人员），只导出这段时间里单独设置过的日期。

### 5.5 设备和设备组

入口：**基础资料 → 产能链选「设备」**。列表列有编号、名称、状态、绑定工种、设备组、备注。新增时填编号、名称、状态，选绑定工种（一台设备只能绑一个自制工种）和设备组（可不填；在设备表单的设备组旁点加号可以直接维护设备组）。

设备状态有可用、停机、停用：**停用** 表示不再参与排产；**停机** 表示设备现在不能用。值班台的“停机影响”、报表中心的“停机影响”报表和试调里的“停机时段”都按已登记的停机记录统计；设备详情的 **维护停机计划** 可新增、修改和取消具体停机时段，取消后保留记录。设备改回可用不会取消已有停机计划。

设备详情下方的“关联人员”列出能操作这台设备的人，并标着“匹配设备授权”和“工种资格匹配 / 不匹配”。要改谁能操作这台设备，去人员详情的 **编辑可操作设备**。

### 5.6 物料和齐套

入口：**基础资料 → 产能链选「物料」**。列表列有编号、名称、规格、库存、状态、备注。新增时填编号、名称、规格、单位、库存数量、状态、备注，库存数量填数字。库存变了不用改整条资料：打开物料详情点 **调整库存**，填“调整后库存”保存。

有物料需求的批次，在详情点 **维护物料需求**，按物料填写需求量和本批次到料量，保存后重新计算齐套；不能仅改齐套标记跳过短缺。没有物料需求的批次仍可在基础信息中明确确认齐套和齐套日期。库存是物料总量，不会自动充当某批次的到料量。复制会保留需求但清零到料、重置齐套；调整批次数量后须重新核对物料需求。没有开齐套检查时，物料和齐套只是页面上的参考信息。执行排产时把 **齐套检查** 设为“开启”，排产检查会把没确认齐套、物料没到齐的批次标成“本次跳过”，并写明原因（比如“这批还没确认齐套。请到批次管理确认齐套状态。”），其它批次照常排，但这次排出的结果只能查看、不能采用；要采用，先取消勾选这些批次再重新排产；齐套日期晚于这次排产日期范围的批次也会跳过。

### 5.7 工作日历

入口：**基础资料 → 产能链选「工作日历」**。这一页维护全局工作时间、效率与可排产范围；人员班表和班次单独设置（见 5.4）。

页面是一张月历：**上一月 / 下一月 / 回到本月 / 今天 / 刷新本月** 换月份；上方四个数字是本月工作日、已单独设置、调休 / 加班、周末休息。图例里“已单独设置工时”表示这一天有单独设置，“调休 / 加班”表示单独设置改变了上班或休息，“周末（默认非工作）”表示按默认规则休息。右侧“默认规则”从班表汇总里读出来：未单独设置的日期按默认规则排产，显示标准工时 / 日和假期录入默认效率，读不到时写“默认规则暂无数据”；“规则来源”说明本页维护全局工作日历，个人日历和班次单独设置。

**改一天**：点日期打开“日期 · 日历详情”，点 **维护此日** 进“日期 · 工作日历”，填：

- 这一天是否排产：工作日 / 休息日；
- 班次开始、班次结束（可跨夜）、可排工时（小时）、效率（%）；
- 允许普通件排产、允许急件排产：是 / 否；
- 备注。

点 **保存配置**。要让这一天回到默认规则，点 **清除单独设置** 再 **确认清除，恢复默认**。

**改一段日期**：点 **批量维护**，弹出“批量维护工作日历”：填开始日期、结束日期（或点 **当前整月**），“应用到”选范围内每天 / 仅周一至周五 / 仅周六、周日，“维护方式”选 **设置日历**（再填上面那几项，可勾“同时替换备注（留空即清除）”）或 **清除单独设置，恢复默认**。先 **预览变更** 看全部命中日期的变更前 / 变更后，再 **确认全部**；范围不对就 **返回修改范围**。预览变更有时限，过期要 **重新预览变更**。

**文件**：**导入日历 / 导出日历** 的列说明见 1.6.9。导出要先选开始日期、结束日期，只导出这段时间里单独设置过的日期；没有单独设置过的日期按默认规则算，不会出现在文件里，所以导出的文件原样导回来不会有任何改动。文件导入只做增量，不会删除任何一天；要清掉一批特殊日期，用 **批量维护** 的“清除单独设置，恢复默认”。

### 5.8 资料总览

入口：**数据准备 → 资料总览**。这一页不改资料，只把八类基础资料的待维护项汇总成一张清单，适合排产前过一遍。

页面顶部有 **刷新资料**、**导出筛选结果**、**维护基础资料**（跳回基础资料）。四个数字：资料条数（已读取资料）、待维护项、涉及资料、已关联对数。“资料类别”一行按零件、工艺路线、工种、设备、人员、物料、供应商、日历配置显示各类条数；“原始数据缺口”提示旧数据里还缺什么。

**清单类型** 可切换 **待维护项**（一行一个问题）或 **资料清单**（一行一条资料）。筛选有资料类别、状态（待维护 / 已检查 / 停用 / 未检查）、搜索（编号、名称或待维护项）、排序（待维护项 / 编号 / 名称 / 关联项，可切换为降序或升序），**清除基础资料筛选** 一键清掉；表头还能按“列包含文字”做列筛选，点 **应用列筛选** 生效。

表格每行有 **详情** 和 **维护**：详情打开“资料详情”，里面有待维护项、相关项、资料项三个页签，**定位当前资料** 或 **维护** 会带着这条资料跳到基础资料的对应页面；**返回清单** 回来。

导出的文件叫“基础资料待维护项.csv”或“基础资料清单.csv”，按当前清单类型和筛选导出。

## 6. 排产操作：完整指南

完整排产路线可以按这 6 段记：

| 段 | 入口 | 要做什么 | 完成标志 |
|---:|---|---|---|
| 1. 先建基础资料 | 基础资料、资料总览 | 工种、供应商、零件工艺、人员、设备、可操作设备、工作日历都准备好 | 资料总览里没有待维护项，零件都是“已就绪” |
| 2. 再建批次 | 批次管理 | 新增或导入批次，确认图号、数量、交期、优先级、齐套显示没有填错 | 批次列表能看到要排的批次，状态是待排，工序概况不再写“尚未生成工序” |
| 3. 补齐批次工序 | 批次管理 → 批次详情 → 补充资料 | 给每道自制工序补设备、人员、换型工时、单件工时；外协工序补供应商和外协周期 | 批次详情的“待补齐”是 0 |
| 4. 执行排产生成候选方案 | 执行排产 | 选批次和日期 → 开始排产检查 → 核对并开始排产 | 候选排产显示“计算完成”，已保存候选方案里能点开候选 |
| 5. 采用为正式计划 | 候选方案页 → 采用方案 | 核对候选甘特和候选交付风险后确认正式采用 | 选择排产方案的计划列表里出现新的“当前正式” |
| 6. 微调和复盘 | 试调排产方案、计划甘特、交付风险、现场记录、报表中心 | 个别工序要改就试调后再采用；现场按正式计划报工；用报表和执行复盘看结果 | 现场按新计划干活，计划员知道哪里超期、哪里资源紧 |

### 6.1 批次管理

入口：**数据准备 → 批次管理**。

**列表上方**：搜索框（批次号、图号、零件名）后点 **搜索**；**筛选** 弹出“筛选批次”，可按状态（待排 / 已排 / 加工中 / 已完成 / 已取消）和齐套显示筛，点 **完成** 生效；**刷新批次列表**；**批量导入 / 批量导出**（见下面“批次文件”）；**新增批次**。已生效的筛选会显示成“列筛选 N 项”“工序缺项”“未齐套”“指定批次”这类标签，点 **清除全部筛选** 一次清掉。从值班台或执行排产跳过来时，右上角会有 **返回值班台** 或 **返回排产**；排产前整理完批次，点 **下一步 · 去排产**。

**列表**：批次号和操作列固定，表头可以排序、调列宽、按列筛选；列有批次号、图号、数量、交期等，右边是 **工序概况**（已完成工序、待补齐，或“尚未生成工序”）和操作（**查看/编辑**、**删除**）。单条 **删除** 会弹出“确认删除批次 编号”，要勾选“已核对明细，确认删除批次 编号”才能提交；已有排产、报工、执行状态或外协登记的批次删不掉。

**多选操作**：勾选后出现“已选 N 个批次”，可 **全选当前筛选**、**清除选择**，然后：

- **批量修改**：弹出“批量修改批次”，批量优先级、批量交期、批量备注三项默认“不修改”，改哪项填哪项。先 **预览变更**，核对“批次变更前后对照”（原记录 / 确认后），再 **确认变更**。
- **复制所选**：把勾选批次复制成新批次，先看对照再 **确认批量复制**。
- **删除所选**：先看对照再 **确认批量删除**；已有排产、报工、执行状态、外协登记或数量拆分记录的批次删不掉。原批和拆出的子批都要保留；预检发现其中任意一批不能删除时，会直接说明原因，不进入删除确认。

**新增批次**：填批次号、图号（从下拉里选已就绪的零件）、数量、交期、优先级（普通 / 急件 / 特急）、齐套显示（齐套 / 未齐套 / 部分齐套）、齐套日期、备注，点 **确认新增**。批次号新增后不能改。

#### 批次详情和补充工序

在列表点 **查看/编辑** 打开批次详情，右上角有 **返回列表**、**刷新详情**、**删除批次**。顶部显示图号 / 零件、数量、批次状态、工序进度（已完成 N 道）；已有排产、报工、执行状态或外协登记时会提示不能删除、替换或编辑工序，点 **查看关联情况** 核对原因。

- **批次基础信息**：交期、优先级、齐套状态、齐套日期、备注，点 **编辑基础信息** 改，改完 **保存基础信息**。资料被别人改过时点 **刷新最新资料** 读到最新资料，核对后点 **已核对，继续编辑**，你填的内容不会被覆盖。
- **批次物料齐套**：展开“物料齐套原记录”核对物料、需求量、到料量、单位和齐套记录；点 **维护物料需求** 新增、修改或明确移除需求，保存后重新计算齐套。
- **从工艺模板更新工序**：显示来源工艺、有效工序和更新条件。零件工艺改过以后，点 **预检工序更新**，弹出“确认更新批次工序”：先看“工序更新前后对照”（每道工序标新增 / 删除 / 修改 / 内容不变）和“设备和人员指定”（写明有几道工序的指定会被清除），确认后点 **确认更新工序**，本批次现有工序会被替换成工艺里的工序，之前补的设备、人员指定要重新补。
- **工序概况**：工序总数、自制、外协、已完工、待补齐。
- **批次工序**：列是工序编码、工序、工种、归属（自制 / 外协 / 未归类）、资源补充、完工（已完工 / 加工中 / 已跳过 / 未完工）、操作。“资源补充”一眼能看出哪道还写着“设备未选”“人员未选”“供应商未选”。

补工序按这个顺序做：

1. 点这一行的 **补充资料**，弹出“工序 N · 工序名”。
2. 自制行选 **设备**、**人员**，填 **换型工时（小时）**、**单件工时（小时）**；外协行选 **供应商**，填 **外协周期（天）**。
3. 设备和人员按可操作设备关系联动：选了设备，人员里没有授权的人会标“（不可用）”，页面会提示“所选人员未获设备操作授权”并列出“设备授权人员”。没人可选时，先去人员详情的 **编辑可操作设备** 补关系。
4. 属于合并外协段的工序，供应商和整段周期只读，不能只把其中一道改给另一家厂。需要调整时回零件工艺维护整段，再在批次详情 **预检工序更新**，核对后明确更新这个批次。
5. 点 **保存工序**。没改任何项时会提示“没有需要保存的变更”。

#### 批次文件

点 **批量导入** 打开“批量导入批次”弹窗，点 **批量导出** 打开“导出批次清单”弹窗：

- **导入**：先 **下载模板**；选导入模式——已有批次就更新，没有的就新增 / 只新增没有的批次（已有的跳过） / 先清除全部批次，再按表格重导；**选择文件**（只接受 .xlsx 文件，也可以把文件拖到弹窗里）后 **开始预检**，没有拒绝行再 **确认导入**。列说明见 1.6.11。
- **导出**：**导出选中** 或 **导出当前筛选全部批次**，点 **下载批次清单**，文件叫“批次清单.xlsx”。

### 6.2 执行排产

入口：**排产 → 执行排产**。页头写着“当前生产资料 · 单次排产范围”，右上角是 **排产记录**。页面按 **选批次和日期 → 检查 → 计算** 三步走，每一步的结果只用于这一次排产。

#### 第一步：选批次和日期

- **排产日期范围**：填开始日期和结束日期。齐套日期晚于结束日期的批次会被跳过。
- **选择批次**：点 **选择批次** 打开“选择排产批次”：可搜批次号、图号、零件名，按齐套（全部 / 齐套 / 部分齐套 / 未齐套）筛，切 **全部待排** 或 **仅齐套**，用 **全选当前筛选 / 清除选择** 批量勾，最多选 5000 个批次。选完 **收起范围**；要改就 **重新选择范围**。
- **本次排产规则**：齐套检查（开启 / 关闭）、缺资源工序（自动分配 / 暂不排）、不重排时段、已开工工序固定为“保留记录（不可修改）”。含义见第 7 章；不重排时段见下面第二步。

#### 第二步：排产检查

点 **开始排产检查**（改过范围或规则后叫 **重新检查**）。检查只读资料，“不生成版本、不写入业务或审计数据”。结果分三块：

- **数字**：范围内工序、资料有效、自动分配待补、本次跳过、缺资料工序、未生成工艺批次、已开工工序。
- **四行结论**：
  - **设备 / 人员**：几道缺资源、几道待自动分配；缺的点 **去补齐** 回批次详情。
  - **齐套状态**：几批未齐套，以及本次是执行还是关闭齐套检查；点 **查看批次**。
  - **工时 / 工艺 / 外协**：几道缺资料、几批未生成工艺；点 **处理缺项**。
  - **班表与产能**：本次不检查。夜班、停机和产能是否够用，请到工作日历核对。
- **检查明细**：每道工序一行，写批次、工序、检查结果和原因；已开工的工序还会显示前序、实际开工、确认完工、剩余数量；保持原安排的工序写“因不重排时段（或正式计划里已锁定），保持原安排：开始 至 结束”（同批次排在前面、跟着一起保持的工序也这样写）。“未生成工艺”单独列出还没有工序的批次。
- **本次不重排**：写“本次不重排：A 至 B，共 N 道工序保持原安排”，点开 **查看明细** 逐道列出批次号 · 工序号 名称 · 原安排起止；正式计划里已锁定的工序另列一组。没有设不重排时段时写“本次不设不重排时段”。

**不重排时段**（本次排产规则里的一行）：开始、结束各填一个“日期 + 时:分”，精确到分。

- 甘特图上落在这段时间里的工序保持原安排不动（只有一部分落在里面也算），同批次排在它们前面、还没报工的工序也一起不动，免得后道先做；其余工序照常重排。
- 不填就按交付设置：检查后两个框显示本次生效的时段，旁边标“（按交付设置）”；交付设置里没开时两个框是空的，标“（按交付设置：不设）”。改了任一端，这次就按你填的时段算；点 **不设**，这次所有工序照常重排；填过以后想回到交付设置，点 **按交付设置**。
- 开始要早于结束，并且在排产日期范围内：最早是开始日期的 00:00，最晚是结束日期次日的 00:00。不合要求时这一行下面直接提示，排产检查不会开始。
- 正式计划里已经锁定的工序，不管设没设不重排时段都保持原安排；工作台里不能解锁，确需改排请联系维护人员处理。只想让个别工序这次不动，把不重排时段设到盖住它们的那段时间（同一时段里的其它工序和同批次前道也会一起不动）。
- 因不重排时段保持原安排的工序，方案采用后不会变成锁定：下次排产按下次填的时段算，填 **不设** 就照常重排。
- 这一项只用于本次排产。填过或点过 **不设** 的会记在排产记录里，候选方案页、排产记录都能看到当时的时段或“不设”；没动过这一项的排产（包括以前的排产记录）显示“未记录（按当时的交付设置）”。

检查结果的五种叫法：

| 检查结果 | 意思 | 这次会怎样 |
|---|---|---|
| 资料有效 | 设备、人员、工时、供应商都齐 | 进入计算 |
| 自动分配待补 | 自制工序缺设备或人员，本次规则选了自动分配 | 计算时由系统挑 |
| 本次跳过 | 批次已完成或取消、数量是 0、齐套检查没过、齐套日期晚于日期范围、缺资源且规则选了暂不排 | 不排，原因写在明细里；这次排出的结果只能查看、不能采用，要采用先取消勾选这批（“按工序齐套”下等料的工序除外） |
| 缺资料 | 工时、工艺、外协周期或齐套日期格式有问题 | 不排，按原因回批次或工艺补 |
| 已开工保护 | 已有报工记录或已经开工 | 原记录保留，整道工序不重排；剩余数量要先在现场记录里确认 |

检查结果有时限，页面会写“检查时间 · 结果有效至”；过期或者“排产参数已变化”时要重新检查。

#### 第三步：候选排产

检查通过后点 **核对并开始排产**，弹出“确认本次候选排产”，再核对一遍本次批次数、排产日期、齐套检查、缺资源工序、不重排时段和已有报工的处理方式，点 **确认开始排产**。计算在本机进行，切走页面再回来也能看到最新结果；状态依次是等待计算 → 正在计算 → 计算完成，也可能是部分完成、计算失败或排产中断。结果没回来时点 **查询结果**；上次排产还没确认结果时不能开始下一次。算完后“已保存候选方案”列出每个候选的状态和已保存工序数，点 **详情** 进候选方案页。

排产算出来的是 **候选方案**，不会自动变成正式计划。要让现场按它干，必须在候选方案页 **采用方案**。

#### 排产记录

点页头的 **排产记录** 打开“历次排产 · 只读”。可按排产状态（等待计算 / 正在计算 / 计算完成 / 部分完成 / 计算失败 / 已中断）、提交起日、提交止日筛，按提交时间、开始时间或结束时间排序，从新到旧或从旧到新，点 **查询**；列是排产范围、开始 / 结束时间、候选数、安排数（排产范围里展开“排产设置”能看到缺资源规则和不重排时段），点 **查看** 进候选方案页。安排行数是各候选方案已保存行的合计，不是不重复的工序道数；计算完成只表示排产结束，约束和任务内容要在候选方案里核对。这里不能导出，也不能把某次排产恢复成当前数据；**返回正式计划** 回到选择排产方案。

#### 候选方案页和采用方案

从排产记录或“已保存候选方案”进入。上面是 **候选比较** 表：候选、状态、安排、预计超期批次、总拖期（小时）、时长（小时），点 **查看** 切换候选；交付指标仅覆盖完成批次，资源指标仅覆盖已排结果，缺项不按零计算。当前候选下面有三个页签：

- **候选甘特**：和计划甘特一样的看法，见 6.4。
- **候选交付风险**：和交付风险页签一样，见 6.5。
- **候选排产结果**：“生成资料与记录编号”记着提交 / 结束时间、物料放行方式、不重排时段、齐套检查 / 缺资源、已有执行 / 当时的正式计划、排产时选批、排产记录编号和候选记录编号；“候选明细”按任务安排、交付风险、采用记录、未安排明细四类列表；“完整候选比较摘要”把整份候选和排产时的正式计划对照，列出调整工序、换设备数和“候选批次交付对照”（交付截至日、对比基准完工、候选完工、超期变化（小时））。

顶部按钮：**返回排产记录**、**返回正式计划**、**刷新候选方案**、**试调**（从这份候选新增试调草稿，试调不影响正式计划）、**导出**（导出当前读取范围全部安排与未安排记录），以及 **采用方案**。

**采用方案** 弹出“确认正式采用”：上面列着上次提交时核对的正式计划、当前正式计划（本次预检）、目标候选方案、采用工序数和采用范围，说明“将完整候选方案采用为新一版正式计划，保留历史版本。恢复旧安排需重新排产并采用”。填 **采用原因**、**经办人**，勾选“确认将完整候选方案正式采用”，点 **确认正式采用**。结果确认后显示“已确认：本次生成第 N 版正式计划，共 M 道工序”，点 **进入正式计划** 去看，或 **完成** 留在本页。排产时对照的那份计划已经不是当前正式计划时会被拒绝，提示重新做排产检查；采用结果没回来时点 **查询采用结果**，不要重新采用。

### 6.3 选择排产方案

入口：**排产 → 选择排产方案**。这一页是计划中心：先选一份计划，再在“选择排产方案、计划甘特、交付风险”三个页签之间切换看它。

**方案与范围**

- **所选计划**：下拉里是能读到的计划。没有指定计划时默认选中唯一可读取的当前正式计划；没有正式计划时显示计划列表。
- **计划列表**：点 **展开计划列表**（看完可 **收起计划列表**），勾“历史版本”“试调方案”决定列表范围，**刷新计划列表** 重新读。列是计划 / 方案、版本、类型（当前正式 / 历史正式 / 候选方案 / 试调方案）、记录状态（记录完整 / 部分记录 / 无效记录 / 暂无数据）。
- **读取范围**：开始（包含）、结束（不含），“应用范围”按这段时间读，“完整计划”读全部；点 **刷新所选计划**，读的时间长可以 **取消读取**。
- **数字**：范围内安排、关联批次、已确认预计超期；交付风险读不到时写“交付风险暂无数据”。
- **导出**：弹出“导出计划”，选 CSV 或 XLSX 后 **下载 CSV / 下载 XLSX**，导的是所选计划在当前读取范围内的安排。
- **试调**：以所选计划为原来源新增试调草稿（见 6.6）。
- 页签下方的导航条可以跳到 **计划版本**、**排产记录**、**候选方案**。

### 6.4 计划甘特

入口：**选择排产方案 → 计划甘特** 页签。看的是上面选中的那份计划。

**工具条**

- **甘特分组**：设备 / 人员 / 批次，决定一行是什么。
- **初始计划**：勾上后把这份计划刚采用时的安排画成对照条，看后来试调改了什么；**仅变更** 只留有变化的任务。
- **搜索**：搜批次、工序、设备、人员。回车跳下一匹配任务，Shift+回车跳上一匹配任务，Esc 清除，按 `/` 直接聚焦搜索框；也可以点 **上一匹配任务 / 下一匹配任务**。
- **缩小 / 放大 / 显示完整** 调时间轴；**定位选中任务**（快捷键 L）把选中的任务滚到视野里；**展开甘特 / 收起甘特** 切全屏。
- 图例：安排、已确认准时、预计超期、资源重叠、初始计划、零工时工序、今日 / 数据时点。底部写着“N / M 道安排”，前一个数是当前筛选后画出来的。

**任务详情**：点一个条形打开“任务详情”，分几块：

- 基本项：分件、本工序目标量、计划来源整批量、数量依据、计划开始、计划结束、时长、设备、人员、供应商。
- **调整此工序**：跳到试调，在草稿里改这道工序。
- **工艺前后序**：前序、后序，点了就跳到那道工序。
- **初始计划对照**：变化、初始开始、初始结束、当前开始、当前结束；可 **查看初始安排 / 查看当前安排**。
- **交付风险**：判定、交期、计划完工、超期时长、未排工序。
- **资源占用**：班表内占用、可用时间、占用率、重叠时间、班表外占用。

### 6.5 交付风险

入口：**选择排产方案 → 交付风险** 页签。按所选计划和读取范围算，分三张表：

| 页签 | 列 | 怎么读 |
|---|---|---|
| 交付风险 | 批次 / 零件、交期、计划完工、交付风险、未排工序、说明 | 计划完工晚于交期的批次是预计超期；有未排工序的批次算不出完工，看“说明” |
| 资源负荷 | 资源、安排（小时）、班表内占用（小时）、可用（小时）、重叠（小时）、班表内占用率、班表外占用（小时） | 占用率接近或超过 100%、重叠不为 0、班表外占用不为 0 的资源要重点看 |
| 资源班表 | 资源、可用（小时）、普通有效（小时）、急件有效（小时）、可工作时段、说明 | 看这段时间里每个资源到底能排多少小时，和工作日历、个人日历对得上不 |

“资源重叠明细”列出每个资源重叠的开始（含）、结束（不含）和并行工序，用来定位是哪几道工序挤在一起。

### 6.6 试调排产方案

入口：**排产 → 试调排产方案**，或从选择排产方案、候选方案页、计划甘特的任务详情点 **试调 / 调整此工序** 过来。试调是在一份原来源（当前正式计划或某个排产候选）的基础上单独改几道工序，正式计划保持不变；改满意了先保存成试调方案，再决定要不要采用。

**草稿 / 试调方案列表**：页头 **排产方案试调**，右上角 **返回方案**、**新增试调**。列表分 **试调草稿** 和 **试调方案** 两个页签，可按状态筛、勾“仅此原来源”只看同一来源；列是名称、原来源、状态、安排、更新时间、记录人，点 **打开**。

**新增试调**：弹出“从原来源新增试调”。原来源类型选 **原正式计划** 或 **排产候选**（候选要先在排产记录列表里选那次排产，再选候选；列表按首批版本 / 下一批版本翻）。选好后 **核对原来源**，勾“确认基于此来源新增独立草稿，正式计划保持不变”，点 **确认新增草稿**；同来源已有草稿时可以 **打开已有草稿**。要换来源点 **更换来源**。

**草稿页**：上方数字是预计超期批次、总拖期（小时）、调整工序、换设备工序、换型次数。中间是试调甘特：甘特分组（设备 / 人员 / 批次）、**原安排**（画原来源的安排做对照）、**仅变更**、**含夜间**、搜索试调工序、缩小 / 放大、收起 / 展开甘特；图例是试调安排、原试调基础、约束问题、已锁定，不能调整。

**调整一道工序**：点任务打开“工序详情”，点 **调整此工序**：选 **调整设备**、**调整人员**（外协工序没有内部资源），填 **调整开工**，完工时间按班表算，其他工序需分别调整；人员没有该设备的操作授权会提示“所选人员尚未取得该设备的操作授权”。勾“已核对当前工序与保留输入”后 **保存调整**；**取消编辑** 放弃这一道，**刷新工序** 重新读。

**来源排产的不重排时段**：从排产候选（或由它采用成的正式计划）发起的试调，按那次排产记下的不重排时段判断哪些工序正式采用时要原样保留；那次排产没记这一项的，按交付设置推算。这些工序和正式计划里已锁定的工序一样，工序详情里写明原因，**调整此工序** 用不了；确实要改，请重新排产，并在排产检查里把不重排时段改短或点 **不设**。

**结果页签**：批次对比（批次 / 零件、批次数量、交付截至日、原完工、试调完工、提前（小时）、预计交付、超期（小时）；预计交付分预计按期、预计超期、暂无数据（交期列写“未指定交期”的批次）、有冲突，不能评估、交期数据无效）、资源占用（含停机时段）、调整记录、采用记录、约束问题、完整任务、未排工序。

**底部**：整体约束显示 **通过**、**有提示** 或 **有冲突，不能采用**。

- **放弃草稿**：弹“确认放弃草稿”，草稿删掉，原来源不变。
- **保存试调方案**：填试调方案名称，勾“确认保存完整试调方案，冲突和未排工序一并保留”，点 **确认保存试调方案**；资料变过时先 **刷新草稿**。
- **采用方案**：只有整体约束通过才可用。弹出“确认正式采用试调方案”，填采用原因、经办人，勾“确认将完整试调方案正式采用”，点 **确认正式采用**；结果确认后可 **进入正式计划** 或 **完成**；原来源不是当前正式计划时要 **重新预检**。
- **导出**：弹出“导出试调方案”，点 **下载 CSV（方案对比）**（方案试调对比.csv）或 **下载 JSON（原始数据）**（试调原始数据.json）；“编号与读取范围”里能看草稿、原来源和读取范围的编号。

## 7. 排产规则：每个开关的作用

看本次用了哪套规则：**执行排产** 第一步里的 **本次排产规则**，以及候选方案页“生成资料与记录编号”里的“不重排时段”“齐套检查 / 缺资源”和“已有执行 / 当时的正式计划”。规则仅用于本次排产，不会保存成默认值。

| 规则 | 选项 | 什么意思 |
|---|---|---|
| 齐套检查 | 开启 / 关闭 | 开启后，没确认齐套、物料没到齐的批次在排产检查里标成“本次跳过”，其它批次照常排，但这次排出的结果只能查看、不能采用；要采用，先取消勾选这些批次再重新排产。关闭时页面写“这次没有检查齐套状态；原来的齐套记录不变”，齐套只是显示 |
| 缺资源工序 | 自动分配 / 暂不排 | 自制工序没选设备或人员时：**自动分配** 让系统按匹配规则从绑定该工种的设备和有设备授权的人员里挑，检查里显示“自动分配待补”；**暂不排** 把这道工序标成“本次跳过” |
| 已开工工序 | 保留记录（不可修改） | 已有报工记录或已经开工的工序保留原记录，整道工序不重排，检查里显示“已开工保护” |
| 不重排时段 | 开始 / 结束（日期 + 时:分）、不设 | 甘特图上落在这段时间里的工序保持原安排，同批次排在前面的工序也一起不动，其余照常重排；不填按交付设置。详见 6.2 第二步 |

原来“高级设置”页里的排序方式、计算模式、优化目标、权重这些参数已随旧页面退役，工作台里没有页面显示或修改它们；排产计算按交付时配置的参数运行，确实要改联系维护人员。原来的“锁定近期排程”换成了排产检查里的 **不重排时段**：交付设置里的天数只当默认值（从开始日期 00:00 起往后几天），每次排产都可以在排产检查里改时段或点 **不设**。

## 8. 怎么判断候选方案好不好

不用先懂算法。拿到候选方案后按这个顺序看：

1. **候选比较** 表：预计超期批次有没有减少、总拖期（小时）有没有降、时长（小时）是不是合理。
2. **候选交付风险**：哪些批次预计超期、超多少；有没有未排工序。
3. **候选甘特**：关键设备和关键人员有没有被挤爆，有没有资源重叠、班表外占用。
4. 值班台的 **方案对比**：和排产时的正式计划相比，整体收益与代价、逐批交期变化。

都能接受就 **采用方案**；个别工序想手动挪一挪，先 **试调**，改好再采用。

## 9. 现场：现场记录与现场实际甘特

### 9.1 现场记录

入口：**现场 → 现场记录**。这一页按当前正式计划的安排列出工序，现场每做完一段就登记一次报工；所有工序完成情况、执行复盘、工时定额校准都从这里的记录算。右上角有 **返回**（从别的页面跳过来时）、**刷新现场记录**、**报工文件**。

**筛选**：搜索批次或工序、计划完工起日、计划完工止日、报工状态（全部 / 待报工 / 已开工 / 部分完成 / 已暂停 / 异常 / 已完工）。

**列表**：批次 / 工序、计划设备 / 人员、计划开工 / 完工、累计完成 / 计划应做、执行剩余、状态、操作（**查看报工**，旁边写着已有几次报工）。

**工序详情**：点 **查看报工** 打开，上面是“作业时间线”和 **实际甘特**（跳到现场实际甘特定位这道工序），按钮 **新增本次报工**。报工记录表的列：报工编号、本次数量、实际开工、本次完工、有效工时（小时）、实际设备 / 人员、备注、操作（**补齐 / 更正 / 撤销**）；每条还记着录入信息（录入时间、记录人、经办人、录入来源：手工或 Excel）。“已撤销报工”和“历史现场记录”（旧系统留下的开工 / 完工 / 暂停 / 恢复 / 异常记录）分开列，历史完工记录缺时间时可以 **补齐原始完工记录**。

**登记一次报工**：点 **新增本次报工**，弹出“本次报工”：

- **产出数量**：本次完成数量，下面写着最小 / 最大和已知累计 / 执行目标；剩下的一次做完可以点 **填剩余数**，把剩余数量填进产出数量，核对后再保存。
- **实际起止**：实际开工、本次实际完工。页面会预填时间，请核对预填时间，不确定的时间请清除（每个时间旁有 **清除**）。
- **工时核对**：有效工时（小时），下面显示作业时长和工时差额，帮你发现填错。
- **实际设备 / 人员 / 备注**：实际设备、实际人员、作业备注、经办人。
- **复制上一条** 只取同任务同工序的有效记录值。
- **保存报工** 存这一条；**保存并继续** 先确认保存成功并刷新到最新结果，再打开下一份草稿；**取消** 放弃。

**补齐 / 更正 / 撤销**：**补齐** 打开“补齐本次报工”，只补原来空着的项，要填补齐原因；**更正** 打开“更正报工”，改已填的值，要填更正原因，点 **保存更正**；**撤销** 打开“撤销这次报工”，填撤销原因、经办人，先 **查看撤销影响** 再 **确认撤销这次报工**。撤销的记录进“已撤销报工”，不会真删。

新增、补齐和更正都会核对已经登记的实际前后序时间；后序不能早于前序的实际完工。共同工序与分件工序之间的衔接也会检查，互不依赖的分件可以并行，合并外协段可以使用同一实际周期。前序实际晚于原计划、后序尚未报工时，可以如实登记晚完工。撤销前序若会影响已有后序报工或正式安排，会在影响清单中说明原因并禁止确认；文件预检和保存按整批修改后的最终状态核对，有冲突时整批不保存。

**报工文件**：点 **报工文件** 打开弹窗：**下载模板**（现场分次报工模板.xlsx）或 **导出当前范围**（现场报工导出.xlsx）。文件是 XLSX，13 列，任务编号、工序范围、单件编号已预填不可修改，也兼容旧的 10 列文件。**选择文件** 后 **开始预检**，结果按行数、变更、重复、空白、问题汇总，逐行标新增 / 补齐 / 重复 / 空白 / 拒绝；有问题时 **下载问题清单**（报工导入问题.xlsx）改好后 **重新预检**，没有拒绝行再 **确认导入**。列说明见 1.6.12。

### 9.2 现场实际甘特

入口：**现场 → 现场实际甘特**。把实际报工画在时间轴上，和原计划对照；页头写着“数据截至”，右上角有 **刷新实际甘特**，还能跳到 **计划甘特**、**现场记录** 或 **回来源**。

**选择计划**：对照计划默认是当前正式采用的那份，也可以选历史正式计划（显示“正式 vN”）。

**当前范围概况**：整道已完工、已报工 · 未整道完工、待报工、平均整道完工偏差（分钟，仅统计有确认完工时间的已完工工序）。

**工具条**：

- **甘特视图**：按设备、人员或批次分组，每组写着几道工序。
- **搜索现场甘特**（批次 / 工序 / 设备 / 人员）；**晚期筛选** 只看晚期工序。
- 图例：原计划、实际报工、已有剩余安排、关键链。
- **全部展开 / 全部折叠**、**只看选中**、**详情**、**关键链连线**。
- **缩小时间轴 / 放大时间轴**、时间轴缩放模式（自动 / 手动）、时间轴刻度、**适应全部**、**定位选中工序**。
- **范围**：原计划时段（计划完工开始日 / 计划完工结束日）、资源范围、批次范围，点 **应用范围**；**清除来源范围** 去掉从别的页面带过来的条件。
- **导出**：弹出“导出现场实际甘特”，点 **下载 CSV**，按当前查询范围和本次读取的数据导出全部匹配工序及其逐次报工，不受滚动、折叠和详情开关影响；数据变化时下载会要求刷新。

**每一行**：写着计划应做、执行剩余、几次报工，工时未知的记录数；标记有“已晚完成”“到期未确认完成”“零工时工序已安排 · 完成待确认”“待续排”。点工序打开“工序详情”，可切 **逐次报工 / 整道工序**，**定位本次报工**，看剩余安排。开 **关键链连线** 后会画所选计划关键链或所选工序前驱链（近似）：工艺依赖是实线，资源依赖是虚线。

### 10.2 执行复盘

- **已确认整道完工偏差**：按工序看整道完工比计划早了还是晚了。
- **到期未确认已过时长**：到期还没确认完工的工序，已经过了多久。
- **实际资源工时**：设备、人员两组，看实际工时分布。
- **统计说明与待补资料**：哪些记录缺时间或缺工时、没有算进去。

### 10.3 其他报表

在报表中心页底部的“其他报表”里选报表：**超期批次**、**资源负荷 / 利用率**、**停机影响**、**正式执行复盘 / Excel**（只做导出）。填统计起日、统计止日后 **读取报表范围**，可搜索、排序，点 **导出 XLSX**；导出文件有“范围与计算方式”和“范围全部结果”两张表。

| 报表 | 列 | 怎么算 |
|---|---|---|
| 超期批次 | 批次、零件、风险类别、交期、计划完工、预计超期（小时） | 按正式计划评估交付风险，未排产和交期异常批次单列 |
| 资源负荷 / 利用率 | 资源、类型、班表内占用（小时）、计划任务数、可用工时（小时）、整窗占用率（%）、累计负荷（小时）、重叠负荷（小时）、班表外占用（小时）、计算说明 | 整窗占用率按班表内占用并集 ÷ 可用工时计算；设备扣除停机，人员使用个人日历 |
| 停机影响 | 设备、停机工时（小时）、停机次数、计划重叠（小时）、计划重叠次数 | 按已登记的停机记录统计 |

导出的都是当前报表、当前范围下的结果，不是完整数据库，也不能拿来恢复计划。

### 10.4 工时定额校准

入口：**统计分析 → 工时定额校准**。用现场已确认的整道完工记录，给零件工艺模板里每道自制工序的单件工时提建议；核对后可以采用，采用后模板定额更新并锁定。

**校准明细** 的列：图号 / 零件、工序 / 来源、原定额（小时/件）、建议（小时/件）、可用记录数、偏差、状态（数据不足 / 已有建议）、详情。规则：取最近 20 条来源与版本已确认的整道完工记录，至少 5 条才生成中位数建议；不足 5 条显示“同模板、同版本的可用完工记录不足 5 条，暂无建议”；原定额为 0 或未填写时都不算相对偏差。

**详情**：原定额、建议定额、可用记录数、核对记录总数，记录分“可用记录”“已关联但剔除”“同零件未关联核对”三组，能看每条记录为什么算或不算。

**采用**：点 **预检并采用模板定额**，弹窗列出模板工序、模板版本（第 N 版）、原定额、建议定额、可用记录数、未采用记录数。填 **采用原因**、**经办人**，点 **检查是否可采用**（资料变过先 **刷新所选模板**），勾选“我已知道：采用后这个模板的定额锁定，不能撤销，以后不能再改；新定额只用于以后新增的工序”，再点 **确认采用并锁定**。结果在“模板采用与锁定结果”里显示，模板上会标“定额已锁定（来自工时校准）”。

**锁定意味着什么**：采用后这个模板工序的单件工时就锁定了，不能撤销；零件工艺里的普通保存和工时定额文件导入都会跳过它（导入预检显示“单件工时已锁定 · 本行跳过”），工时定额校准也不能对它再次采用（会提示已经采用并锁定，不能重复采用或覆盖）。新定额只用于以后新增的工序，已有批次的工时保持不变。采用前务必核对可用记录。

**导出**：**导出** 校准明细，文件叫“工时校准明细-日期.csv”或“.xlsx”。

## 11. 系统管理

入口：**系统 → 系统管理**。页头写着“本机备份恢复、日志与自动维护”，右上角 **重新检查**、**导出诊断文件**（系统诊断.json）。四个数字：当前页面检查、本机数据读取、数据库状态、备份校验。下面是 **概况 / 备份恢复 / 运行日志 / 配置** 四个页签。

### 11.1 概况

- **本机维护事项**：备份恢复、运行日志、自动维护规则三项的入口和当前状态。
- **最近自动维护结果**：自动备份、备份清理、操作日志清理各自上次什么时候跑、结果如何。
- **页面环境自检**：只表示当前页面环境，默认收起。无法读取维护状态时会明确提示并保留写入保护，不能把读取失败当成已确认暂停或已恢复。

### 11.2 备份恢复

列表可按搜索、记录类型、记录状态、开始日期、结束日期筛，点 **查询**，**清除筛选** 重来，**刷新清单** 重新读一遍。列是时间、类型、状态、摘要 / 来源、文件、大小、详情。备份文件名由系统自动按时间和用途生成，不要手工改。

- **新增备份**：弹出确认，勾“我已核对所选文件与操作影响”后提交。正式排产、清除重导、恢复之前都先做一次。
- **下载备份**：在备份详情里，把备份文件拷走另存。
- **删除备份**：勾选确认后删除，删了不能恢复。
- **恢复备份**：在备份详情里点，弹窗写明“将用所选备份替换当前数据库。系统会先生成保护副本；完整性检查不通过时自动还原”，并且“一旦提交恢复，业务操作会停用。无论恢复成功还是已还原，都要关闭整个软件再启动；只刷新浏览器不算重启”。要勾“我已核对所选文件与操作影响”并输入“恢复”两个字才能提交。

恢复过程的状态依次是已接收 → 检查中 → 生成保护副本 → 恢复中 → 完整性检查中 → 已完成；出问题时是操作失败、恢复失败，已还原、还原失败，需人工核对或需人工核对。提交后页面会转到“APS 智能排产 · 系统维护”，可以 **按编号查询** 进度、**导出维护诊断**，结束后 **返回工作台**。“上次维护操作的结果”里能 **查询结果 / 确认结果**，记着操作编号、维护编号 / 结果代码和维护阶段。

### 11.3 运行日志

按日志来源（主日志 / 错误日志 / 启动日志 / 操作记录）、日志级别（信息 / 警告 / 错误 / 调试 / 严重）、开始日期、结束日期和搜索筛选，点 **查询**。列是时间、级别、摘要 / 来源、详情。**导出这段日志 CSV** 只导当前筛选到的这一段；**脱敏诊断 ZIP** 打包给维护人员排错，里面的敏感内容已脱敏。操作记录里能看到导入、备份、恢复、排产、采用这类动作是谁在什么时候做的；部分报表导出只是直接下载文件，不一定都有操作记录。

### 11.4 配置

- **页面偏好**：主题（浅色 / 深色）、每页条数（10 / 25 / 50）、紧凑行距。只影响本机显示。
- **本机自动维护配置**：先 **刷新配置** 读当前值。备份规则：自动备份、备份检查间隔、清理过期备份、备份保留时间、备份清理检查间隔；操作日志规则：清理操作日志、操作日志保留时间、日志清理检查间隔。保留时间按天填（最多 365），检查间隔按分钟填（最多 1440）。改完 **保存维护配置**，不想要就 **放弃草稿**（会问“放弃当前草稿并刷新？”）。自动维护在打开页面时检查是否到期；操作日志与运行日志分别清理。

## 13. 出错后的恢复路线图

这一章专门回答“已经做错了，怎么退回”。先记住一个原则：能用普通页面改回来的，不要急着恢复数据库；只有整批数据错了、误删了很多、或者要把整库恢复到某个时刻时，才去 **系统管理 → 备份恢复**。

| 出错情况 | 先做什么 | 怎么退回 |
|---|---|---|
| 文件导入错了少量行 | 不要马上清除重导，先看预检结果哪些行新增、更新、拒绝 | 导出当前数据，把错行改对后再导一次；除批次的清除重导外，重导一次就能把值改回来 |
| 批次用了清除重导，发现整批不对 | 先停下，不要继续排产或继续导更多表 | 能用正确文件重建就重新导；已经影响很多关联数据，去 **备份恢复** 用导入前的备份 |
| 工作日历或个人日历填错 | 找到具体日期 | 单天用 **清除单独设置，恢复默认** 或重新保存覆盖；一段日期用工作日历的 **批量维护** 或个人日历的 **按日期范围清除** |
| 批次工序补错了设备、人员或工时 | 回批次详情 | 再点一次 **补充资料** 改过来；已排进正式计划的要重新排产 |
| 试调改得不满意 | 看整体约束和批次对比 | 点 **放弃草稿**，原来源不变；已保存的试调方案不采用就不影响正式计划 |
| 采用了不该采用的方案 | 先确认现场还没按它干 | 正式计划不能撤回，只能修正资料后重新执行排产，采用新的候选；历史正式计划在计划列表里还能看 |
| 报工登记错了 | 打开那条记录 | 用 **更正** 改值、**补齐** 补空项，或 **撤销** 整条作废，都要填原因 |
| 恢复备份后发现不对 | 看“上次维护操作的结果”是已完成还是已还原 | 恢复前系统生成的保护副本和恢复前的备份都在备份恢复列表里，确认后再恢复一次 |
| 恢复过程中失败 | 不要继续大批量操作 | 状态是“恢复失败，已还原”表示已回到恢复前；“还原失败，需人工核对”时让维护人员看运行日志和备份文件 |
| 浏览器关闭或软件中断 | 先重新打开页面，不要重复点高风险按钮 | 各页面的 **查询结果 / 刷新上次操作记录** 会把上次没确认的操作找回来；不确定时先查操作记录和当前数据，再决定是否重做 |

外协工序确认完工后，实际设备和人员可以保持未填写。再次排产、采用方案或试调时，系统保留外协实际起止时间，不占用本厂设备和人员，也不会影响其他批次继续排产。自制工序仍需填写实际设备和人员。

恢复数据库属于高风险操作。恢复前先确认备份文件、时间和用途；恢复后按提示重启整个软件，再抽查批次、计划甘特、现场记录和报表。报表导出的文件不是数据库备份，不能拿来恢复系统。

## 14. 常见问题

### 齐套日期为什么没影响排产？

看本次排产规则里的 **齐套检查**。关闭时齐套只显示，不影响排产；开启后，没确认齐套、物料没到齐的批次在排产检查里标成“本次跳过”，其它批次照常排，但这次排出的结果只能查看、不能采用；要采用，先取消勾选这些批次再重新排产。另外不管开不开，齐套日期晚于这次排产结束日期的批次都会跳过。

日期在本次排产范围内时，普通批次和逐件工序都遵守同一个齐套检查设置。候选正式采用、基于候选或正式计划继续试排时，也沿用生成该计划时的设置；不会在采用时自行重新开启齐套检查。

### 工作日历文件里填了周末为什么变成假期？

文件的“类型”列只认工作日和假期；留空又没配置过的日期按默认规则定，周末算假期且不可排产。页面上用 **维护此日** 改的是“这一天是否排产”，和文件里的“类型”是一回事。

### 占用率超过 100% 一定错吗？

不一定，但要检查。它表示这段时间安排的工时超过了可用工时，可能是工作日历、个人日历没配好，也可能是任务确实太挤。到交付风险的 **资源负荷** 和 **资源班表** 页签对照看。

### 零件工艺改了，批次工序怎么没变？

批次工序是生成时按当时的工艺复制的，工艺改了不会自动更新。回批次详情点 **预检工序更新**，看清前后对照和会被清除的设备、人员指定，再 **确认更新工序**。已有排产或执行记录的批次不能替换工序。

### 计划列表里为什么没有计划？

还没有采用过任何候选方案，就没有正式计划。先去 **执行排产** 算候选，再在候选方案页 **采用方案**。历史版本和试调方案要在计划列表里勾上才会显示。

### 排产算完了，为什么现场还是按旧计划？

排产算出来的只是候选方案。要在候选方案页 **采用方案** 并 **确认正式采用**，它才成为当前正式计划；现场记录、值班台、报表都只看当前正式计划。

### 恢复备份后数据和之前不一样？

恢复成功后当前数据库就是备份时的状态，备份之后新增或修改的数据不在里面。系统在恢复前会生成保护副本；确认清楚后可以再恢复回去。恢复完一定要关闭整个软件再启动。

### 采用后计划甘特上看不到任务？

先看四件事：一是所选计划对不对，计划列表里“当前正式”才是最新采用的；二是读取范围，开始（包含）、结束（不含）是不是把任务框在外面了，可以点“完整计划”；三是有没有勾着 **仅变更** 或留着搜索词；四是甘特分组，设备分组看设备行，批次分组看批次行。

### 同一个人能不能操作多台设备？

可以。一个人可以关联多台设备，但同一个人只能有 1 台 **主操设备**；设了新的主操，原来那台自动变成非主操。文件里给同一个人设多台主操时，导入预检会把多余的主操行标成错误。

### 设备编号 / 工号 / 图号填错了怎么改？

编号一旦录进系统就不能直接修改。要先删掉错误的记录，再重新录一条。已经被批次工序、计划、报工或可操作设备关系用到的编号删不掉，页面会说明原因；要先把用到的地方改掉，再删除。

### 批次详情里设备 / 人员选不到？

说明这道自制工序的工种没有绑定设备，或者设备和人员之间没有可操作设备关系。先到基础资料给设备绑定工种，再到人员详情 **编辑可操作设备** 新增关联并保存，回批次详情刷新就能选到了。

### 外协工序的周期改不了？

这道外协工序属于零件工艺里“合并设置”的外协组，批次详情里显示“整组周期（只读）”。要改这个周期，回零件工艺详情的工时定额一步改这组的总周期，或者把周期算法改成“分别设置”。

### 补充资料时提示“所选人员未获设备操作授权”？

选的人员和设备之间没有可操作设备关系。去人员详情 **编辑可操作设备** 给这个人新增这台设备的关联，或者换一个“设备授权人员”里列出的人。

### 为什么有的按钮点不了？

按钮不可用时页面会显示原因，把鼠标停在按钮上或看旁边的说明。常见原因：上次操作的结果还没确认（先点 **查询结果**）、资料已过期（先刷新）、当前记录已被别的计划或报工用到、试调整体约束有冲突。

### 上次操作的结果没确认，页面一直提示怎么办？

每个会写数据的页面都记着上次操作，结果没回来时会拦住新的提交。按页面上的 **查询结果**、**刷新上次操作记录** 或 **查询上次采用结果** 把结果查回来，看清是成功还是失败再继续；不要靠刷新浏览器或重复提交绕过去。
