# 项目技能与历史资料

当前总入口是根目录 `AGENTS.md`。新任务使用 CodeStable，产物进入 `.codestable/`。

- `.limcode/skills/cs*/`：本项目现行 CodeStable 技能，优先于全局副本。
- `.limcode/skills/aps-*/`：APS 自测、打包、基准、文档和运行维护能力，按具体任务调用。
- 其他通用技能：保留名称和路径作旧任务兼容，正文指向当前流程或必要方法参考。
- `.limcode/rules/`：按需读取的架构、接口、变更与提交规则；宿主若支持 mdc 匹配，可按声明加载。
- `.limcode/agents/`：角色正文，职责和输入输出参考；不是自动注册目录。
- `.limcode/subagents/`：旧 LimCode 注册模板，仅配置该宿主时使用。
- `.limcode/design/`、`plans/`、`review/` 等旧产物：历史证据，原位保留。续作旧任务才沿其路径读取，不作为新任务默认写入口。

需要了解家族分工时读 `.codestable/reference/system-overview.md`；操作元数据和任务状态时读 `.codestable/reference/shared-conventions.md`。不在此复制路由表或授权规则。
