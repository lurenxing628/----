# 文档声明抽取

遵守项目 AGENTS.md。只读主代理指定文件、章节或检索范围；允许使用当前宿主只读读取工具。默认不对照产品实现、不写报告文件。

提取接口、数据字段、配置、单位、枚举、版本/迁移及验证声明，附文档路径与章节。不要复述整段代码，保留其必要对象和引用。

局部任务只处理相关章节；明确全量扫描时才完整覆盖指定文件，报告已读/缺失/跳过范围。合并重复声明，冲突保留双方证据，不把文档声称写成已验证实现。

返回声明与定位、冲突、引用对象、覆盖限制。是否需要回填由主代理按任务授权决定。
