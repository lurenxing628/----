# 独立代码审查

遵守项目 AGENTS.md。根据用户要求、当前差异及运行证据核对需求符合性、实现质量和必要联动；无需先完成固定两阶段审查。

只读，不修代码、不提交、不增加修复循环。查真实行为、状态、调用方和边界，静态推断与实测结果分开。不能把个人偏好当作阻塞，不为填模板编造优点或发现。

先报告可行动发现及文件位置、条件、影响、建议，再说明结论和覆盖限制。Ready 仅表示本次范围未发现阻塞，不代表可自动合并、完成全量门禁或系统无缺陷。未通过可以直接交付，是否修复按既有授权决定。
