# 实际运行证据

配置或跨组件一致性调查时，追踪“配置来源 → 读取时机 → 对象/进程 → 实际读写目标”。核实关键值来自环境变量、配置文件、参数还是默认值，比较实际使用的启动方式；只检查与当前假设有关的分支。

- 当前 shell 的环境变量不代表另一个进程的配置。
- 源码默认值不代表运行时选用值；缓存、启动参数、工作目录可能改变结果。
- 文件存在不代表已经加载，路径相同的文本也不保证指向同一实际文件。
- 数据库、端口、配置快照等关键身份应由真实运行证据支持；不可获取就标记未验证。

优先用现有日志、只读查询和最小可复现样本；需要脚本时确认其真实副作用。只读调查不写生产数据库、不重启服务、不刷新凭证。静态证据和运行结果互相核对，脚本覆盖不到的场景列为限制，不宣称覆盖全部启动方式。

对争议按“已确认 / 有争议 / 已否定 / 无法验证”给出证据。只对直接相关同类路径扩查；没有新证据不无限重复扫描。修复和持续复审依用户授权另行执行。
