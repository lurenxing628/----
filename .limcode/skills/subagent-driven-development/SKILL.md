# 旧计划中的任务委派

主流程跟随 [cs-feat-impl](../cs-feat-impl/SKILL.md) 或 [cs-issue-fix](../cs-issue-fix/SKILL.md)。只有具体子任务可独立执行且当前授权和宿主支持时才委派，兼容要求见 [共享约定](../_shared/subagent-compat.md)。

给子代理当前任务、必要背景、允许修改的范围、非目标和验证要求。按文件所有权与依赖安排并发；共享写入点先协调，主代理保留最终整合责任。缺上下文先补足，没有新证据不原地反复重试。

审查按风险安排，可在一次有明确范围的审查中核对需求、业务合同与实现质量。无需为每个小任务固定创建实现、符合性、质量三组代理。普通审查只读报告；用户授权修复后才处理问题，复查限于修复和受影响合同，持续循环须有明确要求。

主代理核对真实差异及验证证据，不能把子代理的完成声明直接当验收结果。无独立审查时如实说明，不声称完成了独立验证。
