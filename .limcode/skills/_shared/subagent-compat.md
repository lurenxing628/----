# 子代理宿主适配

授权、模型继承、并行范围和审查深度遵守根目录 `AGENTS.md`。本文件只解决角色如何交给当前宿主，使用子代理时才读。

- 使用当前宿主实际提供的委派工具；只读任务保留只读边界，写任务明确文件范围，避免共同写同一文件。
- `.limcode/agents/*.md` 是角色正文，不是自动注册目录。按角色需要提供目标、已知证据、约束与输出，不注入无关流程全文。
- 当前宿主为旧 LimCode 且已注册相应角色时，可用原生 `subagents`；配置说明见 `.limcode/subagents/README.md`。其他宿主直接使用自己的通用子代理，不为适配去安装或修改 LimCode。
- 默认省略模型/推理强度覆盖字段以继承主代理；用户本轮明确指定且当前工具支持时才覆盖。旧模板的型号不构成授权，不猜测渠道 ID，不宣称未经核实的继承状态。
- 独立审查提供必要原始证据与任务约束，避免把待验证结论当事实。独立上下文可减少共享偏差，不保证没有偏差。
- 委派不可用时说明限制，继续主代理能完成的工作；不得把主代理自查称为独立审查。若独立审查是明确交付条件，报告该条件未完成。
- 不自动启动外部助手。嵌套深度由当前工具和任务授权决定；单任务角色可被要求不再委派，不据此声称所有宿主都不支持嵌套。

角色入口：`.limcode/agents/README.md`。仅旧 LimCode 注册工作需要读取 `.limcode/subagents/limcode-subagents.template.jsonc`。
