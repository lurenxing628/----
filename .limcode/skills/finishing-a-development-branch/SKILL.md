# 分支收尾

依据已有授权完成交付；用户只要求实现时，报告改动、验证和未提交状态即可。不要自动提交、推送、合并、删除分支或清理工作树。

复用最终版本上已经完成的有效验证，合并产生新内容或暴露新风险时补查受影响行为。测试失败要明确报告，仍可保留现场和交付排查结果，不以失败为由要求先修无关问题。

需要提交时按需读取 [Git 安全参考](../git-commit-safe-workflow/git-safety.md)。合并前核实目标分支、任务基线和工作区状态，不能用猜测的主分支或无条件 `git pull` 改变现场。

已有明确推送、PR 或合并要求时按其执行；缺少实质目标才询问。PR 后默认保留工作树供后续处理。用户要求丢弃时先核对将丢失的具体提交和本地修改；已有明确针对这些内容的授权不重复询问。清理只针对本任务，禁止覆盖或删除他人的修改。
