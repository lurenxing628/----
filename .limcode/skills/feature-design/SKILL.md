# 旧复杂设计

当前设计入口是 [cs-feat-design](../cs-feat-design/SKILL.md)。旧 design 保留原路径，不启动另一套新任务主流程。

重点区分用户要求与建议扩展，核实输入、状态、输出、Schema、调用方和文档联动。按风险检查空数据、老数据、重复提交及状态前置条件；技术不确定性用必要的最小验证解决。

只有用户明确要求多轮设计或独立审查时，安排对应轮次；授权覆盖完整设计时连续完成，不在每轮等待“继续”。审查结论仍需代码证据，独立上下文不保证无偏差。委派适用时按 [共享兼容约定](../_shared/subagent-compat.md) 执行。

设计和审查不自动授权代码修改。用户已批准实施时按现有范围推进；新的关键取舍、破坏性变化或实质扩范围再确认。
