# 有效测试与测试先行

项目验证要求以根 `AGENTS.md` 和当前 cs 任务为准。新增合同用测试锁住，bug 修复优先用可重复失败证明问题，再确认修复后通过。按需读取 [testing-anti-patterns.md](testing-anti-patterns.md)。

测试先行适合行为尚未实现或需要复现 bug 的改动。验证失败原因确实来自目标问题，而不是导入、环境或测试错误。行为不变的重构可用已有回归保护，无需制造失败。

若实现已经存在，保留当前工作，通过受控回退补丁、隔离副本或等价验证检查测试能否捕捉旧问题；不为满足顺序删除实现或覆盖他人修改。低风险文案、配置等改动采用与风险相称的验证，不机械增加测试或要求例外批准。

复用同版本已完成的验证；根据后续变化补跑受影响检查。输出实际验证与限制，不把有测试文件等同于已验证。
