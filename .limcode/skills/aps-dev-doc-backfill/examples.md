# APS 文档同步示例

## 局部更新

用户：“排产入口新增了 end_date，请同步相关文档。”

读取已授权改动及其调用者，核对默认值、截止语义、页面字段与失败行为；更新承载这些事实的接口/速查章节及相关 CodeStable 当前说明。其余 dirty 文件和无关文档不自动纳入。汇报实际修改与证据，不要求四路全仓扫描。

## 只读核对

用户：“检查这份接口清单是否过期。”

按指定清单核对对应路由、参数和模板，报告已确认差异与证据。不自动回填、不运行排产、不创建审计文件。用户随后批准修正时，连续更新相关内容并检查链接与事实一致性。

## 全量文档核对并回填

用户：“把所有当前开发文档逐章节核对并修正。”

明确当前文档集合和历史排除项，提取标题并覆盖相关页面、DB、排产、Excel、交付与门禁事实。独立的大范围事实面可委派，不固定代理数量。最终说明各文档覆盖、修改、证据和剩余未决项；不能将局部检查称为全量完成。

## 数据库变更

用户：“我新增了人员日历字段，请更新对应说明。”

核对 schema、迁移、仓储映射与相关页面/Excel 的真实使用方式，再更新字段字典、相关合同和说明。若实现与已批准需求冲突，报告这一差异；不擅自修代码或把错误实现改写为业务要求。
