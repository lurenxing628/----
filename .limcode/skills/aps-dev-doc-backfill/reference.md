# APS 文档同步参考

本参考按需读取相关事实面。默认局部同步；只有用户明确要求全量文档核对时才遍历约定集合。授权、历史排除项和完成标准以本技能 `SKILL.md` 与根目录 `AGENTS.md` 为准。

## 文档职责

| 信息 | 优先维护位置 |
|---|---|
| 当前需求、架构、issue/refactor 与决定 | `.codestable/` 对应文件 |
| 已有综合开发说明与数据模型 | `开发文档/开发文档.md` |
| 参数、字段、关键文件与操作速查 | `开发文档/系统速查表.md` |
| 已有页面、接口、表单和可见文案 | `开发文档/面板与接口清单.md` |
| 已有实施计划与阶段证据 | `开发文档/实现计划表.md`、`开发文档/阶段留痕与验收记录.md` |
| 开发环境、测试目录、统一门禁与证明边界 | `开发文档/README.md` |

已有多个文档确实记载同一行为时保持一致，或者明确引用权威章节；不要求每次新增信息机械双写。历史决定与证据不改写成当前实施事实。

## 按变更选择核对面

### 路由与页面

读取相关 `web/routes/`、蓝图注册入口、`templates/`、`static/` 及消费者。核对 URL/endpoint、HTTP method、query/form 参数、默认值、空值语义、模板映射、按钮和 flash 文案。

新增、删除或更改接口时更新相关接口清单与速查条目；纯内部拆分可只更新实现位置。历史 `web_new_test/` 已退役，只有指定历史任务才查阅；不要凭旧模板示例推断当前双栈行为。

### 数据库

以 `schema.sql`、相关 `core/models/`、`data/repositories/` 和迁移实现核对表、字段、索引、外键、唯一性、枚举及兼容语义。检查 SQL 与字段映射是否消费了文档所述字段。

涉及数据模型变化时同步相关开发说明、速查字段字典和 CodeStable 当前设计。实现与已批准合同相反时记录差异，不通过改文档掩盖实现问题。

### 排产、日历与配置

从相关 `core/services/scheduler/`、`core/algorithms/`、配置定义和调用者提取参数、默认值、排产窗口、齐套约束、日历覆盖和落库语义。对涉及的字段追踪“入口 → service → algorithm → persistence/logging”；无需扫描无关算法。

检查公开输出、历史读取、页面、导出是否共同消费该行为。速查条目与当前需求/架构说明按各自职责更新，证据可以引用相关测试，但未运行的测试不能写成验收通过。

### Excel

读取相关 `templates_excel/`、Excel 路由、导入组件和 `core/services/common/` 实现。核对模板列名、append/overwrite/replace 语义、整批拒绝条件、预览行号、错误文案和留痕键名。

更新受影响的模板清单、操作说明及合同；不因一个列名变化触发全套文档逐章回填。

### 测试、门禁与交付

以实际登记表、脚本和 `开发文档/README.md` 核对测试入口、依赖与证明类型，不在多份技能里维护固定测试数量。新合同测试的登记不能用文档描述代替。

发布约束以当前 `DELIVERY_WIN7.md` 和 `aps-package-win7/SKILL.md` 为准。APS 产品仍兼容 Win7 x64 / Python 3.8 / 离线；宿主维护工具按 attention 的边界处理。

更新验收记录时区分旧证据、本轮静态检查、实际局部测试与最终 clean proof；不将“待测试”直接改为“已通过”。

## 全量核对补充

明确约定文档集合后，抽取标题逐章核对。优先处理会误导用户操作的接口/参数，再处理模型、算法、交付与验收。每份范围内文档说明覆盖状态，历史排除项继续保留。

文档中的原始方案片段如已过期，标为历史并指向当前实现，不能删除原有决策语境。移动章节时核对交叉链接与锚点；未完成的核对范围要明示。
