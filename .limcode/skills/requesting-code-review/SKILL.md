# 代码审查兼容入口

项目专项审查按 [aps-deep-review](../aps-deep-review/SKILL.md)，系统审计按 [cs-audit](../cs-audit/SKILL.md)；按当前任务选择一个适用入口，不叠加完整流程。

明确用户要求、改动范围、当前版本、已有测试和疑点。核对是否漏做或多做，再检查分层、业务边界、错误处理、真实测试和实际文档联动。审查未提交改动时以工作区差异为准，不用 `HEAD~1` 猜任务基线。

只报告可行动的问题，给出路径、行号、触发条件和影响；个人风格偏好不构成阻塞。缺运行证据时明确限制。需要留痕时跟随当前 CodeStable 任务目录，旧 review 在原处维护。

发现问题不授权修改。已有修复授权时完成相应修复与定向验证；普通审查不自动进入反复修复复审。只有新改动、新证据或尚未解决的具体风险才扩大复查。需要委派时遵循 [共享约定](../_shared/subagent-compat.md)。
